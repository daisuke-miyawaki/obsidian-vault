# かくじかん YouTubeナレッジ化 — 作業手順

## 推奨：自動スクリプト（NotebookLM Playwright）

手動コピペの代わりに、隣のフォルダ `../notebooklm_bot/` のスクリプトを使います。

```bash
cd ../notebooklm_bot
./run.sh setup          # 初回のみ
./run.sh login          # Googleログイン（初回のみ・5分）
./run.sh add-sources    # 38本URLをNotebookLMに追加
./run.sh run-one 001    # 1本試作
./run.sh run-all        # 未処理をすべて
```

詳細は [`../notebooklm_bot/README.md`](../notebooklm_bot/README.md) を参照。

---

## 全体の流れ（自動）

1. **notebooklm_bot** … URL一覧読込 → NotebookLM操作 → md保存
2. 成果物はこのフォルダ（`001_*.md`）に出力
3. `_index.md` が自動で「完了」に更新
4. 次のYouTuberは `notebooklm_bot/config.yaml` を書き換えて繰り返し

---

## 次のYouTuberへ切替

1. `notebooklm_bot/config.yaml` を編集:
   - `channel_slug`
   - `paths.urls_file` / `output_dir` / `index_file`
   - `notebooklm.notebook_name`
2. `notebooklm_bot/state/` を空にする（進捗リセット）
3. 新チャンネルの `_urls_all.txt` を用意
4. `./run.sh login` → `add-sources` → `run-all`

---

## 手動手順（スクリプトが動かないときの予備）

### ステップ1：URL一覧（済）

- 全一覧: `_urls_all.txt`
- NotebookLM用: `_urls_batch01.txt`
- 動画一覧: `_index.md`

### ステップ2：NotebookLM

1. [NotebookLM](https://notebooklm.google.com/) を開く
2. 「新しいノートブック」を作成
3. ソース追加 → 「YouTube」→ URLをコピペ
4. 文字起こしが取れない動画があれば `_index.md` にメモ

### ステップ3：1本ずつノート生成

1. `_NotebookLMプロンプト.md` のプロンプトをコピー
2. 動画タイトルを入れてNotebookLMに送信
3. 出力を `001_短いタイトル.md` として保存
4. `_index.md` を「完了」に更新

---

## ファイル命名ルール

- `001_`, `002_` … 連番（`_urls_all.txt` の順）
- タイトルは30文字程度で切る
