## 手順（この順で）

### 1. NotebookLMを開く
https://notebooklm.google.com/

### 2. 新しいノートブックを作る
名前例: `かくじかん_batch01`

### 3. ソースを追加
- 「YouTube」を選ぶ
- 下のURL **1本だけ** 貼って追加（試作は1本から）

```
https://www.youtube.com/watch?v=FQiNA54Fo9M
```

※慣れたら `_urls_batch01.txt` から38本まとめて追加してもOK

### 4. プロンプトを貼る

```
ソース「AI × note の正しい使い方。実際にお金になるまでの道も教えます。」について、次の2段構成でMarkdownを出力してください。

【第1部：3行で思い出す要約】
- 必ず3行（箇条書き3つ）
- この動画のテーマ・結論・使いどころがパッと思い出せる内容
- ここだけに情報を詰め込まない（詳細は第2部へ）

【第2部：構造化詳細ノート】
- 文字起こし全文は書かない
- 言い淀み・繰り返し・雑談は省く
- 概念・手順・理由・数字・具体例・注意点は漏らさず残す
- 動画の話の順番どおり、見出しと箇条書きで整理
- 重要フレーズだけ > 引用
- 各セクションに「ポイント」「注意点」「例」があれば追加
- 最後に「触れられたトピック一覧」をチェックリストで

出力はこの1動画分だけ。
```

### 5. 出力をCursorに保存
- NotebookLMの回答を全部コピー
- このフォルダに新規ファイル `001_AI × note の正しい使い方。実際にお金に.md` を作ってペースト
- 基本情報のURL行を確認・修正

### 6. バランスを確認
- 3行要約 → 思い出しやすい？
- 詳細ノート → 短すぎ／長すぎない？
- 問題あれば `_NotebookLMプロンプト.md` を一緒に直す

### 7. 完了したら
- `_index.md` の001行の「状態」を `完了` に変更
