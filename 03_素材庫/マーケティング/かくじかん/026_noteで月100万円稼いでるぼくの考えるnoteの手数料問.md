# noteで月100万円稼いでるぼくの考えるnoteの手数料問題。みんなnoteを使うべきか？

noteで月100万円稼いでるぼくの考えるnoteの手数料問題。みんなnoteを使うべきか？
【第1部：3行で思い出す要約】
テーマ：noteの決済手数料・プラットフォーム利用料（約15%）を「高い」と切り捨てるか、価値ある投資と捉えるかの判断基準。
結論：noteを単なる「ツール」ではなく「ビジネスパートナー」と定義し、手数料を「共に価値を作るための対価」と解釈することで、運営との連携や信頼獲得という利益以上のリターンを得る。
自分への使いどころ：自前決済（手数料3%）でコストを削る道よりも、プラットフォーム側に「貴重な成功サンプル」として認知されるまで使い倒し、講演機会や機能改善提案などの共創チャンスを掴み取る。
【第2部：詳細ナレッジベース（構造化詳細ノート）】
1. noteの具体的な手数料構造
多くのユーザーが「高い」と感じがちなnoteの手数料について、著者が実数値を挙げて整理しています。
決済手数料と利用料の内訳
クレジットカード決済：売上の5%
プラットフォーム利用料：
有料記事、有料マガジン、メンバーシップ、サポート：10%
定期購読マガジン：20%
振込手数料：270円
具体的な支払いシミュレーション
500円のメンバーシップをカード決済で販売した場合、合計15%（75円）が差し引かれる。
売上が月50万円なら手数料は約7万5,000円。
売上が月100万円なら手数料は15万円となり、手元に残るのは85万円（利益率85%）。
数字
合計手数料率：約15%（定期購読マガジン以外）
利益率：約85%
ポイント
利益率85%という数字自体は、ビジネスとして見れば「めちゃくちゃ良い」部類に入る。
2. 「15% vs 3%」の捉え方とパートナーシップの思想
自前で決済システム（Square等）を組めば手数料は3%程度に抑えられますが、著者はその「差額12%」にこそ意味があると言います。
プラットフォーマーかパートナーか
単なる「場貸し」と考えると15%は高く、0%に近い方が良いという発想になる。
「一緒に仕事をしているパートナー」と考えれば、相手にもしっかり稼いでもらいたいという心理に変わる。
コストではなく「外注費」としての解釈
年間1,000万円の売上のうち、150万円をパートナーに支払うのは「ビジネスとして普通」のことである。
自分が850万円を得て、相手に150万円払う関係性を「心地よい」と感じられるかが重要。
「ビジネスパートナーとして、ま、一緒に価値に行ってる存在だとしたら、むしろちょっと考え方が変わってきたりしませんか」
注意点
手数料の安さだけでプラットフォームを移動すると、noteが提供している「創作を続けさせるための文化や仕組み」という目に見えない価値を失うリスクがある。
3. トップクリエイターとしての戦略的メリット
一定以上の売上を上げ、手数料を支払い続けることで生まれる「運営側との関係性」について。
貴重なサンプルとしての価値
メンバーシップで1,000人を超えるクリエイターは極めて稀である（アイドルや有名人を除けばほとんどいない）。
2〜3ヶ月で1,000人に到達した著者のようなデータは、note社にとって「他のクリエイターを支援するための貴重なサンプル情報」になる。
運営との共創チャンス
実際にnoteの中の人から連絡が来るようになり、以下のような可能性が生まれる。
note社企画の講演会への登壇
メンバーシップ機能の改善提案（どのようなデータがあれば運営しやすいか等）
新機能の先行テストや分析への参加
例
著者は、自分が使い込んでいるからこそ分かる「メンバーシップ運営を改善するための施策」をnote社に提案できる立場を目指している。
4. noteへの「恩返し」と勝利へのコミットメント
著者は、自分が稼ぐこととnote社の成長をリンクさせるマインドセットを提唱しています。
無償時代からの感謝
稼げるようになる前から、面白い記事を読ませてもらったり、初めてフィクションを書く場を与えられたりしてきた恩がある。
「勝たせる」マインド
手数料を嫌々払うのではなく、「俺たちがnoteの売上を上げ、株価も上げてやる」という勢いで取り組む。
「ビジネスパートナーに15%しか払えていないことをむしろ悔め」というほどの強い当事者意識。
「そんぐらいの気持ちで、もうノートを勝たせに行くみたいな気持ちで一緒にこのノートに関われたら、ええんちゃうかなと」
ポイント
noteを使って、単なる金銭的メリットだけでなく「内面を覗く心地よさ」などの精神的価値も発信していく。
