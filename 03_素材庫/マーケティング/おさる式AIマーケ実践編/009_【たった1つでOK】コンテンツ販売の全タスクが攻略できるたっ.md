### 1. AIを使いこなせない根本原因
- AIを正しく使いこなせていない人が多く、ChatGPTやGeminiなどを利用しても「なんか微妙だ」と感じることが少なくない。
- AIが使えないのではなく、ユーザーの「指示の出し方」に改善点があることが根本原因である。
- AIの出力の精度は、ユーザーがAIに与える指示文、つまり「プロンプト」のうまさに完全に依存している。
- プロンプトの質が低ければ、どんなに高性能なAIでも期待するような出力は得られない。
- 複雑なプロンプトの記述方法を学ぶ必要はないという点が強調されている。
- 役割指定、ハッシュタグを用いた出力形式設計、制約条件の追加など、一見難しそうなプロンプトエンジニアリングの知識は不要である。
- 今回紹介する「たった1つのプロンプトの方」さえ知っていれば、全てのタスクでAIの最高出力を引き出すことが可能になる。
- このプロンプトの型を活用することで、YouTube台本、セールススライド、SNS投稿、LINE配信文など、コンテンツ販売に必要なほぼ全てのタスクが攻略できる。
**ポイント**
- AIの出力精度はプロンプトの質に直結する。
- 複雑なプロンプトエンジニアリングの知識は必ずしも必要ではない。
- 今回のプロンプトはコンテンツ販売の多岐にわたるタスクに対応可能。
**例**
- おさる氏の実績として以下の事例が挙げられている。
- AI本格導入後、口座運営をしながら毎月120本以上の動画投稿。
- 9万文字超えの英語YouTube台本をワンクリックで出力。
- AI駆動でX（旧Twitter）を運用し、月間940万インプレッションを達成。

### 2. AIがうまく使えない人の共通点：背景情報のずれ
- AIをうまく使いこなせない人の9割が陥っている原因は「人間とAIの間で背景情報がずれている」ことである。
- 「背景情報」とは、お互いが持っている前後の文脈や共通の知識を指す。
- 業界ではこの背景情報のことを「コンテキスト」と呼ぶ。
- 具体例として、人間同士の会話で背景情報がずれている場合を挙げて説明。
- 「昨日のおさるのお昼ご飯は何だと思いますか？」と急に聞かれても、背景情報がないため誰も答えられない。
- しかし、毎日一緒にご飯を食べている奥さんであれば、背景情報が揃っているため答えられる。
- AIとの会話でも全く同じ現象が起きている。
- 例1：YouTube台本の作成を依頼しても、AIは動画の目的、ターゲット、ゴールを何も知らないため、ぼんやりとした台本しか出てこない。
- 例2：セールスページの作成を依頼しても、売りたい商品の詳細、ターゲットの悩みなどを伝えていないと、顧客に刺さるページは出てこない。
- 例3：SNS投稿を作成させても、ユーザーの普段の口調や文体をAIが知らないため、「自分が書きそうな文章じゃない」という出力になるのは当然。
**ポイント**
- AIがうまく使えない根本原因はツールの性能ではなく、「情報の渡し方」にある。
- AIに十分な背景情報（コンテキスト）を与えなければ、期待する高精度の出力は得られない。
- 具体的な目的、ターゲット、文脈などをAIに明確に伝える必要がある。
**注意点**
- AIの性能が高いからといって、漠然とした指示で高精度な出力が得られるわけではない。
- AIに「知っていて当然」という前提で情報を与えないこと。

### 3. ゴールシークプロンプトとは
- AIに背景情報を正しく渡す方法として、「ゴールシークプロンプト」が紹介されている。
- ゴールシークプロンプトの定義は以下の通りである。
> AIに自分が達成したいゴールだけを伝えて、そのゴールを達成するために足りない情報を全部AI側に質問させる。
- ユーザーがやるべきことは、たった2つだけである。
1.  ゴールを伝える。

### 2. AIからの質問に答える。
- この手法は非常にシンプルでありながら強力であると説明されている。
**ポイント**
- ユーザーは「ゴール」を明確にすることに集中し、情報の洗い出しはAIに任せる。
- AIとの対話を通じて、必要な背景情報を漏れなく共有する仕組みである。

### 4. ゴールシークプロンプトの2つの強み
- ゴールシークプロンプトが最強とされる理由は2つある。
**ポイント**
- **1. 背景情報が半自動で揃うこと**
- AIとの間で背景情報がずれていると微妙な出力しか得られないが、ゴールシークプロンプトを使えば、AI側がゴール達成に必要な情報を全て洗い出し、質問してくれる。
- これにより「何を伝えればいいか分からない」というユーザー側の問題自体が解消される。
- ユーザーは聞かれたことに答えるだけで、必要な背景情報が自動的に揃っていく。
- **2. 初心者でも簡単に求めている出力を得られること**
- プロンプトエンジニアリングの専門知識が全くなくても問題ない。
- マーケティングの専門知識がなくても問題なく活用できる。
- AIとの対話を進めるだけで、情報を漏れなく共有できるため、自分が本当に欲しい出力を容易に得られる。

### 5. 従来のプロンプトとゴールシークプロンプトの比較
- 従来のプロンプト作成手法とゴールシークプロンプトの決定的な違いが整理されている。

**比較**
| 従来のやり方 | ゴールシークプロンプト |
|--------------------------------------------|--------------------------------------------|
| - 役割設定、前提条件記述、出力形式設計、制約条件の全てを自分で決めなければならない。 | - 達成したいゴールだけをAIに伝える。 |
| - 知識（プロンプトエンジニアリング、マーケティングなど）が必要。 | - 足りない情報はAIに質問させる。 |
| - 情報の抜け漏れが出やすい。 | - 知識は不要。 |
| | - 情報の抜け漏れはゼロ。 |

- この違いは、一度体験すればはっきりと実感できると強調されている。
**ポイント**
- 従来のプロンプトはユーザー側の知識と労力に依存する。
- ゴールシークプロンプトはAIの質問能力を最大限に活用し、ユーザーの負担を軽減する。

### 6. ゴールシークプロンプトの使い方：全体像
- ゴールシークプロンプトの使い方は、たった1つのシンプルなステップで構成される。
**手順**
1.  **AIにゴールを伝える**: まず、自分が達成したい具体的なゴールをAIに明確に伝える。
2.  **ゴールシークプロンプトを入力**: 次に、特定のプロンプト文をAIに入力し、質問を促す。
3.  **AIから質問が来る**: プロンプト入力後、AIがゴール達成に必要な情報を洗い出し、質問を投げかけてくる。
4.  **質問に答える**: AIからの質問に対して、簡潔に回答する。
5.  **出力が完成**: 全ての質問に答え終わると、AIが完全に情報を理解し、高精度の出力を作成する。
**ポイント**
- 非常に直感的で分かりやすい5ステップ。
- 各ステップがシンプルに設計されており、初心者でも迷わずに実行できる。

### 7. ステップ1：AIにゴールを伝える
- ゴールシークプロンプトの最初のステップは、AIに自分が達成したいゴールを伝えることである。
- ここで最も重要なのは「ゴールの解像度を上げること」。
- 例えば、「YouTube台本作って」という指示は解像度が低すぎる。
- どの「どんな動画を作りたいのか」「どんな動線で最終的に何に繋げたいのか」といった具体的な情報を伝える必要がある。
**例**
- 高解像度なゴールの伝え方：
> この動画を参考にして演者を自分に変えた形でYouTube台本を作りたいです。YouTubeで価値提供して視聴維持率を伸ばしたい。そして動画の最後にLINEに誘導して最終的に口座に入会してもらう。このゴールを達成したいです。
- このように、自分が最終的にどうなりたいかという、目的の全体像と最終的な成果までをAIに明確に伝える。
**ポイント**
- ゴールは単なるタスク指示ではなく、そのタスクによって達成したいビジネス上の目的やユーザーの行動変容まで含める。
- ゴールの具体性が、後のAIからの質問の質と最終出力の精度に大きく影響する。

### 8. ステップ2：ゴールシークプロンプトを入力する
- AIにゴールを伝えた後、次のステップは「ゴールシークプロンプト」を入力することである。
- このプロンプトは非常にシンプルで、たったこれだけである。
**例**
- ゴールシークプロンプトの具体的な書き方：
`このゴールを必ず達成するために現状足りない情報を全て私に質問してください。`
- この一文をAIに加えるだけで、AIの挙動が劇的に変化する。
- 通常の指示では、AIは「はい、台本作りました」といきなりそれっぽい出力を返してくることがある。
- しかし、ゴールシークプロンプトを使うと、AIはすぐに出力するのではなく、「まず〇〇について教えてください」と、ユーザーに質問を投げかけるようになる。
- これが、AIが背景情報を自動で収集する重要なポイントである。
**ポイント**
- プロンプトの具体的な文言は上記の一文のみで、特別な呪文や複雑な構文は不要。
- このプロンプトがAIの思考プロセスを「質問モード」に切り替えるトリガーとなる。

### 9. ステップ3：AIからの質問が来る
- ゴールシークプロンプトを入力すると、AIはユーザーが達成したいゴールに対して、必要な情報を全て洗い出して質問してくるようになる。
- 実際のデモ画面では、以下のような質問が例として提示されている。
**例**
- AIからの質問内容の具体例：
- 動画タイトルの方向性はどんな感じにしますか？
- どんな人に見て欲しいですか？（ターゲット層）
- この動画を見終わった視聴者はどういう状態になりますか？（視聴者のゴール）
- 動画の長さはどのくらいを想定していますか？
- どのような口調やトーンで話しますか？
- 競合となるYouTube動画はありますか？
- 最終的なLINE誘導で、具体的にどのような情報を提供しますか？
- 口座の概要や価格帯を教えてください。
- AIはユーザー自身では思いつかなかったような観点からも質問を投げかけてくる。
- これにより、ステップ2で説明した「背景情報のずれ」が、AIからの質問に答えていくだけで全て埋まっていく。
- 結果として、情報の抜け漏れが起きにくくなる。
**ポイント**
- AIはユーザーのゴール達成に必要な情報を多角的に分析し、網羅的に質問を生成する。
- ユーザーはAIの質問に答えることで、無意識のうちに不足していた情報を補完できる。

### 10. ステップ4：AIからの質問に答える
- AIから質問が届いたら、次のステップはそれらの質問に答えていくことである。
- ここも難しく考える必要はなく、完璧な文章で答える必要はないと説明されている。
- 箇条書きで簡潔に、サクッと答えるだけで十分である。
**例**
- AIからの質問に対する回答例：
- **ターゲット**: 30歳から45歳の地方在住の主婦。
- **悩み**: 何から始めればいいか分からない、文章が作れない。
- **口座の価格帯**: 30万円がライトプラン、50万円が標準プラン、70万円が個別相談付き。
- **想定投稿時間**: 20分から25分。
- **投稿頻度**: 週1回。
- このように、聞かれたことに対して素直に答えるだけで良い。
**ポイント**
- 回答は自然言語処理のAIが理解できるレベルであればよく、表現の洗練度は求められない。
- 箇条書きは情報を整理しやすく、AIにとっても処理しやすい形式である。

### 11. ステP5：出力が完成する
- 全ての質問に答え終わると、AIは必要な情報を完全に理解した状態となる。
- ここまで来たら、あとは具体的なコンテンツ作成作業をAIに任せるだけである。
- 完成した出力は、従来の漠然とした指示で得られるものとは比較にならないほどの精度を持っている。
**ポイント**
- AIは、ユーザーが提供した詳細な背景情報に基づいて、具体的なアウトプットを生成する。
- 出力されたコンテンツは以下の特徴を持つ。
- 誰にでも当てはまるぼんやりした内容ではない。
- 明確にターゲットの悩みに刺さる内容になっている。
- 動画の最後にLINEに誘導し、最終的に口座に入会させるという導線設計まで組み込まれている。
- 実用レベルの台本が一撃で出てくる。
- この精度の高さを体験することで、AI活用の認識が大きく変わると述べられている。

### 12. ゴールシークプロンプトの核心と汎用性
- ゴールシークプロンプトの最も重要な核心は「背景情報を揃える」ことにある。
- このプロンプトは非常に汎用性が高く、コンテンツ販売における多岐にわたるタスクに対応可能である。
**ポイント**
- **ゴールの変化に応じた柔軟性**:
- 設定するゴールが変われば、AIからの質問内容も当然変化する。
- その結果、最終的に出てくる出力も、それぞれのゴールに最適化されたものになる。
- 例えば、YouTube台本を作りたい場合は台本に最適化された質問が来る。
- セールスページを作りたい場合は、セールスに必要な情報を質問してくる。
- **全コンテンツ対応**:
- LINE配信文、特典資料、SNS投稿など、あらゆる種類のコンテンツ作成にこの「たった1つの型」で対応できる。
- これが「全コンテンツ対応」と呼ばれる理由である。

- 動画の内容が簡潔にまとめられ、視聴者への行動喚起が行われている。
