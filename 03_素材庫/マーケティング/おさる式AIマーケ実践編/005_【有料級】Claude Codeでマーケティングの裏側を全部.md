### 2. Claude Codeの正体：ChatGPTとの決定的な違い
- 多くの人がChatGPTとClaude Codeを「どっちもAI」と考えているが、全く異なるツールであることを解説。
- 両者とも「AI社員」であると例え、数千円から数万円で無限に働いてくれる社員と位置づける。

**比較表**
| 項目      | ChatGPT (アドバイザー社員)             | Claude Code (実務社員)                         |
| :-------- | :------------------------------------- | :--------------------------------------------- |
| 役割      | 質問応答、文章作成、アイデア出し、提案   | ファイル読み込み、コード記述、テスト、エラー修正、完成品引き渡し |
| 具体例    | 家の間取りの提案書を作成する           | 指示された場所に家を実際に建てて引き渡す         |
| マーケティング適用例（LP作成） | 「良いLPはこうです」とコードを出力するだけ。自分でコピペして調整が必要。 | 実際にLPファイルを作成し、デザインを整え、ブラウザで見れる状態まで完成させる。修正指示も日本語で可能。 |
| コスト削減 | 間接的（アイデア創出による効率化）       | 直接的（LP外注費30万～50万円が月額3000円程度に） |
**ポイント**
- ChatGPTは「相談役」であり、実際の作業は人間が手を動かす必要がある。
- Claude Codeは「施工担当」であり、指示されたものを形にして納品する。
- LP制作を例にとると、Claude Codeはコード出力だけでなく、ファイルの生成、デザイン調整、ブラウザでの確認までを自動で行うため、非エンジニアでも実用的な成果物を短時間で得られる。

### 3. ステップ1：Claude Codeの招待を理解する
- Claude Codeを使い始めるにあたり、その基本的な「正体」と「役割」を理解することが最初のステップ。
- 従来のプログラマー向けツールという認識は誤りであり、マーケティング実務に深く関わるツールであることを認識する。
**注意点**
- Claude Codeは単なるコード生成ツールではなく、指示に基づいて具体的なファイル構造と機能を構築し、動く状態まで持っていく「実行者」としての側面を持つ。

### 4. ステップ2：LPを一撃で構築する
- LP（ランディングページ）の構築は、Claude Codeを使えば非エンジニアでも実現可能。
- 特にコンテンツ販売の初期段階におけるLPの叩き台作成において、Claude Codeは強力な武器となる。
**手順**

### 1. Claude CodeにLP作成を指示する際に、以下の3つの情報を明確に伝える。

### 1. **誰に向けたサービスか**
2.  **何が手に入るか**
3.  **いくらか**

### 2. 以下のプロンプト例を参考に、具体的な指示を日本語で入力する。
-   「30歳から45歳の主婦向けにAI活用の入門講座のLPを作ってください。」
-   「講座の特徴は3つ。完全未経験からでもAIを使いこなせる。1日30分の実践で副収入の柱を作れる。専任コーチが3ヶ月間サポート。」
-   「デザインはシンプルで清潔感のある配色でお願いします。」
-   「ファーストビューに体験者の声を3つ入れてください。」
-   「スマートフォンで見た時に崩れないように調整してください。」

### 3. Claude Codeは指示を受け取り、HTMLファイル、CSSファイル、画像の配置まで全て自動で作成し、ブラウザで確認できる状態にする。

### 4. 修正が必要な場合は、日本語で具体的に指示するだけで対応可能。
-   「ヘッダーの色をネイビーに変えて。」
-   「お客様の声のセクションを下に追加して。」
-   「スマホで見た時に文字が小さすぎるから大きくして。」
**ポイント**
- たったこれだけの情報で、スマホ対応済み、デザイン調整済みのLPが約10分で完成する。
- 修正にかかる追加費用はゼロで、即座に反映される。

### 5. LP作成における人間の役割：売れる「中身」の重要性
- Claude CodeはLPの「見た目」を作るが、「売れるLPの中身」を書くのは人間の仕事。
- AIに全てを任せると、当たり障りのない文章になってしまい、顧客に刺さらないLPになる。
**ポイント**
- 「一時情報」が非常に重要。顧客の生の声をLPに反映させる必要がある。
- LPに渡すべき情報は以下の3つ。
-   **お客さんが実際に口にした言葉:** 例：保育勉強したい人の本音は「会議で恥をかきたくない」だった。
-   **お客さんがどこでつまづいているか:** 例：教材を買っても3日で挫折する、申し込みボタン直前で迷ってやめる。
-   **お客さんが買う前に抱える不安:** 例：自分でもできるかな？ 家族に怪しまれないかな？
**例**
- 英語事業の経験談として、TOEICのアンケートで「会議で外国人の上司に反応できなくて悔しい」という顧客の本音を聞き出した結果、LPの見出しを「TOEIC 900点突破」ではなく「会議で外国人の上司の前で恥をかきたくないあなたへ」に変更し、顧客に深く刺さるLPができた。
**注意点**
- Claude CodeでLPを作る前に、最初の3人程度の顧客にヒアリングを行い、生の言葉、つまづく場所、買う前の不安をメモにまとめることが必須。
- コンテンツ販売を始める際は、商品を作る時間を半分に減らし、顧客の声を聞く時間を倍にすることで、半年後の売上が大きく変わる。

### 6. ステップ3：決済導線を最短で構築する
- LPが完成しても、決済導線がなければ売上はゼロ。
- 申し込みボタンから決済完了までの導線をいかにスムーズにするかが重要。
**ポイント**
- 申し込みから決済完了までのクリック数は「3回以内」にすること。これ以上増えると離脱率が跳ね上がる。
- 決済導線のクリック数を4回から2回に減らしただけで、制約率が1.5倍になった事例もある。

**決済ツールの選択肢**
| タイプ   | ツール名                                | 特徴・注意点                                  |
| :------- | :-------------------------------------- | :-------------------------------------------- |
| 低単価   | Stripe, PayPal                          | 一時的な利用は可能だが、アカウント凍結リスクあり。 |
| 高単価・推奨 | UNIVA Pay, ロボットペイメント, テレコムクレジット | 低単価でも利用可能で、凍結リスクが低い。分割払い対応など高機能。 |
**例**
- 講演者はUNIVA Payを推奨し、提携しているため受講者はスムーズに決済構築が可能。

**プロンプト例（決済導線をLPに組み込む）**
- 「先ほど作ったLPに決済リンクを組み込んでください。」
- 「メインプランとサブプランの2つのボタンを設置。」
- 「ボタンを押したら決済ページに直接飛ぶようにしてください。」
- 「決済完了後はサンキューページに遷移させてください。」
- 「サンキューページには次の一歩としてLINE登録のQRコードを表示してください。」
**ポイント**
- これだけの指示で、LP、決済ボタン、決済ページ、サンキューページ、LINE登録誘導という全体の導線が30分で完成する。

### 7. 決済完了後の次のアクションと3Qページ設計
- 多くの人が決済完了をゴールにしてしまうが、決済完了は単なる「通過点」。
- 決済完了後も必ず次のステップへ誘導することが重要（例：LINE登録、講座ログイン画面）。ここで離脱させると次のオファーに繋がるチャンスが消える。

**3Qページに入れるべき5つの要素**
1.  **ありがとうございます + 次にすべきこと3ステップ:** 購入直後のモチベーションが高い瞬間に、何をすれば良いか具体的かつ簡潔に（3行程度で）指示する。
2.  **LINE登録のQRコード:** 購入者限定の特典や、今後の連絡先はLINEで届く旨を添える。
3.  **会員サイトへのLogin URL:** URLが未定の場合は「ここに会員サイトURLを入れる」といったプレースホルダーで良い。
4.  **購入確認メールが届くことの案内:** 「15分以内にご登録のメールに確認メールが届きます」と明記し、届かない場合の連絡先も記載する。
5.  **よくある初回Q&A:** 「教材はどこから見れますか？」「Zoomリンクはどこですか？」など、頻出する質問とその回答を置いておくことで、問い合わせを激減させる。

**プロンプト例（3Qページ作成）**
- 上記5つの要素を箇条書きでClaude Codeに渡すだけで、3Qページを構築できる。

### 8. 決済システムの役割分担とテスト決済の重要性
- Claude Codeと外部決済ツール・顧客管理ツールの役割分担を理解することが重要。

**役割分担表**
| 担当             | 役割（動画での説明どおり）                               |
| :--------------- | :------------------------------------------------------- |
| Claude Code      | LP、決済ボタン、決済ページ、3Qページの「入り口の設計」 |
| 宴、Stripe, UNIVA Pay | 実際の決済処理、顧客管理、自動配信、裏側の処理とデータ管理 |
**注意点**
- Claude Codeだけで全てをやろうとすると詰まるため、この役割分担を最初に理解しておく必要がある。
**手順**

### 1. **本番公開前のテスト決済を必ず実施する。**
-   自分でテストカードを使って実際に購入操作を行い、導線が全て繋がっているかを確認する。
-   よくある失敗パターン：3QページのURLが404エラーになる、LINE登録のQRが読み込めない、確認メールが迷惑メールに入ってしまう、スマホで見たら決済ボタンが半分切れる。
-   これらは全てテスト決済で発見できるものであり、本番後に発覚すると入金済みのお客さんが困惑する最悪の事態になる。
**ポイント**
- 講演者の事業では、高単価商品はUNIVA Payで受け、分割払い対応やクレジット審査に対応。
- 宴と連携させ、決済完了と同時に受講メール、会員登録、LINE連携が一気に動くように自動化している。
- 顧客が決済を完了させた瞬間から、何もしなくても次のステップへ進む状態を構築することが理想。

### 9. ステップ4：購入後のフォローアップを全自動化する
- 決済完了後も、サンキューメールやコンテンツ受け取り方法の案内を自動化しなければ、受講生が増えるにつれて手動対応が破綻する。
- 自動配信の仕組みが必須となる。
**ポイント**
- サンキューメール1通だけで終わらせるのは不十分。
- 購入直後の数日間は顧客のモチベーションが最も高い「ゴールデンタイム」。この期間に成功体験を一つ作らせることで、最後まで学び続けてくれる確率が大幅に向上する。
- 講演者が実践しているフォローアップ設計例（動画内提示）のような多段階のフォローアップを全自動で構築できるのがClaude Code。
**注意点**
- メールのテンプレートは「URL穴埋め形式」で組む。
-   会員サイトのURLや講座リンクなど、後から実際の値に差し替えることを前提に、本文中に「ここに会員サイトURLを後で入れる」のようなプレースホルダーを入れて作成する。
-   Claude Codeにも「URLを穴埋め式で出してください」と指示する。
-   これにより、構築タイミングと文章作成タイミングを切り離せるため、商品リンクや会員サイトURLが後から決まってもメール本文を作り直す必要がなくなる。

**役割分担**
- Claude Codeが担うのは「自動配信の仕組みを構築」すること。
- メールを送ること自体は「宴」などの配信ツールが担う。
- Claude Codeは配信ツールのAPIと連携するコードを書き、「この条件の時にこのメールを送る」という仕組みを構築する「実務社員」。
- Claude Codeだけで全て完結すると思ってしまうと痛い目を見る。

### 10. 自動配信におけるAIと人間の役割分担
- 講演者自身も事業開始当初はサンキューメールやフォローメールを手動で送っていたが、受講生が増えるにつれてメール対応だけで一日が終わるようになり、自動化の必要性を痛感した経験がある。
- Claude Codeがあれば、最初から自動化の仕組みを構築でき、受講生が3人でも1万人でも同じ仕組みで回せる。
**注意点**
- **絶対にAIに任せてはいけない領域:** 受講生からの質問への「直接回答」。
- 質問対応をAIに任せた瞬間、顧客からの「お猿さんが直接見てくれる」という信頼の貯金が消える。
- 講演者は自分の受講生からの質問は必ず自分で返している。
- > 「AIに任せるのは裏側の作業だけ。お客さんとの接点だけは絶対に人間。ここを間違えるとマジでやばいので覚えて帰ってください。」

### 11. ステップ5：会員サイトの試作版を一撃で形にする
- コンテンツ販売では、購入者専用の会員サイトが必須。
- 会員サイトの本質は、動画やPDFを置いておく場所であるだけでなく、「お客さんが学ぶ場所」であり、もっと言えば「お客さんから繰り返し聞かれる質問への答えをいつでも見れる形で置いておく場所」である。
- 従来の会員サイト構築には、月額プラットフォーム費用と初期構築の外注費で年間50万円以上かかることも珍しくなかった。
- Claude Codeを使えば、ログイン機能付きの会員サイトを日本語の指示だけで構築できる。

**プロンプト例（会員サイト作成）**
- 「ログイン機能付きの会員サイトを作成してください。」
- 「動画コンテンツとPDF資料をアップロードできるセクションを設けてください。」
- 「シンプルで見やすいデザインでお願いします。」
- 「スマートフォンでの表示にも対応してください。」
**注意点**
- 大規模な会員サイトの本格運用には、セキュリティやサーバーの問題から「宴」などのプラットフォームを使うのが正解。
- しかし、Claude Codeで試作版を構築することで、「こういう会員サイトを作りたい」というイメージを具体的に形にできる。
**ポイント**
- 試作版を事前に作成することは、外注先やエンジニアとの「認識のずれをゼロにする」上で非常に強力なツールとなる。
- 口頭で説明しても、100人中100人が異なるイメージを持つ可能性があるが、試作版があれば「これを本番で再現してください」と渡すだけで済むため、手戻りがなくなる。

### 12. 会員サイト構築における人間の役割：顧客満足度向上
- 会員サイト構築において、講演者が最もこだわっている点は「お客さんが個別相談で何度も聞いてきた質問を全てコンテンツ化して置いておく」こと。
**ポイント**
- 個別相談で繰り返し答える質問は、それだけ多くの人がつまずいているポイントだから。
- これを会員サイトに置いておくことで、お客さんは困った時にいつでも見に行ける状態になる。
- これにより、サポート対応の負荷が下がり、顧客満足度も向上するという一石二鳥の効果がある。
**手順**

### 1. コンテンツ販売を始めたばかりの場合、最初から大規模な会員サイトを作る必要はない。

### 2. 最初の3人程度の顧客からよく聞かれた質問を5本のコンテンツにまとめることから始める。

### 3. Claude Codeで試作版を構築し、自分で答えた内容を順番に置いていく。
**ポイント**
- これだけで「ちゃんと用意されている感」が出て、顧客の満足度が大幅に向上する。

### 13. 全体ロードマップとAI活用の本質
- 今回解説した5つのステップ（Claude Codeの招待理解、LP構築、決済導線構築、自動配信構築、会員サイト構築）を一つずつ確認し、進めていく。
**注意点**
- 「Claude Codeを入れれば誰でも稼げる」という都合の良い話は存在しない。
- 完全自動化は不可能であり、薄っぺらいノウハウで稼げるほどビジネスは甘くない。
- Claude Codeはあくまで「パーツを作る実務社員」。
**ポイント**
- 人間がやるべき仕事は、どこにどんな家を建てるか、誰のためにどんな間取りにするかといった「設計」の部分。
- 具体的には、ターゲットの選定、コンセプトの設計、導線の設計、メッセージの設計。
- AIに作業を任せることで、人間は「考える仕事」に集中すべきである。
- マーケティングというスポーツで本気で勝ちたいなら、最高のバット（Claude Code）やグローブ（各種AIツール）を手に入れただけでは不十分。
- 試合全体のルール（マーケティング術）を理解していなければ、どんなに良い道具を持っても勝てない。
