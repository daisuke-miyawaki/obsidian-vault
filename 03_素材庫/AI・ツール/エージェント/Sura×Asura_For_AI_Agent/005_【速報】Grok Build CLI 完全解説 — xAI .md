**ポイント**

### 2. 「プランモード」による実行前の詳細な工程管理
Grok Buildの最も目立つ特徴の一つであり、デフォルトで「オン」に設定されている
クロード・コード等では明示的な切り替えが必要なプランニング機能を、標準フローとして組み込んでいる
AIが実際にコードを編集する前に、どのファイルをどの順番で作成・編集するかという計画を可視化する
実行前にステップごとの工程がすべて表示されるため、人間による事前レビューが可能である
表示された計画は、個別のステップを編集、削除、または順番の入れ替えを行うことができる
「まずテストコードを書いてから実装に移ってほしい」といった指示を計画段階で差し込める
計画に対するフィードバックを即座に反映し、修正されたプランで再スタートできる柔軟性を持つ
意図しない大規模なコード変更を未然に防ぐためのセーフティネットとして機能する
**手順**
ターミナルからタスクを指示する
AIが自動的に「プラン（実行計画）」を生成し表示する
必要に応じてステップの編集や順序変更を行う
計画を承認し、実行を開始させる
**ポイント**
デフォルトでのプラン提示による「予測可能性」の向上
実行前のステップ単位での細かなカスタマイズ性
TDD（テスト駆動開発）のような開発手法の強制が可能
**注意点**
計画が複雑すぎる場合、人間がレビューするコストが増大する懸念がある
プランニング自体にもトークンを消費するため、効率的な指示が求められる

### 3. 最大8つの「並列サブエージェント」による分散作業
最大8つのサブエージェントを同時に稼働させることができる画期的なアーキテクチャを採用している
各エージェントは独立した「Git Worktree」で作業するため、互いの変更が物理的に干渉しない
ブランチも作業ディレクトリも完全に別個の状態で並列処理が行われる
例えば「バグの原因究明」を依頼すると、複数のエージェントが異なる切り口で調査を開始する
あるエージェントは最近のデプロイ履歴を、別のは遅延エンドポイントを、別のはスロークエリを調査するといった分担が可能である
キャッシュヒット率のチェックなど、多角的な分析を同時並行で進められる
各サブエージェントの調査結果は、最終的にメインエージェントが統合・集約する
この設計により、複雑な問題解決の速度が劇的に向上する
**例**
1つのエージェント：APIのレスポンスログの解析
2つのエージェント：データベースのインデックス状況の確認
3つのエージェント：フロントエンドのレンダリング負荷の調査
**ポイント**
Git Worktree活用による物理的な作業分離
競合（コンフリクト）を恐れずに複数箇所を同時調査・修正可能
複雑なデバッグ作業の圧倒的なスピードアップ
**注意点**
同時稼働させるエージェント数が増えると、APIコストが急増する可能性がある
統合（マージ）の段階でメインエージェントの判断力が試される

### 4. 実装コンペを実現する「アリーナモード」の構想
「アリーナモード」と呼ばれる新機能が予告されており、現在はカミングスーン（近日公開）の状態である

**ポイント**
複数アプローチの同時試行と自動評価

### 5. MCP/ACP等の広範なエコシステムへの対応
Anthropicが推進するオープンプロトコル「MCP（Model Context Protocol）」に標準対応している
さらに、マルチエージェント間の調整プロトコルである「ACP（Agent Coordination Protocol）」にフル対応している点が注目される
agents.md を読み込むことで、既存リポジトリの規約やコンテキストを即座に理解する
スキル（Skills）やプラグイン（Plugins）による機能拡張もサポートされている
レガシーなプロジェクトや独自のルールを持つコードベースへの適応力が高い
他のAIツールや外部データソースとの連携が容易な設計になっている
オープンな標準規格を採用することで、ベンダーロックインを避けつつエコシステムの恩恵を受けられる
開発チーム全体でのナレッジ共有やツール共有がスムーズに行える
用語・プロトコル対応表
MCP: Model Context Protocol（コンテキスト共有）
ACP: Agent Coordination Protocol（エージェント間連携）
agents.md: プロジェクト規約の記述ファイル
**ポイント**
特定のAIモデルに依存しないオープンプロトコルの重視
agents.md によるプロジェクト固有ルールの即時注入
拡張性の高いプラグインシステム

### 6. 「ヘッドレスモード」による自動化・CI/CD連携
対話なしでバッチ実行が可能な「ヘッドレスモード」を搭載している
コマンド例として grok -ttr "security review" のように、特定のタスクを投げっぱなしにできる
人間がターミナルの前で待機する必要がなく、バックグラウンドでの重い処理に適している
CI/CDパイプラインに組み込むことで、プルリクエストに対する自動セキュリティレビューなどが実現できる
定期的なコードベースのスキャンや、ドキュメントの自動更新といった運用タスクにも活用可能である
開発フローの自動化（オートメーション）に直接載せられるため、実用性が極めて高い
ログ出力なども構造化されており、他のツールとの連携が考慮されている
大規模プロジェクトにおける品質管理の自動化を強力に支援する
**例**
grok --headless "refactor old modules"
grok -ttr "run tests and fix failures"
**ポイント**
非対話型実行による「投げっぱなし」開発
CI/CDパイプラインへの統合の容易さ
定常的なメンテナンス・レビュー業務の自動化
**注意点**
ヘッドレス実行中にAIが暴走しないよう、適切な制約やテスト環境が必要
実行結果の確認方法を確立しておく必要がある

### 11. 競合（Claude Code/Codex CLI）との詳細な比較分析

ワークフローの思想も異なり、Claudeは「慎重派（確認しながら進む）」、Grokは「自律派（走りながら見せる）」である

成熟度ではClaude Codeが先行しており、既に本番のCI/CDに組み込んでいるチームも多い
Grokはまだベータ版であり、エラーハンドリングの甘さが見られる場面もある
料金体系はxAIが「企業・チーム」を、AnthropicやCodexが「個人〜プロ」を主戦場としている

速度：Grok Build > Claude Code
慎重さ：Claude Code > Grok Build
巨大コードへの対応：Claude Code > Grok Build
価格：Grok Build（企業向け高額設定）

### 12. プロンプト流出から判明した内部アーキテクチャの全貌
セキュリティ研究者がバイナリーを調査したところ、30以上のシステムプロンプトが抽出されてしまった
プロンプトは暗号化されず「平文」で同梱されており、xAIのオープン（あるいは無頓着）な姿勢が話題となった
抽出された内容から、メインエージェントの指示内容やオーケストレーターの構造が判明した
メモリーシステムが非常に凝っており、SQLの「FTS5（全文検索）」と「ベクトル検索」を組み合わせている
セッションを跨いで学習内容を保持する「永続メモリー」の仕組みが実装されている
410個の依存関係、80個以上の環境変数フラグなど、ツールの巨大な構成が明らかになった
一部のツール説明文がClaude Codeの文言と酷似していることが指摘され、論争となった
xAIの開発陣はこれらの指摘に対し、日々のバグ修正と機能追加で応えている
判明した技術要素
検索エンジン：SQL FTS5 + Vector Search
構成：410個の依存ライブラリ
記憶：セッション間永続メモリー
**ポイント**
内部プロンプトから読み取れる高度なエージェント制御ロジック
SQLとベクトル検索のハイブリッドによる高精度な記憶検索
競合他社を「参考」にしつつも独自の高速実装を進める戦略

### 13. 永続メモリーとサンドボックスによる高度なセキュリティ設計
開発環境の安全性を守るため、三層構造のサンドボックスを実装している
「Bubblewrap」「Landlock」「Seccomp」というLinuxのセキュリティ機能をフル活用している
AIによる予期せぬファイル操作やシステム破壊を強力に制限する設計である
記憶システムには、長期的なプロジェクトの文脈を学習し続ける仕組みが組み込まれている
過去の修正履歴や開発者の好みを反映したコード生成が可能になりつつある
サンドボックスの詳細まで公開（あるいは露出）されている点は、透明性の観点から評価もされている
企業が安心してAIにコードを触らせるための「インフラ」としての信頼性を構築しようとしている
各エージェントが独立した環境で動くため、1つのエラーが全体に波及しにくい構造となっている
サンドボックスの三層構造
Bubblewrap（名前空間の分離）
Landlock（ファイルアクセス制御）
Seccomp（システムコール制限）
**ポイント**
Linuxカーネルレベルのセキュリティ機能の採用
企業利用を前提とした堅牢な実行環境
永続的な「プロジェクト学習」によるパーソナライズ

### 14. 導入コストとプラン別解放状況の最新情報
標準的な利用には「Super Grok Heavy」プラン（月額300ドル、約4万5000円）が必要である
導入キャンペーンとして、最初の6ヶ月間は月額99ドル（約1万5000円）で利用可能となっている
最近では、より安価な「Super Grok（30ドル）」や「X Premium+（40ドル）」プランにも段階的に解放されている
企業チーム向けには、1人300ドルという価格設定は「エンジニアの時給」と比較して正当化されている
実際、時給150ドル以上のエンジニアであれば初日で元が取れるという評価もある
