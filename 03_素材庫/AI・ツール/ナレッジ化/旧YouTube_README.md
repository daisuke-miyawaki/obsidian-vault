# YouTube ナレッジ置き場

## このフォルダの目的

YouTube動画をMarkdown化した成果物と、自動化スクリプトを置く。

**人生戦略OS（0000〜9999）には入れない。** ここは「取り込んだ素材」層。

---

## フォルダ構成

| フォルダ | 内容 |
|----------|------|
| `notebooklm_bot/` | 自動化スクリプト（Playwright + NotebookLM） |
| `かくじかん/` | かくじかんチャンネル38本（完了・2026-06-28） |
| `宇宙の法則/引き寄せ/isaさん/` | isaさん①〜⑰・自愛（完了・2026-06-29） |
| `Obsidian/` | Obsidian理解用のYouTubeナレッジ |
| `{チャンネル名}/` | 仕事系など、系統別でないチャンネル用 |

---

## 新チャンネルを追加するとき

1. `{チャンネル名}/` フォルダを作る
2. `_urls_all.txt`（全本）または `_urls_selected.txt`（個別動画）を置く
3. `notebooklm_bot/config.yaml` を更新
4. 手順は `02_活動基盤/運用/プレイブック_YouTube動画ナレッジ化.md` を参照

---

## 動画の `001_` について

YouTubeフォルダ内の `001_` `002_` … は**動画の連番**。

人生戦略OSの4桁番号（`0700` 等）とは**別体系**。混同しない。
