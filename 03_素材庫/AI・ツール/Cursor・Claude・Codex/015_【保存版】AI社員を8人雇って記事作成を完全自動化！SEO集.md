## 【第2部：詳細ナレッジベース（構造化詳細ノート）】

### AI社員「Claude Code」によるSEO記事作成の完全自動化
*   株式会社Nの奥山氏が運営するオウンドメディアでは、Claude Codeを活用してSEO記事作成を完全自動化している。
*   この動画では、その一連の仕組みと具体的なやり方を公開している。
*   本システムは、概要欄の公式LINEからスキルとして受け取れるプレゼントに含まれている。

### 従来のSEO記事作成の課題
*   **時間と手間**:
    *   キーワード選定、競合分析に各1時間。
    *   1万文字の記事執筆に3～4時間。
    *   アイキャッチ画像作成、WordPressへの入稿を含めると、1記事あたり合計6時間以上かかる。
*   **生産性の限界**:
    *   正社員1人がフル稼働しても、月に20本の記事作成が限界。
*   **コストと品質の課題**:
    *   SEO記事の外注費は月40万～50万円に達することがあり、品質にばらつきがある。
    *   社内リソースを使った場合でも、最低月50万円の人件費がかかる。

### Claude Code導入による劇的な変化
*   **記事作成時間の大幅短縮**: 1記事あたり**40分**で完了。
*   **生産性の向上**: 月に**60本以上**の記事投稿が可能。
*   **人件費の削減**: 人件費はかからず、Claude Codeの利用料金は月額**2～3万円**程度。
*   **事例紹介**: 実際に運営しているオウンドメディア「クロードコード」は、サイト自体から記事、アイキャッチ画像、記事内の図解まで全てClaude Codeで作成され、ほぼ自動で毎日2本の記事が投稿されている。
    *   #### 例
        *   「Chat GPTで画像生成する方法 2026年最新版 無料・回数・プロンプトのコツ・商用利用まで完全解説」といったタイトルで、高品質なアイキャッチや図解、目次、表、内部リンクを含む記事が生成されている。
        *   アイキャッチ画像はGoogleの画像生成AI「Novana」のAPIを活用し、コーディングで文字入れまで自動で行われる。

### Claude Codeとは何か？AIエージェント機能の解説
*   従来の生成AI（ChatGPT、Geminiなど）は、指示に対して回答を生成するまでが主な役割だった。
*   Claude Codeは「**AIエージェント**」機能を持つ点が特徴。
    *   ユーザーの意図を汲み取り、回答だけでなく、その指示を実行するまでを自動で行う。
    *   > 「メールが来たものをもうそもそも読み取りに行ってくれた上でそれの返信文を考えて返信までしてくれるがクロードコードです。」
*   デスクワーク作業のほぼ100%を自動化できる可能性を秘めている。
*   特に企業の売上向上や個人事業主の集客において、マーケティングの完全自動化に貢献できる。

### Claude Codeでできること（SEOにおける活用範囲）
*   記事の自動投稿、投稿記事の分析。
*   アイキャッチ画像やH2タグ直下に入れる画像などの作成。
*   競合リサーチ結果をスプレッドシートに保存するなど、リサーチ業務も可能。
    *   #### 例
        *   スプレッドシートにClaude Codeが自動でリサーチ結果を記入している様子が紹介された。

### SEOメディア完全自動化の仕組み（ヒューマンインザループ）
*   **基本的な構成**:
    *   人間が最終的な意思決定（品質チェック、投稿の可否判断）。
    *   AI社員（Claude Code）が中間管理職として全体を指揮。
    *   各エージェント（全てClaude Code）が具体的な作業を実行。
*   **ヒューマンインザループ**: 完全な自動化も可能だが、SEOにおいては検索順位向上に必要なナレッジや独自情報を記事に盛り込むため、人間による最終チェックが推奨される。
    *   AI社員が作成した記事の品質を人間が確認し、Goサインを出すことで投稿される。
    *   修正指示も人間が行い、AIが再度実行する。

### E-E-A-Tへの対応（Experience, Expertise, Authoritativeness, Trustworthiness）
*   **現在のSEOトレンド**: ネット上の情報をキュレーションしただけの記事では検索順位が上がりにくい。
*   **E-E-A-Tの重要性**: 特に最初の「E」（Experience = 経験）である、書き手独自の一次情報やノウハウが重要視されている。
*   **本システムでの対応**:
    *   **リサーチ段階で工夫**: ネットで集めた情報だけでなく、X（旧Twitter）やYouTubeから「一次情報」を引っ張ってくる。
        *   X: 最新情報や実際に触っている人のノウハウが多く集まっているため、これを収集・活用。
        *   YouTube: 再生数の高い動画を検索し、その文字起こし内容をローカルに保存し、記事執筆に活用。

### 具体的な自動化の流れ（7種類のAIエージェントとループ構造）
1.  **キーワード選定エージェント**:
    *   **ツール**: Ahrefs（エイチレフス）というSEOキーワード分析ツール。
    *   **手順**: Ahrefsでキーワードの検索ボリュームや上位記事を分析。独自のSEOナレッジ（YouTube情報などをまとめたもの）と照合し、狙い目のキーワードを選定。
2.  **リサーチエージェント**:
    *   選定されたキーワードに基づき、XやYouTubeから一次情報を収集・分析。
    *   #### 例
        *   Xで伸びている投稿を抽出。
        *   YouTubeでキーワード検索し、再生数の高い動画の文字起こしをローカルに保存。
3.  **構成作成エージェント**:
    *   選定キーワードの上位10記事のH2、H3タグを分析し、最適な記事構成を生成。
4.  **執筆エージェント（3種類）**:
    *   生成された構成に基づき、複数のAIエージェントが分担して記事を執筆。
5.  **品質エージェント**:
    *   執筆された記事を100点満点で評価。
    *   **合格基準**: **95点**以上。
    *   **ループ機能**: 95点に満たない場合、自動でリサーチや執筆プロセスにフィードバックし、再生成を繰り返す。目標点数に達するまで何度もブラッシュアップを行う。
6.  **公開エージェント**:
    *   WordPressへ記事を自動入稿し、公開。
    *   Google Search Consoleを通じて、インデックス登録まで自動で完了させる。
    *   **E-A-T対応**: 記事の監修者情報（奥山氏のアイコン、Xアカウントなど）を自動で挿入。
    *   **記事品質のポイント**:
        *   SEOを意識した目次、H2/H3タグ。
        *   画像、図解、表の挿入（Novanaを活用）。
        *   内部リンクの設置。
        *   「つまずきポイント」など、ユーザー体験に基づいた一次情報的な解説。
7.  **分析エージェント**:
    *   公開された記事のパフォーマンスをGoogle AnalyticsやGoogle Search Consoleから収集・分析。
    *   PVなどのKPIを評価し、次回の記事作成におけるキーワード選定や構成に活用する。
*   この一連の流れが「ヒューマンインザループ」の概念に基づき、人間が最終チェックを行うことで循環し、SEO効果を最大化する。

### 自動化システムの運用スケジュール
*   Claude Codeのループ機能やスケジュールタスク機能を活用し、以下のスケジュールで自動運用される。
    *   **毎日 朝5時**: 1本目の記事を作成・公開（途中で人間が品質チェック）。
    *   **毎日 午後2時**: 2本目の記事を作成・公開（途中で人間が品質チェック）。
    *   **毎日 夜10時**: Google Analytics、Google Search Consoleのデータを分析し、KPIを評価。次回の記事作成に活かす。
    *   **週に1回**: 過去記事のリライト提案・実行、内部リンクの最適化提案・実行。
*   このシステムにより、24時間稼働し、週1回のメンテナンスでSEOコンサルタントが行うような一連の作業が自動化され、PV数が最適化される。

### Claude Codeへの導入方法
*   奥山氏が公式LINEで配布する「プレゼントファイル」をClaude Codeにインポートする。
*   Claude Codeデスクトップ版アプリの「予約済み」機能（スケジュールタスク）を使用する。
    1.  「新しいタスク」→「新しいローカルタスク」を選択。
    2.  タスクの名前、説明を設定。
    3.  プレゼントファイルに含まれるプロンプトを貼り付ける。
    4.  実行日時（例: 毎朝5時）を指定する。
*   これにより、設定した時間に自動で記事作成プロセスが開始される。

## 【第3部：Cursor × Grok への取り込みガイド】

動画は **Claude Code** 前提だが、宮脇さんの環境は **Cursor ＋ Grok（Claudeなし）**。  
ここでは動画の「7エージェント」「人間が最終確認」「E-E-A-T」「定期運用」の**考え方はそのまま**、道具だけ Cursor × Grok に置き換える。

### 役割分担

| 道具 | 役割 |
|------|------|
| **Cursor** | 司令塔・作業場。記事mdの編集、スクリプト実行、WordPress連携、一連の流れの組み立て |
| **Grok** | 頭脳。文章生成・要約・分析。**X連携と最新情報の収集**が特に強い |

### 7エージェントの対応表

| 動画のエージェント | Cursorでやること | Grokでやること |
|-------------------|------------------|----------------|
| 1. キーワード選定 | Ahrefs等のデータをファイルに置き、Agentに渡す | キーワードの狙い目・構成の方向性を分析 |
| 2. リサーチ | YouTube文字起こし取得（既存スクリプト流用可） | **Xから一次情報を収集・要約**（Grokの最大の強み） |
| 3. 構成作成 | 構成案をmdに保存 | 上位記事のH2/H3を参考に目次を生成 |
| 4. 執筆（3種） | 生成した記事を `03_素材庫/` 等に保存・整形 | 構成に沿って本文を執筆（導入・本文・まとめを分けて指示） |
| 5. 品質 | 95点未満なら再指示をループ | SEO・E-E-A-T観点で採点と改善点を出す |
| 6. 公開 | WordPress API・画像生成APIをスクリプトで実行 | 画像の指示文作成、メタ情報の文案 |
| 7. 分析 | GA・Search Consoleのデータ取得スクリプト | 数値の読み解きと次の打ち手の提案 |

### ヒューマンインザループ（人間が最終確認）

- AIが書いた記事を Cursor で開き、「OK／ここを直して」と判断
- 修正は Cursor のチャットで Grok に再指示 → md を更新
- 動画と同じく、**公開の最終Goは人間**（E-E-A-Tの「経験」を足すタイミング）

### E-E-A-T（Cursor × Grok版）

- **Grok × X**: まだ記事化されていない生の声・最新ノウハウを拾いやすい → リサーチエージェントの核
- **YouTube文字起こし**: このVaultで使っている `notebooklm_bot` の仕組みをそのまま記事素材に使える
- **自分の経験**: `01_人生戦略OS` や日記・活動ログから、AIに渡す「一次情報」を足す

### Claude Codeにしかない機能と代替

| 動画の機能 | 代替案 |
|-----------|--------|
| 予約タスク（朝5時に自動開始） | ①まずは手動でAgent起動 ②Macのcronでスクリプト実行 ③Cursor Automations（将来） |
| スキルファイル一括インポート | `.cursor/rules/` や Agent Skills にエージェント役ごとの指示を分けて置く |
| Claude社内のループ | Cursor Agent に「品質95点まで繰り返し」と明示する |

> 丸ごとコピーは無理。**考え方とフローは再現できる**が、最初は「1本まるごと手動＋チェックリスト」から始めるのが現実的。
