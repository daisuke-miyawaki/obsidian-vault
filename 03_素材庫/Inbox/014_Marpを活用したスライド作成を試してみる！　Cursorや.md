## 基本情報
- 系統: YouTube / 未分類
- チャンネル: 未分類

- **テーマ**: Marpを活用したマークダウンでのスライド作成とAI（Cursor, ChatGPT, Perplexity）連携の可能性検証。
- **結論**: AIでマークダウン形式のスライド内容を生成し、Marp（VS Code拡張機能やWeb版）で表示・PDF化は可能だが、ツールの導入ハードルや既存プレゼンツールと比べた編集の柔軟性の低さが課題。

## Marpとは？マークダウンでスライド作成の試み

*   **Marp (Markdown Presentation Ecosystem)** とは、マークダウン形式でプレゼンテーションスライドを作成できる仕組み。
*   動画では、Marpを活用した資料作成がどれほど簡単にできるかを検証している。
*   最初にAIツール「Claude」を使ってMarp形式のスライド作成を試みたが、ClaudeはMarp形式での直接出力に対応していなかった。
    *   > 「マープでは作れないんだなるほどね」

#### 注意点

*   **ClaudeでのMaru出力は不可**: Claudeに「Marpで生成AIの活用価値についての資料を作って」と依頼しても、「Marpは使える？」という問いに対して「マープでは作れないんだ」と回答され、直接Marp形式でスライドを生成することはできない。

## Cursor（VS Code連携）でのMarp活用

*   Marpを試すため、AIコードエディター「Cursor」の活用が検討された。CursorはVS Codeと連携しており、拡張機能の利用が可能。
*   **Marp for VS Code** という拡張機能をインストールすることで、VS CodeやCursor上でMarp形式のスライドを記述・プレビューできる。
*   **インストール手順**:
    1.  Cursorを起動。
    2.  拡張機能検索で「Marp for VS Code」を検索し、インストール。
*   ただし、このようなエディターへのインストールが必要な時点で、Marpが一般的に普及するにはまだ時間がかかるとの所感が述べられている。

#### 手順：CursorでのMarpスライド作成とプレビュー

1.  Cursor上でマークダウンファイル（`.md`）を作成。
2.  ファイル内にAI（例: Cursor自身）に「生成AIの活用方法についてマークダウン形式でまとめて」と指示して内容を生成させる。
3.  生成されたマークダウンテキストを貼り付ける。
4.  Marp形式でスライドとして表示させるためには、特定の記述が必要。
    *   スライドの各ページは、3つ以上のハイフン`---`で区切ることで認識される。
    *   Marpのテーマ指定や表示設定を記述する（例: `---`の前に以下を記述）。
        ```markdown
        ---
        marp: true
        theme: default
        paginate: true
        ---
        ```
5.  Cursorのプレビュー機能（通常は右側に表示される）を利用すると、マークダウンがスライド形式で表示される。
    *   > 「ゆに来ましたねはいはいスライドっぽい感じになりましたねと」「なるほどね急激に見た目が資料になりましたね」

#### ポイント

*   マークダウンと適切なMarp記述により、シンプルなテキストが急激にスライドのような見た目に変わる点が強調されている。

## Marpでの画像挿入と階層構造

*   Marpスライドには画像の挿入も可能。
*   **画像挿入の方法**: マークダウンの画像構文 `![代替テキスト](画像URL)` を使用する。
    *   例: `![ロボット画像](https://example.com/robot.png)`
*   一時的に使用する画像として、フリー素材サイトで「ロボット画像」を検索し、URLを貼り付けてテストしている。
*   画像生成AIで生成した画像をURLとして指定すれば、自動で画像をスライドに含めることも可能だと示唆されている。
*   マークダウンの見出し（`#`, `##`, `###`）を使うことで、スライド内のテキストに階層構造を持たせることができる。

## MarpスライドのPDFエクスポートとオンラインエディター

*   作成したMarpスライドをPDFとしてエクスポートすることを試みた。
*   Cursor（VS Code）上での `Control + Shift + P` から「エクスポートスライドデック」を試したが、エラーとなり直接のエクスポートはできなかった。
*   そこで、**Marp公式オンラインエディター（Web Marp）** の存在が発見された。
    *   オンラインエディターを利用すれば、ブラウザ上でマークダウンをMarpスライドとして表示し、PDFとしてエクスポートすることが可能。

#### 手順：Web MarpでのPDFエクスポート

1.  Marp公式オンラインエディターのウェブサイトを開く。
2.  AIで生成した、または手動で作成したMarp形式のマークダウンテキストをオンラインエディターに貼り付ける。
3.  エディター上でスライドのプレビューを確認。
4.  エクスポート機能を使って、PDF形式で資料を出力する。
    *   > 「あこのwebマープでいけんのはいいかもしれないですねだから資料をガッと作らした上でこっちで表示してってやったらチャットGPTとかでもいけるかな」

#### ポイント

*   オンラインエディターの存在により、Marpの利用ハードルが大幅に下がることが示された。ローカル環境にMarp for VS Codeをインストールすることなく、手軽にスライドのプレビューとPDFエクスポートが可能になる。

## 他のAIツール（ChatGPT, Perplexity）でのMarpスライド生成

*   Web Marpの存在により、ChatGPTのような汎用AIでもMarp形式のマークダウンを生成させれば、スライド作成が可能になると考えられた。
*   **Perplexity AI** を使って、生成AIの活用事例についてMarp形式でのスライド作成を依頼。
    *   **依頼内容**: 「生成AIの最近の活用事例についてMarp形式で資料を出力して」と具体的に指示。
    *   Perplexityはマークダウン形式で回答を生成し、スライドの区切り（`---`）も含まれていた。
*   Perplexityが生成したマークダウンテキストをWeb Marpに貼り付けると、スライドとして表示された。
    *   **画像挿入の制約**: Perplexityの回答に含まれる画像URLは、Web Marpでは残念ながら直接表示されなかった。

#### 手順：Perplexityでの生成とWeb Marpでの表示

1.  Perplexityに「生成AIの最近の活用事例についてMarp形式で資料を出力して」と依頼。
2.  Perplexityが生成したマークダウンテキストをコピーする。
3.  Web Marpを開き、テキストエディタ部分にコピーしたマークダウンを貼り付ける。
4.  右側のプレビューエリアでスライドとして表示されることを確認し、必要に応じてPDFエクスポートを行う。

## Marpを活用したスライド作成の評価と展望

*   MarpとAIを組み合わせることで、マークダウン形式でスライドのベースを迅速に作成できる可能性は示された。
*   特にWeb MarpとAIの組み合わせは、ツールのインストール不要で手軽に試せるメリットがある。
*   しかし、以下の課題も指摘されている。
    *   **インストールハードル**: Marp for VS Codeのようにエディタに拡張機能をインストールする必要がある点は、一般ユーザーにとってはハードルが高い。
    *   **編集の柔軟性**: 生成されたスライドの内容やデザインの微調整、レイアウトの変更といった編集作業は、PowerPointやGoogleスライド、Canvaといった既存のプレゼンツールの方がはるかに優れている。
    *   > 「作ったやつの編集がしづらい感じがねちょっとこう実際使えるかって言うとなんか調整もしづらいしやっぱパポとかGoogleスライドとかキャンバとかの方がいいのかな」
*   **活用シーン**: 元ネタとなるテキストデータからのスライド化など、特定の用途では有効活用できるかもしれない。
*   動画の結論として、現時点では「ちょっと厳しいかな」という感想を述べつつも、Marpという仕組み自体の可能性は認めている。より良い活用方法があれば教えてほしいと視聴者に呼びかけている。
