#### 2. コンセプト設計
- コンセプトとは「誰に何を発信してどういう状態にするアカウントなのか」を決める作業。
- ここでつまずく人が9割。
- #### 注意点：初心者がやりがちな最大の失敗
- 「いろんな人に届けたい」という思いから「広い発信」をしてしまうこと。
- 収益を出したいなら当然多くの人に届けたいと思うが、この考え方が一番失敗する。
- > 「全員に売ろうとすればするほどなぜか全く売れなくなるんですよ。」
- #### ポイント：コンセプト設計でやるべき3つのこと

### 1. **理想のお客さんを「たった1人だけ」思い浮かべ、その人だけに売り切るように設計する。**

### 2. **その人以外の人にはもう刺さんなくていい、と腹を括る。**

### 3. **「これ私のことだ」と思わせて、当てはまらない人とはスパッと切る。**
- 「捨てる」と言われると客が減ると怖くなるが、逆。
- 全方位に薄く広く呼びかけるよりも、たった1人にぶっ刺さる言葉の方が、その背後にいる「同じ悩みを持った100人」に届く。
- コンセプト設計で大事なのは「多くを拾うこと」ではなく「切り捨てること」。
- AI界隈は需要が大きいジャンルなので、切り捨てても人は十分いる。
- **マインド**: 理想のお客さん以外はスパッと捨てる、というマインドを持つ。
- **ツール**: Claudeと壁打ちしながらコンセプトを決める。
- **Claudeでのコンセプト設計実演（プロンプト例）**:
- `あなたはXアカウントのコンセプト設計を専門にするマーケターです。さっき出したリサーチ結果と僕の情報をもとに壁打ち相手になってください。`
- **絶対守って欲しいルール**: ターゲットを絞る、理想のお客さん以外は切り捨てる。
- **自分の情報**:
- やりたいジャンル：AI×副業
- 経験・強み・実績：100本AIの動画を見た（→Claudeから「強みにならない」と指摘あり）、Claude Codeで実際に何か動かした。
- 発信で扱えそうなテーマ：流行っているClaude Code
- **やって欲しいこと**: ターゲット像を3パターンで出す、その理由、ターゲットが決まったら「誰に何を、どういう状態にするアカウントなのか」をまとめる。
- **Claudeとの壁打ちプロセス**:
- Claudeから「AIの動画100本見ただけでは強みにならない」と指摘。100本見た人ではなく「Claude Codeで実際に何か動かした人」の方が良いとアドバイス。
- 講師が「100本動画を見た上でClaude Codeを実際に営業の業務効率化に活用した」という設定で進める。
- Claudeがターゲット像をA、B、Cと提案。講師が「自動化がしたい非エンジニア会社員の田中さん」であるAに一番近いと選択。
- Claudeがさらに深掘り質問をし、講師が回答することでコンセプトが絞られていく。
- **決定したコンセプト例**:
- **誰に**: 見積もり作成に毎日追われている、プログラミング経験未経験の30代法人営業マン。
- **何を**: Claude Codeで単価表案件を読ませ、見積書を半自動で生成する仕組みの作り方を実演で解説。
- **どういう状態にするか**: コードが書けなくても自分の手で営業業務を自動化できる状態に変える。
- **コンセプトを一言で**: プログラミング未経験の営業マンがClaude Codeで見積もり作成を自動化して定時で帰れるようになる方法を実演で見せるアカウント。
- **キャッチコピー**: Chat GPTで時短だったあなたを、自分の業務を自分で仕組み化できる営業に変えます。
- **学び**: リサーチ結果と自分の情報を元にAIと壁打ちしながらコンセプトを決めていけば良い。

### X集客の本番：良い投稿の作り方（AI活用）
- Xの土台（準備段階）が完了したら、いよいよ良い投稿ができるかどうかにかかっている。
- #### 最重要：AIに丸投げはNG
- **注意点**: AIに「なんか良い投稿を作ってよ」と丸投げするのは絶対NG。良いものは出てこない。
- **理由**: 自分自身が「良い投稿とは何か」を分かっていないと、AIに正しい指示を出せない。AIも「良い投稿って何？」と思っているため、ふんわりとした平均的な答えしか返ってこない。
- **大前提**: 自分が良い投稿の正体を知っておくこと。

#### 良い投稿の正体：伸びる投稿 vs 売れる投稿
- 良い投稿は大きく「伸びる投稿」と「売れる投稿」の2つに分けられる。

#### 1. 伸びる投稿
- シンプルに「数字が取れる投稿」（インプレッション、いいね、リプライ/コメントの数など）。
- たくさんの人に反応してもらえる投稿。
- #### 大事な前提：人は面倒くさがり
- Xで流れてくる投稿は基本的に開かないし読まない。ガンガンスクロールする。
- 最初の壁は「目に止まること」。ポストの1行目で勝負が決まる（1秒2秒の世界）。
- 1行目で目が止まらなければ、どんなに良い内容を長文で書いても読まれずに終わる。
- #### ポイント：1行目で目に止まるための3つの要素

### 1. **結論を1行目に持ってくる。**
- **例（講師のポスト）**: `もし今僕がフォロワーも実績も全部失った状態でクロードコードを使って3ヶ月で月100万稼ぐなら`
- 効果: このポストで何が学べるかが一発で分かる。「0からClaude Codeで3ヶ月100万稼ぐ方法がわかるんだな」と良さそうに感じる。
- **実績**: この投稿で「2.3万インプレッション」。ここからnoteに繋げたら10%が見たとして2300人が見てくれる計算。note単体ではマジで無理な数字。

### 2. **理想の未来と再現性を匂わせる。**
- **例**:
- 理想の未来: 「3ヶ月で月100万円稼ぐ」
- 再現性: 「フォロワーも実績も全部失った状態で」
- 効果: 「自分にもできそうかも」と思わせ、続きがめちゃくちゃ気になる。

### 3. **数字と固有名詞を使う。**
- **例**: 「3ヶ月で月100万」（数字）、
- 「Claude Code」（固有名詞）
- **NG例**: 「もし今僕がAIを使って稼ぐならどうするかを書きマス」 → ありきたりで気にならない。

#### 2. 売れる投稿
- 伸びる投稿だけでは人が増えてもnote自体は売れない。伸びる投稿と売れる投稿は別物。
- #### ポイント：売れる投稿の3つの要素

### 1. **売るノートと内容に「一貫性」があること。**
- **例（講師の場合）**: 「AI×note」で発信しているため、投稿内で「note」「Claude Code」というワードを頻繁に使う。
- 効果: 「この人といえばClaude Codeとnoteだ」という印象が定着する。

- プロンプトの質よりも、AIに投入する「自分の情報（MDファイル）」の量と質を重視したこと。
- 生成された投稿案をリライトし、その修正点をAIにフィードバックすることで、AIを継続的に成長させていること。
- これらの仕組みを構築することで、noteが自動で売れる「自動販売機」のような状態を目指せること。

### やってはいけないこと・注意点一覧
- いきなり自分の頭だけで発信内容を考え、市場ニーズとずれた投稿をしてしまうこと。
- 「いろんな人に届けたい」という気持ちから、ターゲットを絞らず広い発信をすること。これは結果的に誰にも刺さらない。
- AI感が強く、他のアカウントに埋もれてしまうような「モブアイコン」の使用。
- リプライ時に相手が入力しづらい「英語名」をアカウント名に設定すること。
- 大手アカウントに対し、一方的に「拡散してくれ」とメリットのない絡み方をすること。
- 「初心者感」を出しすぎる投稿（意味のない成り上がりストーリー、発信軸と関係ない日記、統一感のない発信）は伸びない人の特徴。
- 「AIに良い投稿を作ってよ」と、自身が良い投稿を理解しないまま「丸投げ」すること。
- Claudeのプロジェクト機能を使わず、毎回真っさらな状態でAIに投稿作成を依頼すること。これは出力の質が不安定になり、手間もかかる。
- プロンプトの質だけにこだわり、自分の情報や過去のやり取りをAIに学習させないこと。
- 信頼構築ができていない段階での過度なnote販売告知。
