## ■ システム構成（確定版）

```
【あなた側】
あなた → Dify秘書（ローカル）
         ↓ 先生向けに変換
         → Notionに書き込む

【自動化】
Make.com が定期確認
→ 新メッセージがあれば先生にメール送信

【先生側】
メールのURLからDify Webアプリ（ふくちゃん）を開く
→ ふくちゃんがNotionから情報取得
→ 先生向けの言葉でタスク・連絡を表示
→ 先生が返信・確認
→ Notionに記録 → あなたにメール通知
→ Dify秘書があなた向けに変換
```

### 使用ツール

| Gemini API | AIエンジン | ほぼ無料 |

## ■ 重要な方針・注意点

- 先生への提案は「セッション集客」を前面に出さない（プライドを傷つける）
- タスクリマインドはふくちゃん（AI）が行う（あなたが直接言わない）
- 先生が動くのは「目先の楽・目先の利益」がある時だけ
- 先生に提案する前に「動くもの」を先に作る
- コストは先生に払ってもらう前提で最初から合意する
- あなたのストレスを最優先：「やらなければやらないでいい」スタンスを保つ
- ふくちゃんの「優しい・相談しやすい」キャラクターを維持する
