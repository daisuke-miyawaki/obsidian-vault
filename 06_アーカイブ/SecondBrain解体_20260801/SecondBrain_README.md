# SecondBrain - 宮脇大輔 第二の脳（Knowledge OS）

## 目的
このフォルダは、私の思考・知識・事業を統合管理し、AI（Grok統括PM、Hermesなど）と連携して人生と事業を最適化するための「第二の脳」です。

## フォルダ構造概要
- **00_KnowledgeOS/** → 人生戦略OSの憲法（価値観・哲学・ルール）
- **01_Personal/** → 個人内省・日記・自己観察
- **02_Projects/** → 事業・趣味・実験プロジェクト
- **03_AI_Systems/** → Grok, Hermes, CursorなどのAIシステム管理
- **04_Learning/** → 外部からの学び（AI、マーケティング、宇宙の法則など）
- **98_Archive/** → 完了・過去資料
- **99_Inbox/** → 未整理の一時置き場

## 運用原則
- 何かわからないものは一旦 `99_Inbox/` へ
- 重要な気づきは `00_KnowledgeOS` に昇格させる
- AIは常にこのREADMEと00_KnowledgeOSを参照して判断する
