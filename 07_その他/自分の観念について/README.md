# 自分の観念について（デスクトップ用コピー置き場）

## このフォルダの役割

- Mac **デスクトップ**の `自分の観念について/` に置くファイルと同じ内容を、Vault内にも持つ。
- 正本（素材庫）: `03_素材庫/宇宙の法則/偉人の言葉/001_【99%が知らない】お金のブロックの外し方.md`
- Cloud Agent は Mac 本体のデスクトップへ直接書き込めない。Mac 側で下の同期を実行する。

## Mac でデスクトップへコピーする

DigitalGarden（外付けSSD）がマウントされているとき:

```bash
mkdir -p "$HOME/Desktop/自分の観念について"
cp "/Volumes/MultiPurpose_SSD/DigitalGarden/07_その他/自分の観念について/001_【99%が知らない】お金のブロックの外し方.md" \
   "$HOME/Desktop/自分の観念について/"
```

Vault の場所が `~/.../DigitalGarden` だけ違う場合は、上の `cp` の元パスを実際の Vault ルートに合わせる。

素材庫の正本を直したあと、このフォルダへ同じファイル名で `cp` し、必要ならデスクトップへも同じ `cp` を繰り返す。
