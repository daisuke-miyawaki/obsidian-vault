# 【ナレッジベース】公図・GIS・AIを活用した土地位置図（配置図ドラフト）作成の仕組みと周辺知識

看板設置（屋外広告物許可申請・建築確認申請等）において、公図（紙・画像）とGoogleマップ（航空写真）などの現代の地理データを重ね合わせ、SVG等のベクターデータとして出力する仕組み・基礎知識を整理したナレッジ集です。

---

## 1. 地理データ（GIS）の基本データ形式

地図や土地に関するデジタルデータは、大きく**「ベクターデータ」**と**「ラスタデータ」**の2つに分類されます。

| データ形式 | 主な拡張子 / フォーマット | 特徴・用途 |
| :--- | :--- | :--- |
| **Shapefile (シェープファイル)** | `.shp`, `.shx`, `.dbf`（複数ファイルで構成） | ESRI社が提唱したGIS業界の標準ベクターフォーマット。点（Point）、線（Line）、面（Polygon）の座標データと属性情報（地番等）を保持。 |
| **GeoJSON (ジオジェイソン)** | `.geojson`, `.json` | WebGISやAI処理に親和性が高いJSONベースの軽量フォーマット。PythonやJavaScriptでの処理、SVGへの変換が容易。 |
| **登記所備付地図データ (XML)** | `.xml`（法務省G空間情報ポータル等） | 法務局が公表している全国の筆（土地）境界ベクターデータ。世界測地系などの正規座標系を持つ。 |
| **ラスタデータ (画像データ)** | `.jpg`, `.png`, `.pdf`, `GeoTIFF` | 公図のスキャン画像やGoogleマップの衛星写真。画素（ピクセル）で構成され、そのままでは地球上の位置座標を持たない。 |

---

## 2. 位置合わせの仕組み：「ジオレファレンス（Georeferencing）」

「写真やスキャン画像の公図」には緯度・経度の情報がありません。これを現代の地理座標の上に重ね合わせる技術を**ジオレファレンス**と呼びます。

### ジオレファレンスの原理
1. **基準点（GCP: Ground Control Points）の設定**:
   公図画像上の特徴的な点（道路の角、筆の屈曲点など）と、GISデータ（Shapefileや航空写真）上の対応する同一地点を複数指定（最低3点以上）します。
2. **位置補正（変形処理）**:
   アルゴリズム（アフィン変換、多項式変換など）を用いて、公図画像を「回転」「拡大・縮小」「台形補正（歪み除去）」し、実世界の座標系にフィットさせます。

### 処理のワークフロー
[紙・写真の公図] ──(画像補正/OCR)──> [公図画像]
│
(ジオレファレンス) ──> [合成レイヤー] ──> [SVG書き出し]
│
[GISデータ/Googleマップ] ──────────────────┘

## 3. SVG出力のメリットと構造

ドラフト結果を**SVG（Scalable Vector Graphics）**で出力・保存することには、実務上大きなアドバンテージがあります。

* **レイヤーの独立保持**:
  * 背景のGoogleマップ（衛星写真）は「埋め込みラスタ画像」として保持。
  * 公図の境界線や地番テキスト（「803-2」等）は「ベクター要素（`<path>`, `<text>`）」として独立。
* **無段階ズーム（拡大してもボヤけない）**:
  * 看板の配置予定位置や隣地境界との距離を拡大表示しても、線画や文字が鮮明なまま保たれます。
* **CAD・デザインソフトとの高い連携性**:
  * Adobe Illustrator、Inkscape、AutoCAD等のCADツールにそのままインポートし、設計図（配置図）の下図として活用・編集できます。

## 4. なぜ「人間のチェック」と「ドラフト扱い」が必要か？（実務上の注意点）

AIやGISで高度に合成された図面であっても、以下の理由から**必ず「ドラフト（下書き）」として扱い、最終的な現地確認および専門家の手配を行う必要があります**。

1. **公図自体の精度の限界（公差）**:
   * 多くの公図（特に旧公図/14条指定外地域）は明治時代の測量（地押調査）に基づいているため、**実際の土地の形状や面積とズレが生じている**ことが珍しくありません（いわゆる「縄伸び」「縄縮み」）。
2. **Web地図の歪み・誤差**:
   * Googleマップや衛星写真はMercator（メルカトル）投影法を採用しており、地表の凹凸やレンズ歪み等により、数メートル単位の誤差が含まれます。
3. **現地状況の不反映**:
   * 地図上では境界線に見えても、現地には擁壁、側溝、電柱、越境している樹木などがあり、物理的に看板が建てられないケースがあります。

## 5. 実務でのベストプラクティス（まとめ）

1. **フェーズ1（事前の位置把握 / AI・GIS活用）**:
   * 公図画像＋GeoJSON/Googleマップをジオレファレンスし、**SVG形式で配置図ドラフトを作成**する。
   * 看板の概ねの位置や地番との位置関係を視覚的に関係者に共有する。
2. **フェーズ2（現地確認・チェック）**:
   * 作成したドラフト図面を手に現地へ行き、道路、隣地境界フェンス、電柱等との位置関係を人間が確認・修正する。
3. **フェーズ3（正式申請・施工）**:
   * 建築確認申請や大規模看板の施工においては、**土地家屋調査士**（境界確定）や**測量士/施工会社**による実測配置図を作成・提出する。
