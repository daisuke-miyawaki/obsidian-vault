### スクール名の由来
「PINTO」という名前は**「ピンっときた!!ひらめいた!!」**という言葉から生まれました。

### スクール理念
*   **考える力を重視**: スポーツは考えて練習をしなければ身につかないという考えから、生徒自身の発想力を大切にした指導を行っています。
*   **ひらめきの重要性**: 「なるほど!こうだったのか!!」という気づきを通じて、生徒が自分で上達への一歩を進めることができるようサポートします。
*   **少人数制**: 一人一人に合った指導やアドバイスを行うため、少人数制を導入しています。

## レッスン内容・クラス体系

### 一般クラス
レギュラーお1人様出席の場合は、1時間レッスンとなります。

| クラス | 定員 | 内容 |
| :--- | :--- | :--- |
| **初級** | 8名 | 基本フォームを確認して、ストロークやボレーが出来るようになります。 |
| **初中級** | 8名 | より美しいフォームを目指し、ゲームが出来るようになります。 |
| **中級** | 6名 | ゲームの中で確実なプレーを目指します。応用的なポジショニングをマスターします。 |
| **上級** | 6名 | ゲーム感覚を養い、最高のプレーを目指します。 |
| **シングルス** | 4名 | シングルスのゲーム展開をマスターします。 |

### ジュニアコース
お子様の成長に合わせた運動能力の開発、向上に重点を置き、その年齢しか伸ばせない能力を最大限に引き出します。テニスやスポーツの楽しさ、マナーやルールの規則を学びます。また、月例ジュニア大会も開催しています（海部地域：津島市、あま市、大治町、蟹江町、弥富市、愛西市、飛島市）。

| クラス | 対象年齢 | 内容 |
| :--- | :--- | :--- |
| **J1クラス（初中級）** | 小学1年生〜小学4年生 | テニスを通じて基本的な運動能力の発達を目指します。またルールやテニスの基礎を学ぶとともに集団の中での協協調性も身につけ、ゲームが出来るようルールを覚えていきます。 |
| **J2クラス（初中級）** | 小学4年生〜小学6年生・中学生 | J1クラスと同様の内容を行います。 |
| **強化クラス** | 小学生〜中学生 | 応用的な技術を身につけます。試合に出場することを目標にして全国的選手を目指し、技術やメンタル等の試合に勝つための要素を指導していきます。 |
| **選手クラス** | 高校生（中学生はコーチの推薦が必要） | 戦術、展開を学び、体づくりに励み試合に勝つこと。強い意志を持って県大会上位と東海大会、全国大会出場を目指していくクラスです。 |

### レッスン・イベントの種類
*   **レギュラークラス**
    *   定期的なレッスン（週1回、隔週などの受講形態）。1カ月4週レッスンになりますので、第5週目は休館日となります。
*   **テーマレッスン**
    *   月〜金曜日まで様々なテーマで行われる選択制レッスン。辰巳コーチ、晋吾コーチ、浜島コーチが担当します。各曜日で様々なレッスンをご用意（例：ネットプレー、アプローチからのリズムとポイントなど）。
*   **スポットテーマレッスン**
    *   特定の日に開催されるテーマレッスン（要予約）。ご予約はメール（pintotennisclub@gmail.com）で受付。ビジターの方も受講可能です。
*   **プライベートレッスン**
    *   個人指導。時間と曜日を個別にご相談いただけます。
*   **シングルスクラス**
    *   1人コーチで4名定員に絞り、シングルスに特化。シングルスのゲーム展開をマスターします。

### 少人数制システム
当スクールの最大の特徴の一つです。きめ細やかな指導が可能になり、上達が早いことが特徴です。

*   **ダブルスクラス**: 6名（1人コーチあたり）
*   **シングルスクラス**: 4名
*   **初級・初中級クラス**: 8名
