## かくじかん案件の経緯（別チャット含む・時系列）

### 1. きっかけ（2026-06-28頃）

- 対象：YouTubeチャンネル「かくじかん」（@KAKUZIKAN）全動画
- 当初の課題：38本をCursorだけで処理すると、AI枠・時間・コストが大きい
- **ユーザー提案**：重い処理は無料の NotebookLM に逃がす
- **成果物の決定**：チャンネル丸ごと要約ではなく、**1動画1md**。中身は「3行要約＋構造化詳細ノート」（文字起こし全文は入れない）

### 2. URL一覧の作成

- `yt-dlp` でチャンネルから38本のタイトル＋URLを抽出
- 保存先：`かくじかん/_urls_all.txt`（1行1動画、`タイトル|URL` 形式）
- 連番 `001_`〜`038_` はこのファイルの順番に対応

### 3. 自動化スクリプトの実装

- 別チャットで `notebooklm_bot/` を新規実装（Python + Playwright）
- 役割：NotebookLMにログイン → YouTubeソース追加 → プロンプト投入 → 回答をmd保存 → `_index.md` 更新
- **初回ログインだけ人手**（Google認証）。以降はCookie再利用

### 4. 試作 → 全本処理

1. `./run.sh setup` … 環境構築
2. `./run.sh login` … Googleログイン（初回のみ）
3. `./run.sh run-one 001` … 1本試作（001で形式確認）
4. `./run.sh add-sources` … 38本URLをNotebookLMへ
5. `./run.sh run-all` … 002〜038を一括処理（001は試作済み）

**完了日：2026-06-28**（38本すべて「完了」）

## 失敗と直し方（再発防止・詳細）

| 失敗 | 原因 | 直し方 |
|------|------|--------|
| Cursor力業で1本ずつ処理 | AI枠・コスト・時間 | NotebookLM＋スクリプトに切替（恒久方針） |
| `「ソースを追加」ボタンが見つかりません`（001で3回失敗） | `notebook_url.txt` がホームURLのまま保存され、ノートブック内に入れていなかった | ノートブック内URLを正しく保存するよう修正。`selectors.py` を2026年UI向けに更新 |
| NotebookLM UI変更 | セレクタ不一致 | `03_素材庫/YouTube/notebooklm_bot/src/selectors.py` を更新 |
| 処理中断 | ブラウザ落ち・ログイン切れ | `state/progress.json` から再開、`./run.sh login` |
| デバッグ | 画面が想定と違う | `state/screenshots/` を確認 |
| **012で毎回止まる（isa）** | **①チャット履歴が11本ぶん溜まり拒否 ②1日のチャット上限** | 下記「isa案件」を参照。プログラム修正済み（2026-06-30） |
| 既存ブラウザセッション | Chrome for Testing が裏で残存 | `pkill -f notebooklm_bot/state/browser_profile` 後に再実行 |
| 15分待ってタイムアウト | 拒否・上限でも古い検知が弱かった | `notebooklm.py` で即検知するよう修正済み |

## isaさん案件の経緯（2026-06-29〜30）

### 概要

- 対象：isaさん YouTube 17本（`宇宙の法則/引き寄せ/isaさん/`）
- NotebookLMノートブック名：`isaさん17本`
- 001は単独ソース＋専用プロンプト（`prompts/video_note_isa.txt`）で品質改善後、002〜011を一括処理して完了

### 012で止まったように見えた本当の理由（調査結果）

**012の動画そのものの不具合ではない。** 次の2つが重なっていた。

| 順番 | 現象 | 本当の原因 |
|------|------|------------|
| 1 | 「答えられません」→15分待ち→タイムアウト | 001〜011の**チャット履歴**が同一ノートブックに残り、長いプロンプトを拒否 |
| 2 | 「現在、回答できません」／短いプロンプトでも失敗 | リトライを繰り返し **NotebookLMの1日チャット上限** に到達 |

**見分け方（スクショ）：**

- `state/screenshots/response_refusal.png` … 「答えられません。言い換えるか…」
- `state/screenshots/response_timeout.png` … 「**チャットの1日の上限に達しました**」

### 2026-06-30 に入れたプログラム修正

| 修正 | ファイル | 内容 |
|------|----------|------|
| 質問前にチャット履歴削除 | `notebooklm.py` | 「チャット オプション」→「チャットの履歴を削除」→「削除」確認 |
| 拒否・上限の即検知 | `notebooklm.py` | 15分待たず、数秒〜数十秒で失敗理由を表示 |
| 古いブラウザ終了 | `auth.py`（既存） | 起動前に `browser_profile` 関連プロセスを掃除 |
