# [ナレッジ] 自分専用AIエージェント（AI秘書）の構築・運用ノウハウ

## 1. メインテーマと結論
* **メインテーマ:** Claude Cowork等のデスクトップアプリを活用し、PC内ローカルファイルへのアクセス、外部ツール（Gmail・カレンダー等）連携、および `claude.md` による自己学習・ルール更新機能を備えた**「使えば使うほど賢くなり、資産化していく自分専用のAI秘書」**を構築・運用する。
* **結論:** AIを単なるチャットボットとして使うのではなく、特定のフォルダ構成（PARAメソッド等）の中で情報を蓄積させ、雑務を自律的に自動実行させる「エージェント」として機能させることが重要である。

---

## 2. タイムライン・章ごとの詳細展開

### 2.1. AI秘書の概念とWeb版チャットAIの限界
* **核心となる主張・要点:**
  * 従来のWebブラウザ上のChatGPTやClaudeでは不可能な「PC内部への操作」を、Claude Cowork等のデスクトップアプリが実現する。
* **具体的な解説・ロジック:**
  * Webアプリは基本的にユーザーのPC内フォルダやファイルに直接アクセスしたり、新しいファイルを作成・編集したりするプログラムを動かすことはできない。
  * AI秘書として雑用をこなすには、自分が普段使っているツール、ファイル、フォルダにアクセスできる権限を持つデスクトップアプリ（`Claude Cowork`, `Claude Code`, `Codeexe` 等）を使うことが前提条件となる。
* **具体例・エピソード・データ:**
  * ファイルのアップロードはWeb版でも可能だが、フォルダ内での新規作成や直接編集はデスクトップアプリが必要。
* **注意点・見落としがちなリスク:**
  * 普通のチャットアプリは「育てていく」という感覚が薄く、やり取りが単発で終わりがちである。

### 2.2. PARAメソッドによる情報管理とフォルダ構成
* **核心となる主張・要点:**
  * AI秘書を正常に機能させるためには、情報を整理・蓄積するための構造（PARAメソッド）を導入することが有効である。
* **具体的な解説・ロジック:**
  * **P (Project):** 進行中のプロジェクト情報を格納する。
  * **A (Area):** クライアント情報、会社情報、デイリーオペレーション（日々の業務）など、継続的な責任範囲を管理する。
  * **R (Resource):** テンプレートや参考資料などのリソースを格納する。
  * **A (Archive):** 完了したプロジェクトや使用しなくなった情報を移動させる。
* **具体例・エピソード・データ:**
  * 「プロジェクト001」の中に「AI秘書を作る完全ガイド」の修正タスクを入れるなど、具体的な案件ごとにフォルダを分けて管理する実例。
* **注意点・見落としがちなリスク:**
  * フォルダ構成が乱雑だとAIが混乱するため、AIが読み取りやすい構成に常に整える必要がある。

### 2.3. 外部ツール連携とMCPの活用
* **核心となる主張・要点:**
  * **MCP (Model Context Protocol)** という共通規格により、AIがGmailやGoogleカレンダーなどの外部サービスと直接やり取りできるようになる。
* **具体的な解説・ロジック:**
  * MCPはAIが外部サービスと連携するための「USB」のような共通規格であり、Anthropicが提唱。
  * 外部サービスがMCPを公開していれば連携可能で、公開されていない場合でも自作が可能（ただし難易度は高い）。
  * コネクターとしてツールを接続することで、AIが直接メールの下書きを作成したり、カレンダーに予定を書き込んだりする「ツール実行」が可能になる。
* **具体例・エピソード・データ:**
  * Gmailから「返信が必要なメール」を洗い出し、6通のメールに対して一括で下書きを作成するデモ。
  * メール本文から「4月10日の会食（銀座周辺、19時から）」という情報を読み取り、Googleカレンダーに場所やゲスト招待を含めて自動登録。
* **注意点・見落としがちなリスク:**
  * メール送信のAPI自体はあるが、現状のツール構成では下書き作成までを行い、送信自体は手動で行う形になる場合がある。
  * Gmailの「アーカイブ」操作は、現時点ではMCP経由で実行できないという制限がある。

### 2.4. エージェントの核：claude.mdの役割
* **核心となる主張・要点:**
  * `claude.md` はAIエージェントが最初に読み込む「マスタードキュメント（指示書）」であり、AIの挙動や記憶システムを定義する。
* **具体的な解説・ロジック:**
  * AIは何者か（役割）、出力ルール（トーン＆マナー等）、情報の管理方法（PARAメソッド等）をこのファイルで定義する。
  * `memory/` ディレクトリを指定し、学習事項、頻出用語、ツール設定、失敗パターンを記録させる「メモリーシステム」を構築することで、同じミスを繰り返さないようにさせる。
  * Claude Coworkだけでなく、Cursorや他のエージェントでは `agent.md` という名前で同様の役割を果たすファイルが使われる。
* **具体例・エピソード・データ:**
  * `claude.md` に指示を書くことで、新しいタスク（J君の情報記録）が発生した際に、自動的に `context/people/` 内に「J君のプロフィールファイル」を作成・蓄積させたデモ。
* **注意点・見落としがちなリスク:**
  * `claude.md` が長すぎると情報が混乱し、AIが正しく理解できなくなるため、不要な情報を削り、可能な限り**200行〜500行以内**にコンパクトに収める「チューニング」が必要。

### 2.5. 成果物の自動作成と運用高度化
* **核心となる主張・要点:**
  * AIにゼロから提案資料やリサーチ結果を作成させ、それを特定のプロジェクトフォルダへ自動配置させることができる。
* **具体的な解説・ロジック:**
  * AIはJavaScript（PPTXGenJSなど）を使用して、PC上に直接PowerPointファイル（`.pptx`）を生成できる。
  * 作成中、AIは「スクラッチパッド（編集履歴）」に足跡を残しながら、ビジュアルの修正や内容のブラッシュアップを自律的に行う。
* **具体例・エピソード・データ:**
  * 「ABCパン屋」向けの北海道産小麦の提案資料をPowerPointで作成するデモ。
  * 「小麦市場の10年間のリサーチ」を指示し、リサーチとスライド作成を並行して実行。
* **注意点・見落としがちなリスク:**
  * デスクトップ全体をワークスペースにすると、余計なファイルまでコンテキストに入り判断ミスを誘発するため、AI秘書専用のフォルダを作成して運用すべきである。

### 2.7. スケジュール実行（定期実行）機能
* **核心となる主張・要点:**
  * Claude Coworkにはタスクをスケジュール登録して定期実行する機能が備わっている。
* **具体的な解説・ロジック:**
  * 毎日、あるいは平日のみなど頻度を指定し、特定の時間に特定のタスク（メールチェック等）を自動起動できる。
* **具体例・エピソード・データ:**
  * 「毎朝9時に受信メールを確認し、返信必要のものは下書きを作り、不要なものにはラベルをつける」という設定例。
* **注意点・見落としがちなリスク:**
  * PCがスリープ状態だと実行されないため、アプリ側の設定で「コンピューターをスリープさせない（アイドルスリープ防止）」をオンにする必要がある。

### 2.8. プラグインとスキルの武装
* **核心となる主張・要点:**
  * Anthropicが提供するプラグインを導入することで、AI秘書に専門知識を「武装」させることができる。
* **具体的な解説・ロジック:**
  * プラグインは、特定の分野（ファイナンス、マーケティング、セールス等）で必要な「スキル」をまとめたパッケージである。
  * これらを導入することで、ゼロベースの状態よりも高度な業務知識を持った秘書として機能する。
* **具体例・エピソード・データ:**
  * ファイナンスプラグイン、マーケティングプラグイン、オペレーションプラグインなどの存在。

## 3. 重要なキーワード・概念の定義

| キーワード | 定義・役割 |
| :--- | :--- |
| **Claude Cowork** | PC内のローカルファイル操作や外部ツール連携が可能な、Claudeのデスクトップ向けエージェント機能。 |
| **claude.md** | エージェントの性格、ルール、情報の保存先、記憶の仕組みなどを記述した、エージェントが最初に読み込む最重要の指示ファイル（マスタードキュメント）。 |
| **PARAメソッド** | Project（プロジェクト）、Area（継続的責任）、Resource（リソース）、Archive（アーカイブ）の4分類で情報を管理する手法。AI秘書のフォルダ構成に適用される。 |
| **MCP (Model Context Protocol)** | AIが外部ツール（Gmail, Slack等）と会話するための標準規格。USBのような役割を果たす。 |
| **コネクター (Connector)** | GmailやGoogleカレンダー、Notionなど特定の外部ツールとClaudeを橋渡しする接続機能。 |
| **プラグイン / スキル** | 特定の業務（マーケティング、財務等）に特化した知識や機能をAIに追加するパッケージ。 |
| **資産化 / 育てるAI** | 単発のチャットで終わらず、やり取りの履歴や作成した成果物を特定のフォルダに蓄積し、`claude.md` を更新し続けることで、時間とともに自分好みに最適化されていく運用の考え方。 |
| **アイドルスリープ防止** | スケジュールされたタスクを確実に実行するために、PCが自動的にスリープ状態にならないようにする設定。 |
