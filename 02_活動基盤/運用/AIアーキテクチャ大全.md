# AIアーキテクチャ大全

> **目的**
>
> AIを「ツール」として覚えるのではなく、「役割」と「構造」で理解する。
>
> 新しいAIや技術が登場しても、この設計図のどこに位置するかを判断できるようになることを目的とする。

---

# この資料の考え方

AIは単体ではなく、様々な役割を持つ部品の集合体である。

私はそれらを理解することで、

* 自分に最適なAI環境を作る
* AI同士を組み合わせる
* AI導入を分かりやすく説明する
* 将来的な変化にも対応する

ことを目指す。

# AIを理解する軸

AIを理解するときは、次の3つの軸で考える。

## ① 役割

AIは何を担当するのか。

例

* 思考
* 開発
* ブラウザ操作
* PC操作
* 記憶
* 検索
* 自動化
* デザイン
* 文章生成
* 音声
* 動画
* 画像
* 管理
* 指揮

---

## ② レイヤー（階層）

AIはどの階層で動いているのか。

例

人

↓

LLM

↓

AIエージェント

↓

ツール

↓

OS

↓

ブラウザ

↓

Webサービス

---

## ③ 代表ツール

役割ごとの代表的なツール。

例

### AI開発

* Cursor
* Codex
* Claude Code

### AIエージェント

* Dify
* Manus

### ブラウザ操作

* Browser Use
* OpenClaw
* Playwright

### 記憶

* RAG
* ベクトルデータベース

### 外部連携

* MCP
* API
* OAuth

# 学習の基本ルール

新しいAIが登場したら、

①何をするAIなのか

②どの役割なのか

③どのレイヤーなのか

④既存の何と競合するのか

⑤何を置き換えるのか

⑥何と組み合わせると強いのか

を考える。
