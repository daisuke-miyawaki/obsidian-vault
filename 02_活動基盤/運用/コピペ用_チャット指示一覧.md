# コピペ用：チャット指示一覧

## このファイルの目的

新しいチャットでAIに作業を頼むとき、**コピペするだけ**で伝わる文面を集めたもの。

うまくいった指示はここに追記していく。プレイブック（手順の正本）とは別で、**あなたが貼る用の短い文**だけを置く。

---

## 使い方

1. やりたい作業のブロックをコピー
2. `{ }` の中身を自分の内容に書き換え
3. 新チャットに貼り付けて送信

**あると助かる3点（覚えておくと十分）：**

| 項目 | 例 |
|------|-----|
| **何をしてほしいか** | ナレッジ化して／整理して／追記して |
| **参照してほしいやり方** | かくじかんと同じ形式で／プレイブックどおりに |
| **材料・場所** | URL、フォルダ名、ファイル名 |

## YouTube動画のナレッジ化

詳細手順：[[プレイブック_YouTube動画ナレッジ化]]／経緯：[[作業ログ_YouTubeナレッジ化]]

### 1本だけ

```
この動画をナレッジ化して。かくじかんと同じ形式で。
保存先フォルダ：{Obsidian など}

https://www.youtube.com/watch?v=xxxxxxxx
```

### 複数本（次回以降の基本）

```
次の動画をナレッジ化して。かくじかんと同じ形式で（モードB・個別動画）。
保存先フォルダ：{Obsidian など}
本数：{3}本

https://www.youtube.com/watch?v=aaaaaaaa
https://www.youtube.com/watch?v=bbbbbbbb
https://www.youtube.com/watch?v=cccccccc
```

### チャンネル全本（初回・資産化したいときだけ）

```
{チャンネル名}のYouTubeを全動画ナレッジ化して。かくじかんと同じ要領で（モードA）。
チャンネルURL：https://www.youtube.com/@xxxxxxxx
```

## プレゼン・提案資料（毎回このブロックを使う）

正本：[[プレイブック_プレゼン・提案資料]]

```
プレゼン・提案資料の作成です。作業前に必ず読んでから進めてください。
- 02_活動基盤/運用/プレイブック_プレゼン・提案資料.md

必ず守ること：
- 自己肯定感の「2層（表層＝言葉で直接／奥層＝体験で）× 2時間（今＝山場／未来＝回収）」を設計に反映
- 第3・4章に「今」の自己肯定感の山場を入れる
- 心理分析文句（「〜したいのでは」等）は資料に書かない
- ポジティブ表現（§3）を使う
- 完成後、§5 のチェックリストで確認

やってほしいこと：{例：NotebookLM原稿／提案書／構成案 など}
対象：{相手・案件名}
```

## AI学習（別チャット・カリキュラム）

正本：[[カリキュラム_AI学習]]

### 第1回を始める

```
AI学習カリキュラム（改訂版）の第1回です。

まず読んでください：
- 02_活動基盤/運用/カリキュラム_AI学習.md
- 01_人生戦略OS/0900_AI戦略.md
- 02_活動基盤/運用/AIアーキテクチャ大全.md

前提：
- 個人ではDifyは作らない（Cursor中心）
- 目的は時短・仕事・学び。使い方パターンは今後どんどん増やす
- 1回1時間。平易な日本語。最後に自分の言葉で確認してください
- 企業相談の実践・日記の話はこのチャットではしない

第1回：AI全体の地図 を始めてください。
```

### 第2回以降

`カリキュラム_AI学習.md` の「別チャットの進め方」で `{N}` と `{タイトル}` を書き換えてコピー。
