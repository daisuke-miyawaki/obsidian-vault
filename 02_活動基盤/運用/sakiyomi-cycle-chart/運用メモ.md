# マーケティング・先読みサイクル年表 — 運用メモ

## ファイル構成

| ファイル | 用途 |
|---|---|
| `マーケティング・先読みサイクル年表.xlsx` | 正本（Sheet1=データ、Sheet2=年表） |
| `Gem指示文_年表アシスタント.md` | Gemini Gem に貼る指示文 |
| `prompts/bi-monthly-update.md` | 2ヶ月更新の手順 |
| `build_excel_template.py` | テンプレ再生成（初回・壊れたとき） |
| `refresh_bands.py` | データ貼付後に帯を再描画 |

## 段階定義（MBA 4期）

| 期 | 色（年表シート） |
|---|---|
| 導入期 | 薄青 |
| 成長期 | 緑 |
| 成熟期 | 黄 |
| 衰退期 | 灰 |

「入るべき時」「判定」は表に出さない。判断は読んで行う。

## 年表シートの見た目（v0.2）

- **横軸＝年**（データに合わせて自動。例：2007〜2033）
- **太い横棒** … 導入｜成長｜成熟｜衰退が結合セルで1本ずつつながる（期の切れ目に隙間）
- **アメリカ**ブロック（上）→ **日本**ブロック（下）で同じ項目を比較
- 棒の中に「導入」「成長」等の短いラベル
- 各項目の下にヒント行

Numbersでも同じ xlsx の「年表」タブを開く。CSVや「データ」シートは帯は出ない。

## 時間の細かさ（合意：年単位で表示、データは月まで保持）

- **採用：年単位の帯表示**（境界日付は YYYY-MM のまま。帯は年で丸め）
- 成熟期の境界は ±数ヶ月の誤差として許容

## 更新フロー（2ヶ月ごと）

1. Gemに項目名 → Perplexity用・NotebookLM用プロンプト取得
2. リサーチ（NotebookLMは「+ インポート」必須）
3. Gemにステップ2で結果貼付 → CSV取得
4. `データ`シートにCSVを貼る（項目ごと2行）
5. ターミナルで `python3 refresh_bands.py` → `年表`シート更新
6. 旧版を `archive/YYYY-MM.xlsx` に保存（手動）
