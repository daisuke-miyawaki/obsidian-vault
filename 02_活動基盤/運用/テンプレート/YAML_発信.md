# YAMLテンプレ：発信

素材と項目は似るが、**公開・媒体・読者**がある点が違う。

```yaml
---
type: publish
title: 
created: YYYY-MM-DD
updated: YYYY-MM-DD
tags: []
status: draft
related: []
source: 
channel: note  # note | short | podcast | other
audience: 
project:       # 例：筋トレ式引き寄せ / Nguyen物語
stage: idea    # idea | draft | published
---
```

複数媒体がある場合も、まずこの1型で足りる。足りなくなったら項目を足す。
