# YAMLテンプレ：宇宙の法則／心理学・脳科学・潜在意識

本文の並びと「削ってよいか」の正本は [[フォーマット_宇宙心理ナレッジ]]。

```yaml
---
type: material
title: 
created: YYYY-MM-DD
updated: YYYY-MM-DD
tags: []
status: active
related: []
source: 
material_kind: knowledge
topic: 宇宙の法則
本文扱い: 通常
notion_id:

---
```

| 項目 | 意味 |
|------|------|
| topic | 系統。置き場フォルダと一致させる（宇宙の法則／心理学・脳科学・潜在意識） |
| 本文扱い | **作り込み**＝本文を減らさない／**通常**＝普通／**断片**＝ほぼ空 |
| notion_id | Notionから取り込んだときの追跡用。無ければ空でよい |
| status | active＝使える／draft＝下書き／archive＝保管 |

`status` に書く active などは、Vault全体の共通ルールに合わせた分類語です。人に説明するときは「使える／下書き／保管」と言い換えてよい。
