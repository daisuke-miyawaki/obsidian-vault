# フォーマット：学びの歴史（周期）

役割④（学びの歴史。自分の周期・パターンを見る）用の抜き出しノートの正本。

置き場：`03_素材庫/宇宙の法則/学びの歴史/`

関連：[[YAML_素材_宇宙心理]]／前段階：[[フォーマット_学びの歴史_周期抽出]]／相談の入口：[[メソッド一覧_宇宙心理]]

---

## このノートの役割

**繰り返す問題または繰り返す良い状態**として、すでに見えたものを1本にまとめる。  
材料の元は精選日記だが、日ごとの観測は先に `周期抽出_YYYY.md`（[[フォーマット_学びの歴史_周期抽出]]）へ抜き出す。このノートで周期の名前と間隔を書く。

相談のときは、このフォルダの `_index.md` を先に開き、該当する周期ノートを最大2本まで読む。年単位の抽出ファイルは、相談のたびに開かない。

やってはいけないこと：

- 倉庫の生日記を開く
- 精選日記の本文をこのノートへコピーする（日付へのリンクだけ置く）
- 精選日記の全期間を、相談のたびに読み直す

---

## 周期の構造（書くときの共通の骨組み）

世の中の周期の説明に共通する次の4つを、このノートでも使う。

1. **大小の周期が同時に重なる** … 長い周期の中に、中くらい・短い周期がある。1本のノートは、そのうち1階層を主にする  
2. **期間の長さ** … 長期／中期／短期のどれかを書く  
3. **影響の大きさ** … その周期が来たときの影響が、大きい／中くらい／軽いかを書く  
4. **前ぶれ** … 切り替わる前に出る兆しを書く  

---

## ファイル名

`周期_短い名前.md`  
1つの繰り返しにつき1ファイル。短い名前は、人が見て何の繰り返しか分かる言葉にする。

## 項目の意味

| 項目 | 書くこと |
|------|----------|
| 階層 | このノートが扱う長さ。長期／中期／短期のいずれか1つ |
| おおよその間隔 | 実際に繰り返している長さ。分からなければ「不明」 |
| 影響の大きさ | 来たときの影響。大きい／中くらい／軽い |
| 重なっている長い周期 | この周期を含む、より長い周期。なければ「なし」 |
| この中の短い周期 | この周期の内側で繰り返す、より短い周期。なければ「なし」 |
| 前ぶれ | 切り替わる前に出る兆し |

分類欄の `階層` と `影響の大きさ` は、基本情報と同じ内容を短く置く（一覧や検索用）。
