# Marp設定・トラブル解決マニュアル（Cursor環境版）

本書は、Cursor（Mac環境）においてMarkdownファイルからMarpスライドプレビューを正しく表示させるまでの手順、今回発生した問題の原因、および今後再発した際の具体的な対処法をまとめた完全マニュアルです。

---

## 1. 今回のトラブルの全体像（何が起きていたのか？）

当初、「Marpの拡張機能を入れても背景が黒いまま、白いスライド形式に描画されない」という問題が発生していました。

### 根本的な原因
Marpのシステム的な不具合ではなく、「スライドを表示するための専用画面（プレビューウインドウ）」がまだ右側に開かれておらず、文字を入力する「エディタ画面（黒背景）」だけをずっと見ていたことが原因でした。

Marpは、「左側に文字を入力する画面（エディタ）」「右側にスライドを描画する画面（プレビュー）」という2つの画面に分割して使うという基本構造を見落としていたため、うまく進まない状態になっていました。

---

## 2. なぜうまくできなかったのか？（3つの原因の紐解き）

原因は大きく分けて以下の3点にありました。

### ① プレビュー画面が開いていなかった（最大の盲点）
Cursorの画面が1つ（黒い画面）しか開いておらず、Marpが裏側でスライドを描画する準備を完了していたにもかかわらず、それを映し出すための「右側のウインドウ」が出現していませんでした。

### ② HTML要素の制限（セキュリティ競合）
Cursor（VS Codeベース）の標準機能が、Marpのデザイン（CSSやHTML）の描画を危険なコードと誤認してブロックしていました。これにより、プレビューを開こうとしても「うんともすんとも言わない」状態になっていました。

### ③ 言語モードが「Markdown」として認識されていなかった可能性
ファイル作成時、Cursorがそのファイルを「ただのテキスト（Plain Text）」と認識していると、Marpの機能（プレビューを開くボタンやショートカット）自体が完全に無効化されてしまいます。

---

## 3. 正しい画面の構造と呼び方

トラブルを防ぐために、まずはCursor内の画面の呼び方と役割を正しく理解しておきましょう。

* エディタ（左側の黒い画面）
  * チャットの左側にある、実際に文字や設定コード（marp: true など）をタイピングして打ち込むメインの編集画面です。
* プレビュー（右側の白い画面）
  * エディタに書いた内容がリアルタイムに連動し、真っ白なスライド形式（1枚目、2枚目...と縦に並ぶ形）で映し出される確認用の画面です。

---

## 4. 次回から一発でうまくやるための「Cursor操作」

今後、新しくスライドを作成するときは、画面のボタンを探し回る必要はありません。以下の「Cursor操作（コマンドパレットを使ったキーボード操作）」を行うだけで、一発で確実にYouTubeと同じ3分割（エディタ・プレビュー・パネル）の画面を呼び出せます。

### 【ステップ 1】先頭の「3行」を必ず書く
新しいファイル（例：slide2.md）を作ったら、必ずファイルの1行目から以下を正確に入力してください。これがMarpを起動させる鍵になります。
---
marp: true
---

### 【ステップ 2】Cursor操作でプレビューを右側に開く
1. キーボードの「Cmd + Shift + P」を同時に押して、画面上部に検索窓（コマンドパレット）を出します。
2. 検索窓に「Marp」と入力します。
3. 候補の中から「Marp: Open Preview to the Side」（横にプレビューを開く）を選んでエンターキーを押します。

★これだけで、画面が左右にパッと分割され、右側に白いスライドプレビューが出現します。（※ショートカットキー「Option + V」を押すだけでも同様に開くことができます）

---

## 5. また動かなくなったときの「3大対処法」

もし次回以降、上記の手順をやっても右側にスライドが開かない、あるいはデザインが崩れた場合は、以下の3つの対処法を上から順番に試してください。

### 対処法①：右下の「言語モード」を確認する
* 症状：Cmd + Shift + P を押してもMarpのコマンドが出てこない、または Option + V が効かない。
* 解決策：Cursor画面の一番右下のフチを見てください。そこに Plain Text と書いてあれば、そこをクリックして Markdown に変更してください。ファイル名に必ず .md をつけて保存することでも解決します。

### 対処法②：Marp機能を強制的にオンにする（Toggle機能）
* 症状：プレビューは開いたが、スライドの形にならず、ただの縦長の文字の羅列になってしまう。
* 解決策：
  1. Cmd + Shift + P を押す。
  2. 「Marp: Toggle Marp Feature For Current Markdown」を選択して実行する。
  3. これにより、Cursorに「このファイルをMarpモードとして処理しろ」と強制的に命令できます。

### 対処法③：HTMLの許可設定（今回設定した箇所）を確認する
* 症状：スライドの一部（画像や特定のデザイン）が白く描画されない。
* 解決策：
  1. Cmd + Shift + P を押し、「Preferences: Open User Settings (UI)」で設定画面を開く。
  2. 検索窓に「Marp HTML」と入力する。
  3. 「Markdown › Marp: HTML」の設定項目を default から all に変更する。

---
このマニュアルの手順（特に Cmd + Shift + P からの Marp: Open Preview to the Side）さえ覚えておけば、今後どのようなスライドファイルを作成しても、迷うことなく確実にスライド作成を開始できます。
