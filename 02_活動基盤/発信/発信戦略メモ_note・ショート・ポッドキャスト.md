## 3. 発信の全体設計（ファネル）

```
ショート動画（集客・拡散・各種SNS）
     ＋
note（検索・文章で信頼・概要）
     ↓
ポッドキャスト（深い信頼づくり・本命コンテンツ）
     ↓
利益（会員 / 直接教える / その他 ※後から設計）
```

### 各媒体の役割

| 媒体 | 役割 | 儲け |
|---|---|---|
| ショート | 切り抜き・フック・拡散 | しない（集客のみ） |
| note | ポッドキャストの魅力的な概要・検索流入 | しない（集客のみ） |
| ポッドキャスト | 信頼の中心・深いコンテンツ | 微益程度（本丸ではない） |
| 利益の場 | 濃いコア向け | ここで取る |

---

## 4. コンテンツ制作の流れ（効率化）

1. **ポッドキャストを本命で力を入れて作る**
2. 自分の声を録音 → **AIで自分の声に変換**（自分の声でAIが話す）
3. ポッドキャストの**概要・魅力的な要約** → noteに発信
4. **もっと切り抜き的な部分** → ショートで各種SNSに展開

→ 1本のポッドキャストから note＋ショートが作れる。**手間が少ない設計**

### AIの声について
- 別人のAI声ではなく**自分の声のクローン** → 信頼づくりとの矛盾は小さい
- ニュースチャンネルではひどいデザイン＋AI声でも伸びた実績あり
- AIは主役にせず、**整理・要約・台本・下書き**の補助として使う
- 大事な回は生声を混ぜる選択肢もあり

---

## 5. コンテンツの中身（宇宙の法則）

### 宇宙の法則とは（宮脇大輔モデル）
- 一般的な引き寄せ・波動・スピ系とは**別物**
- 世界全体の仕組みを理解する**統合モデル**
- 心理・脳科学・潜在意識・運・AIなどを一つの地図として扱う
- 目的は願望実現ではなく**「本来の自分に戻ること」**
- 人生戦略OSの**最上位概念**

### 独自性の源泉
1. **宇宙の法則の統合的理解**（他にない深さ）
2. **成功者への直接取材**（普通の人ができないネタ）
3. **宗教っぽいコア感** → のめり込んで長く見続けてくれる層がいる

### 需要への懸念と対策
**懸念：**
- 目先の願望（お金・恋愛）に流れる人が多い
- 幸せ・価値観・悟りに近い話は、ある程度成長してからでないと刺さらないかも
- 全員向けではない → 需要は狭い

**対策（入口と中身を分ける）：**

| 場所 | 話す内容 | 狙う人 |
|---|---|---|
| ショート / note | 成功者の本音、「なぜ満たされないか」など | 今は願望層でも違和感がある人 |
| ポッドキャスト | 宇宙の法則・価値観・深い話 | 成熟した層・コア |

**入口の例：**
- 「月収100万の人が、なぜ不幸だと言ったか」
- 「引き寄せが効かなくなる瞬間」
- 「お金は増えたのに、なぜ虚しいのか」

→ 取材の一言を軸に、深い話へつなげる

## 6. 過去の実績と注意点

### ニュースチャンネル（5万人・最大60万再生）
- **宇宙の法則とは全く別ジャンル**
- 楽して5万人、AI声・粗いデザインでも伸びた
- ちゃんと内容を考えていたのに**アカウント削除**された

### 教訓
- ニュースの数字を**そのまま宇宙の法則に当てはめない**
- プラットフォーム任せは危ない → **リスト（メルマガ等）を持つ意識が必要**
- 爆発的な数字より、**コアがのめり込む設計**の方が合っている

## 7. 収益について（方針のみ。詳細は未設計）

| 手段 | 評価 |
|---|---|
| Podcast広告等 | 微益。狙わない |
| 会員ビジネス | 面倒（更新・解約・コミュニティ管理） |
| 直接教える | 単価は高いが、変な人が来るリスクあり → **絞って受ける** |

- 利益の本丸は**ポッドキャストで信頼ができた先**
- 会員が面倒なら、**狭く絞った直接教える**で十分
- 変な人対策は後からでもよい（紹介制・事前ヒアリング・高単価で門を狭く）

## 10. note・ショートの「持続期間」見立て（2026年6月時点）

### 結論
「秋から1年でかなり終わり」より、**ゆっくり効きにくくなる（2〜3年）**が現実的。  
ただし**楽に伸ばす時期**はもう短い。

| 手段 | まだ使える期間 | 落ち方 |
|---|---|---|
| **ショート** | 形式自体はあと2〜3年は主力 | 秋に急落ではなく、**半年ごとに少しずつ難しくなる** |
| **note（集客用）** | 1〜2年はまだ使える | 稼ぎ方系は既に厳しい。独自ネタはもう少し長持ち |

### 目安
- **2026年内**：note＋ショートを本気で回す価値あり
- **2026年末まで**：ショートは「まだ楽」
- **2027〜2028年**：同じ手間で取れる再生・流入はだんだん減る
- **2027年以降**：入口の効率は下がるが、手間が少なければ**継続してよい**
- **遅いのは2027年後半以降に初めて入口だけ頼る場合**

### 長持ちする理由（自分の場合）
- 引き寄せの焼き直しではない
- 取材は他にないネタ
- ポッドキャスト1本から note＋ショートを作れる
- コアがのめり込む → リスト・ポッドキャスト側が本命資産

## 11. AIからの主要アドバイス一覧

1. noteを入り口の1つにするのは**アリ。今から始めてよい**
2. ショート＋noteの二段構えは、note単独より強い
3. ショートで伸びても、**導線がなければポッドキャストに来ない** → 毎回明示
4. 自分の声のAIクローンなら、信頼づくりとのねじれは小さい
5. 深い話は需要が狭いが、**入口を「願望の隣」にすれば戦える**
6. 宗教っぽいコアの深さは**最大の武器**（変な客リスクもセット）
7. ニュースの成功は別ジャンル。**過信しすぎない**
8. アカウント削除の教訓 → **リスト化は必須**
9. 利益は「広さ」より「コアの濃さ」で取る設計が合っている
10. 取材コンテンツは**副ではなく主役**にする
