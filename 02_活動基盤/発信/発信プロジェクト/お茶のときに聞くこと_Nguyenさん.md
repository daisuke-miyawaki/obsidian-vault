# お茶のときに聞くこと：Nguyenさん

作成日：2026年6月28日  
予定：Nguyenさん日本来訪時のお茶

---

## 1. このお茶の目的

1. **発信の許可**をもらう（最重要）
2. 第1回ポッドキャストの**ネタ**を集める
3. 20年の付き合いを活かし、**自然な会話**の中で聞く

堅い「取材させてください」ではなく、**信頼している友人への相談**のトーンで。

---

## 2. 許可について聞くこと（必須）

友達に相談する感じで、軽くでOK：

1. 「あなたの話、他の人にも役立つと思うんだけど、発信してもいい？」
2. 「名前はNguyenさんでいい？ もっと隠したい部分はある？」
3. 「どこまで話していい？（資産・病気・家族・場所の名前など）」
4. 「嫌なら、いつでも止める。それで大丈夫」

**4つ目が一番大事。** 信頼関係があるからこそ、安心して伝えてもらう。

### 確認したい公開範囲（チェック用）

- [ ] ベトナム人・実業家であること
- [ ] ハノイ・ダナンに不動産があること（地名の詳細度）
- [ ] ビル一棟・富裕層であること（具体的な金額）
- [ ] 病気の話
- [ ] 幸せそうにない・空虚さの話
- [ ] 宇宙の法則を学んでいること
- [ ] 毎週電話していること
- [ ] 写真・映像の使用
- [ ] お茶中の会話の録音・ボイスメモ

---

## 3. 物語のネタとして聞くこと

許可が出たら、自然な流れで：

### 生い立ち・成功
- 子どもの頃、お金はどんな意味だったか
- どうやって今の地位・資産になっていったか
- お金が増えるにつれ、何が変わったか（良いこと・悪いこと）

### 空虚さ・病気
- いつから「幸せそうじゃない」と自分でも感じたか
- 病気になったとき、何を考えたか
- お金も時間もあるのに、何が足りないと感じるか

### 宇宙の法則
- 宇宙の法則に興味を持ったきっかけ
- 学んでから、何か変わったことはあるか（小さくても）
- なぜ毎週電話してくるのか（素直な理由）
- 最近特に聞きたいことが増えたのはなぜか

### 今回の来日
- 日本に来て、今何を感じているか
- 宮脇の発信の話をしたら、どう思うか
