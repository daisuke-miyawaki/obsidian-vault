## 1. なぜNguyenさんの物語が中心か

これは「取材した話」ではなく、**宮脇だけが語れる本物の物語**。

| 普通の発信 | Nguyenさんの話 |
|---|---|
| 成功者の名言切り抜き | **数年〜20年近くの深い付き合い** |
| 「お金持ちは不幸」という一般論 | 弁護士（年収数億）が**生前に例外なくそう言っていた** |
| 1回きりの取材 | **毎週電話が来る・これからも続く** |
| 日本だけの話 | ハノイ・ダナン・国際的な視点 |

発信設計の「表は成功者の本音、奥は宇宙の法則」と**完全に一致**する。

---

## 2. Nguyenさんについて（メモ）

### 関係性
- **付き合い：もうすぐ20年**
- 宇宙の法則を**数年前から**教えている（有料コンサル含む）
- **1週間ほどベトナムで一緒に旅行・滞在**した経験あり
- **かなり信頼**されている
- **毎週電話**がかかってくる（ベトナム在住）
- 最近特に宇宙の法則への興味が強い
- 宮脇の活動についても聞いてくる

### 2026年6月
- **昨日（相談時点）日本に来日**
- **近々お茶**の予定 → 発信の許可確認の好機

### プロフィール（発信用メモ・要許可確認）
- ベトナム人・富裕層
- ハノイの高級住宅街に**自宅のビル**を持つ
- 各地に不動産（**ダナン**にも好タイミングで複数）
- ダナンの不動産で悠々自適に過ごすことも
- **お金も時間もあるが、幸せそうに見えない**（長年の印象）
- **病気**になった経歴あり
- 名前：**Nguyen**（どこにでもいる名前 → 匿名としても自然）

### 発信での名前
- 本人OKなら「Nguyenさん」のまま使用可
- より隠す場合も「Nguyen」は一般的なので違和感が少ない

## 3. 弁護士先生（哲学のアンカー）

### プロフィール
- **名古屋で有名な弁護士**（故人）
- 年収**約7億円**規模の個人弁護士
- 大きなお客さん、テレビニュース、ラジオ、弁護士会役員
- Nguyenさんとは**取材レベルではなく、かなり深い付き合い**があった
- 伝えたいことが**かなりある**

### 生前の言葉（番組の憲法）
> **「例外なく、お金持ち成功者は不幸だ」**

### その後
- 本人も病気になり、**不幸な状態で亡くなった**

### 発信での使い方
- 各回の冒頭で30秒程度、敬意を込めて触れる
- Nguyenさんの物語が、この言葉の**生きた証明**として機能する
- 故人なので、家族・関係者への配慮が必要

## 4. クラウド大富豪（シーズン2・温存）

- Nguyenさんの**紹介**
- 宮脇より**若い**
- **クラウド**で大富豪になった
- **人が良い**
- まだ生きている
- 第1シーズン（Nguyen物語）が軌道に乗ってから投入

---

## 5. 番組の骨格（確定案）

```
表：Nguyenさんの物語（連載・メイン）
裏の流れ：弁護士先生の「成功者は不幸」という問い
奥：宇宙の法則（気づいた人だけが深く入る）
```

### 製作側の意図
- 表向きは**人間ドラマ**として見ても面白い
- 裏で**宇宙の法則が何気に学べる**流れ
- 無理に「宇宙の法則」を前面に出さない

---

## 6. 連載の切り口（エピソード案）

### ポッドキャスト
| 回 | テーマ（案） |
|---|---|
| 第1回 | ビル一棟持ちの男が、なぜ毎週日本に電話してくるのか |
| 第2回 | 子どもの頃〜お金が増えるほど何が消えたか |
| 第3回 | 病気になって気づいたこと |
| 第4回 | 宇宙の法則を学び始めたきっかけ |
| 第5回 | 学んでから、何が変わり始めたか（変化の途中経過） |
| 第6回 | ダナンで悠々自適なのに、何が足りないのか |

### ショート（例）
- 「ダナンに別荘を持つ男が、毎週日本に電話してくる理由」
- 「ビル一棟持ちの人が、宇宙の法則を学び始めたきっかけ」
- 「お金も時間もあるのに、笑顔がない理由」

## 7. 許可・倫理（必須）

20年の信頼があるので、**どんな話でも聞ける可能性は高い**。  
それでも発信する場合は確認が必要。

- 資産・病気・家族など、**どこまで公開OKか**
- 名前はNguyenさんでよいか
- **いつでも止められる**ことを伝える
- クラウド大富豪・弁護士先生についても同様（別途）
