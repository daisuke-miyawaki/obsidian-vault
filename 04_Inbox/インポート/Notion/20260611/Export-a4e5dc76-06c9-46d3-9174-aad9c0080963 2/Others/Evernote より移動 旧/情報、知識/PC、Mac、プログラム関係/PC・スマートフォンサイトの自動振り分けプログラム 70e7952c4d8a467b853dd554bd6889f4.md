# PC・スマートフォンサイトの自動振り分けプログラム

タグ: スマートフォン, プログラム, 振り分け
作成日時: 2012年1月24日 11:52
更新されました: 2012年1月24日 11:53

PC向けなどの会社ホームページにアクセスしていただいた際に、自動でスマー

トフォン用サイトに転送する方法をご紹介しています。今回は「Javascript」を使用します。

これにより、iPhoneやAndroid携帯などで、見やすいスマホ専用サイトを表示できます。

【 Javascriptでのリダイレクト設定 】

一番手軽な、Javascriptで転送する方法です。下記のソースをPC用のホームページテンプ

レートに記載しましょう。

<script type="text/javascript">

if ((navigator.userAgent.indexOf('iPhone') > 0 &&

navigator.userAgent.indexOf('iPad') == -1) ||

navigator.userAgent.indexOf('iPod') > 0 || navigator.userAgent.indexOf('Android') > 0) {

location.href = '/smartphone/';

}

</script>

＊ ↑↑↑↑↑　上記のソースをコピーして使用してください！！ ↑↑↑↑↑
