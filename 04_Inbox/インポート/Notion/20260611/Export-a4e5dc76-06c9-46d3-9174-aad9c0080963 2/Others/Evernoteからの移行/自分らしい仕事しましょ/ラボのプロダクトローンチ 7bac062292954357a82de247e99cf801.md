★どんなブランディング？

★自分らしいブランディングの流れ

自分を知る → 分析 → 自分のサービスがある：そのサービスのスパイスに自分らしさを入れる   自分のサービスがない：それを中心にサービスを大まかに作る → 来て欲しくないお客さんを決める → 来て欲しいお客さんを決める → 来て欲しいお客さんを具体的にできれば1人（絞る）決める、居ない場合は人物像を詳細に決める → そのお客さんの悩みを書き出す → どうなれば解決されるかを考える → お客さんが悩んでいて、右葉曲折の末にあなたのサービスで解決されて、喜んで感謝してくれるストーリーを考える→ それを具体的にあなたらしく解決する方法をサービスに入れる →  ブランドピラミッドを作る → サービスが手段になる → あなたに依頼する具体的なメリットを考える → それを抽象化してどんな、ウオンツとニーズがあるかを考えコンセプトを作る → それを生かして自分はどんな人をどのように助けたいかをミッションにする → そのミッションを遂行する自分のイメージの特徴をまとめる → 具て具体的にする（色、雰囲気、誰、音、イメージなど） → それらを文章やデザインに反映させる
