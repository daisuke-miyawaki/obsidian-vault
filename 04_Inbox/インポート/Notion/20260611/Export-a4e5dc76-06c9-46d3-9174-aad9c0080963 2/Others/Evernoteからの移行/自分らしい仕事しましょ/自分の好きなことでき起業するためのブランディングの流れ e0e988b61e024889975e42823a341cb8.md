# 自分の好きなことでき起業するためのブランディングの流れ

作成日時: 2016年2月7日 12:27
更新されました: 2022年12月13日 11:37

質問に答えていくと、起業で重要な、差別化、ポジショニング、キャッチコピー、ブンドイメージ、信頼度・安心度アップ、お客さん選びなど、ブランディングの設計図ができます。

自分の好きどんなサービスで起業するかを考える → 自分のサービスを求めるお客さんを決める → そのサービスにライバルがいるか考えてみる →

→ いた場合お客さんの悩みを絞り込む → そのサービスにライバルがいるか考えてみる → いた場合お客さんの悩みを絞り込む →

→ 提供するサービスの軸を作る（コアバリュー） →  個性を抽象的にイメージできるものを決める（人、感覚、色、雰囲気、OOOのいような） →

→ お客さんの解決される具体的な悩みを文章にする → それを実現する方法を文章にする → それを客観的に証明できる証拠を見つける →

→ コンセプトをデザインでどう表現するか決める（キャッチコピー、ロゴ、イメージカラー） → ツールで表現 → 名刺、HP、ブログ、封筒 など

変化しないブランドは劣化します。

常にお客さんと、時代に合わせて、ブランドを進化させましょう。

商品のクオリティ、見せ方、信頼・安心度を常に向上させていきましょう。
