# どんな時代でも集客できる広告作り　基礎編

作成日時: 2013年11月27日 11:54
更新されました: 2022年12月13日 11:38

★1phase

◎集客のを自動化する仕組みを作りましょう。

◎あなたの商品価値と信用があがるブランディング。

◎お客さん目線で集客をしましょう。

★2phase

◎集客を自動化する仕組みを作りましょう。

※代表：営業活動　→　代表：集客の仕組み作り、管理

大手企業の場合は管理職、中小企業これから増える個人事業主の場合は、代表が営業活動を行う事で、本来は行うはずの仕組み作りや管理ができない事はよくあります。やはり目先の売り上げは重要なので、どうしても即 売り上げに繋がらない仕組み作りにはなかなか手が付けられません。

※常に追いかける集客　→　自然と集客

もし、常に追いかける集客をされていましたら、ゆったりと自然とお客さんが増えるような、集客の自動化の仕組みを作ってはいかがでしょうか？
集客の労力は大幅に減り、世の中の状況が変わっても、対応しやすくなります。

不況で収益が伸びない事を社会や政治のせいにして、ストレスから逃げる方法もありますが、今この動画を見え頂いているような、賢明なあなたなら、自分の力で環境の変化にも対応できる集客の仕組みを作る事ができると思います。

※見込み客を集め　→　サービスを紹介、購入　→　アフターフォロー　→　リピート　→　ファン化

ほとんどの業種の流れは、見込み客を集め、サービスを紹介して、購入してもらった後に、アフターフォローをし、リピートに繋げ、よりコアなお客さんになってもらう事で流れができます。現在お客さんの財布の紐はともて硬く、広告をしてもなかなか、購入に結びつきません。ですので、それぞれの戦術でより工夫が必要になります。

◎あなたの商品価値と信用があがるブランディング。

◎お客さん目線で集客をしましょう。

※bad：予想的イメージ、好み　good：お客さんの気持ち

ほとんどの場合お客さんの目線ではなく、自分達のあやふやなイメージや、好みで広告を作ってしまします。どうしても固定概念が入ってしまい、直接お客さんに接していても勘違いする事はよくあります。デザイン、コピーライト流れ作り、などサービス購入の決定権を１００％持っているお客さんの気持ちで、広告を作りましょう。

良い方法は、今いるお客さんの中で、一番、長期的に考えてよいお客さんを一人選び、その人を見本に考えるとイメージしやすくなります。例えば、ゴルチェさんがもし、サービスを利用してもらっていないとしたら、突然サービスを紹介するのではなく、あの事を悩んでいると思うから、ゴルチェさんにはこういう言い回しのキャッチコピーで、悩みを解決できる事を伝え、この点を心配すると思うから、この点とこの点を詳しく説明し、こういう文字でこういう色味の方が受け入れてもらえる、あとはその人になりきるイメージ力です。
