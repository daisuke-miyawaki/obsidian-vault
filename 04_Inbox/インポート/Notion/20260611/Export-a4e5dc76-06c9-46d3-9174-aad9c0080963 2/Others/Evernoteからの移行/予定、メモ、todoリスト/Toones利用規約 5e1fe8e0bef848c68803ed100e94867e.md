# Toones利用規約

作成日時: 2016年4月25日 13:17
更新されました: 2016年4月25日 13:17

ビジネスサービスポータルサイトの各種サービスを利用する為には、Toones(ツーネス)ビジネスアカウントをご利用いただくには、以下の利用規約に同意して頂く事が必要となります。

・

Toonesとは
Toonesとは、株式会社Karigo（以下、「当社」と言う）の商品やサービスの取引代金決済を、Toonesを通じて銀行振込にて決済購入したポイントを利用し、ポイント決済を行うサービスであり、一時的な商品・サービスのポイント決済だけでなく継続的な（毎月など）サービスなどの代金の自動決済なども行えるサービスです。決済後には、商品の提供や各種有料サービスをToones上から受ける事が可能となります。

・

会員登録について
Toonesを利用するには、事前にToones指定のインターネット上のフォーマットより必要事項を送信し、当社の審査が必要となります。審査に通過した場合にのみ会員登録が可能です。また、お客様の会員登録時のメールアドレスへ確認メールアドレスを送付し、そのメールのURLをクリックする事でアカウントが有効になり会員登録が完了します。また、会員登録前後で審査に通過しなかったお客様に対し、理由の開示などは、一切行いません。

・

会員登録情報について
Toonesをご利用している間に登録情報（会社名、氏名、電話番号、メールアドレスなど）に変更があった場合は、速やかにToones Myページより会員登録情報の変更を行って下さい。会員登録情報を最新の情報にしない事に起因するお客様への不利益は、Toonesでは一切補償致しませんので予めご了承下さい。

・

会員の権利について
会員の権利やID、パスワードを第三者へ譲渡、貸与、担保、開示する事を禁止致します。

・

Toonesポイントについて
Toonesポイントの取扱い等については、別途「Toonesポイント利用規約」に定めます。

・

請求書及び領収書に関して
Toonesビジネスアカウント内のポイント購入ページにて、請求書及び領収書の作成が可能となっております。別途作成が必要な場合は、１部に付き600ptがかかります。

・

会員退会について
会員を退会する場合、当社指定の会員退会フォームから所定の情報を送信し、Toonesから会員退会の旨を承諾したメールを送信した時点で退会が成立するものとします。但し、退会申請時にToonesを通じて利用しているサービス等の解約を事前に行うものとします。また、退会時にToonesポイント残高がマイナスになっている場合は、退会する事ができません。

・

利用料について
Toonesビジネスアカウントのご利用料等は、一切かかりません。但し、今後、サービス内容の変更により有料となる場合もあります。

・

会員情報の開示について
会員が利用規約に違反した場合は、該当する期間や第三者に対し個人情報を問題の解決や再発防止の為、開示する場合があります。

・

利用規約の変更について
Toones利用規約は、会員に事前に通知する事無く変更出来るものとします。また、変更した際には、Toonesホームページ上にて表示致します。

・

サービスの停止などについて
システムメンテナンスやシステム障害、天災などにより一時的にサービスを会員に事前通知する事無く停止する場合があります。サービス停止により会員へ損害が発生した場合でも一切責任を負いません。

・

会員利用の停止と強制解約

下記事項の何れに該当する場合、理由の如何を問わずお客様に事前に通知、承諾を得る事なくサービスの停止、解約、退会を当社にて行います。また、サービス停止、解約、退会の処置によりお客様側に損害が発生したとしても当社は、一切の責任を負いません。

- 登録情報に虚偽があった場合
- 破産、民事再生、会社更生およびこれに準じる信用不安が生じたとき
- 代金の支払いを滞納した場合
- 各種法令、利用規約、ガイドラインに違反した場合
- 会員登録情報のメールアドレス及び電話番号に連絡しても連絡が取れない場合
- 故意、過失を問わず他のお客様や当社に損害を与える行為を行った場合
- 最終ログインから1年が経過した場合
- 料金不足（滞納）等が発生し、30日以上経過した場合
- 当社の全てのサービスにおいて、1度でも契約違反の事実があった場合

・

免責
Toonesを通じて発生したいかなる損害について当社では、一切責任を負わず補償も致しません。会員がToonesの利用資格を失ったために代金決済を実行できなくなったことに起因して損害が生じた場合にも、当社は理由の如何を問わず、当該会員に対して、賠償する責任を一切負わないものとします。

・

責任範囲
代金決済サービスの購入又は、利用される商品やサービスについては、各商品・サービス提供者との契約内容に従って商品・サービス提供者が責任を負うものとします。利用規約に別段の定めのある場合を除いて当社は、購入又は利用される商品・サービスについては、一切保証をしないものとします。

・

損害賠償
お客様、若しくはお客様に関係のある第三者に起因して当社が損害を被った場合には、その損害の賠償を会員及び第三者が連帯して当社の損害を賠償する義務を負います。

・

債権譲渡
お客様が当社に対して支払いを遅滞した場合、当社はその債権を第三者に自由に譲渡できるものとします。

・

運営について
当社は、会員へ事前通知する事無く自由に第三者へ運営を委託、譲渡出来るものとします。また、当社の事業戦略や経営状態によって、サービスを終了する場合があります。
