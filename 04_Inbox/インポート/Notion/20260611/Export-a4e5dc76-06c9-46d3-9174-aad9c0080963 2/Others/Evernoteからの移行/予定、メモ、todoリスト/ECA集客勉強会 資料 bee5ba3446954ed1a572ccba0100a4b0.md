# ECA集客勉強会 資料

作成日時: 2015年12月24日 12:54
更新されました: 2015年12月26日 13:35

★目的

・ECAの集客を皆さんの力をかりて成功させる

その中で

・個々の目的達成の近道

・集客技術の向上

★成功のために

・仕組み作り（役割分担、スケジュール）

・自分の得意分野や、目的達成に関わることをお手伝いをお願いしたい。

★流れつくりの大切さ

・効率良く集客できる。

・一度流れができると毎回集客に気を取られる事なく、重要な事に力を入れられる。

・安定した集客ができる。

・講座だけでなく、他の商品も販売しやすくなる。

★内容

・目先の集客も重要ですが、安定した集客の流れ作りの大切

見込み前客作り → 見込み客作り → 信頼構築 → 講座申し込み → リピート → ファン化

★ECAの講座への集客の流れ

◎流れ案（見込み前客作り → 見込み客作り → 信頼構築 → 講座申し込み）

A：ツイッター → ブログ → LPメルマガ登録 → メルマガ → 講座告知 → 申し込み

B：ツイッター → ブログ → LPメルマガ登録 → メルマガ → プロダクトローンチ → 申し込み

C：ツイッター → アメブロ → ECAブログ → LPメルマガ登録 → メルマガ → プロダクトローンチ → 申し込み

D：ツイッター（各それぞれ＆ECA） → ブログ（各それぞれ＆ECA） → LPメルマガ登録 → メルマガ → プロダクトローンチ → 申し込み

※ツイッター部分にFacebookも追加してもいいと思います。プロダクトローンチは縦長のLPを小分けして、ギブギブの精神で情報提供し、最後に講座の案内をする手間がかかりますが、成約率の高い技術です。

◎見込み前客作り：ツイッター、ブログ、Facebook、YouTube

・ツイッター→ツイートをBOTに登録（ブログの概要をつぶやき、詳しくはブログにリンクを貼る。bitly（短縮URL）で検証、ECAに興味を持ちそうな人をフォロー）

・ブログ→考え方的なブログを定期的に更新し優良なアクセスを増やす。→記事の下と、サイドメニューの上にLPのバナーを設置

↓

◎見込み客作り：LP→メルマガ登録（現在300人→1,000人を目標）

・PDF、音声でまずは進め、できたら「00日で学べるOO動画講座」などにして、登録率をアップさせる。

・LP対策

↓

◎信頼構築：（メルマガ）

・優良な情報発信（ブログとかぶってもいいと思います。）

・たまに他では発信していない情報を提供できるともっといいと思います。

↓

◎講座申し込み

・LP or プロダクトローンチ

※本当はプロダクトローンチの方が成約率が高いですが、労力がかかります。

★ツイッター

・フォローついて→興味を持ちそうな人をフォロー（数と興味があるかが重要）

・BOTの登録について→ある程度のつぶやきが登録できると、自動でつぶやきます。つぶやきの数に合わせた、つぶきやきの頻度設定

・Bitlyについて→Bitlyを利用することで、ツイッターに短縮されたURLを設置でき、そこからのクリック頻度を検証できます。

★ブログ

・アクセス数ではなく、濃い見込み前客集めが目的です。

・アクセス数が多いことで、より露出が増え、濃い見込み客を集められます。

・ページが多くなるろSEO対策にもなりますが、まずは気にしなくていいと思います。

・内容は考えを伝えるイメージ（日記や細かな技術は別のフェーズで）

★LP

◎基本的な流れ

お客さんのメリット → お客さんの不安 → 解決方法 → 講座でそれができる事を紹介 → どうしてそれが可能か根拠を説明 → それを実証 → 申し込み

★YouTube

・SEO対策が有利（動画１つ＝ホームページ20ページのイメージ）

・検索以外にもYouTubeからも集客（YouTube検索、関連動画）

・信頼度アッップ

・静止画やテキスト文よりコミュニケーションが取りやすい

・閲覧時間アップ、離脱率減少、成約率アップ

・ライバルまだ少なく効果が出やすいが敷居が高く面倒

・特に初期はVSEOが重要

・閲覧が伸びてくると再生回数が重要（1つの動画の再生回数が1万回を超えると伸び率が大きくなります）

・チャンネル登録が増えると伸びが良くなります。（エンディングでチャンネル登録の告知をすると大幅に登録率アップ）

★決めること

・役割分担

・スケジュール
