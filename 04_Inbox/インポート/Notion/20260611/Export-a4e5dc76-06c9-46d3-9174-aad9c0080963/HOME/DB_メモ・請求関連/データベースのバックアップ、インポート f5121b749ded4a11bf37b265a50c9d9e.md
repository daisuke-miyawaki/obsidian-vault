**WP Database Backup（データベースのみが簡単）**

色々なプラグインがあるけど
データベースだけのバックアップを考えると、
**WP Database Backupがいいかも**

はい、データベースのバックアップとインポートができる無料の使いやすいプラグインはいくつかあります。以下におすすめのプラグインを紹介します：

1. **UpdraftPlus WordPress Backup Plugin**:
    - 特徴: データベースのバックアップだけでなく、ファイル、プラグイン、テーマなどのバックアップも可能です。バックアップをクラウドストレージ（Google Drive、Dropbox、Amazon S3など）に保存することができます。
    - URL: UpdraftPlus
2. **WP Database Backup**:
    - 特徴: シンプルで使いやすいデータベースバックアッププラグインです。定期的なバックアップスケジュールを設定でき、バックアップをメールで送信することもできます。
    - URL: WP Database Backup
3. **BackWPup – WordPress Backup Plugin**:
    - 特徴: データベースのバックアップ、ファイルのバックアップ、クラウドストレージへの保存（Dropbox、S3、FTPなど）に対応しています。簡単な設定でバックアップを自動化できます。
    - URL: BackWPup
4. **Duplicator – WordPress Migration Plugin**:
    - 特徴: サイトの完全なバックアップ（データベースとファイル）を作成し、他のサーバーに移行することができます。バックアップファイルを生成してダウンロードするのが簡単です。
    - URL: Duplicator

### 推奨手順

1. **プラグインをインストール**: 上記のリンクから希望するプラグインをダウンロードしてインストールします。
2. **バックアップを作成**: プラグインの設定ページからバックアップを作成します。データベースと必要に応じてファイルも含めてバックアップを行います。
3. **バックアップの保存**: バックアップファイルを安全な場所（ローカルPC、クラウドストレージ）に保存します。
4. **再インストール後の復元**: WordPressを再インストール後、同じプラグインをインストールし、バックアップファイルをインポートして復元します。
