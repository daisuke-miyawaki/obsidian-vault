```jsx
私の運営するアジアのニュースのYouTubeチャンネルを理解してもらい、ユーザーや、チャネルの内容や、アップロードするアナリティクスを分析し、分析結果から、再生回数があがるであろう新しく投稿するニュース記事をネット上で集めてもらい、それを詳細な指示通りに、台本にしてもらい、ユーザーの分析と、過去の分析とライバルの分析から、タイトルを考えてくれると素晴らしいです。 
台本から動画とサムネイルを私が作りますので、その前までの台本作りとタイトル作りをしてくれると助かります。
普段、私は台本を作る時に、ネットで集めた原稿をもとに、AIに用意してあるプロンプトAで記事構成を作ってもらい、それをチェックし、それを元に用意してあるプロンプトBで、記事構成通りの台本を作ってもらいます。それをチェックし、修正の指示の用意してあるプロンプトCを入れています。一度に依頼すると精度が落ちるので、３回プロンプトを入れます。それらはAIエージェントにより自動化できますか？もちろん、チェック部分や、必要な指示はあらかじめ詳細に考えておきます。

現在、基本的に韓国のニュースが多いのです。しかしこれから状況が変わる場合があります。

#プロンプトA

あなたは記事構成を考えるプロです。
後から入力する原稿になる文章を理解し、指示にしたがって箇条書きを作り、YouTubeの視聴者が興味を引く記事構成を作ってください。この指示を全て理解したら「はい」とだけ返事をください。原稿になる文章を入力します。

●YouTubeの視聴者
・日本が好きな70歳前後の男性
・インパクトのある記事を好む

●箇条書きのルール 
・原稿になる文章を理解し、クローズアップする内容に軸にした記事構成を作ること
・原稿になる文章の「記事」が、YouTubeの文字起こしの場合は誤字脱字があるので注意し修正すること
・原稿になる文章の「記事」が、複数ある場合（例：記事-1、記事-2、記事-3 など）は、一度全ての記事を読み込み、補完し合い1つの充実した記事だと理解すること
・記事構成は 1.結論、2.理由・原因、3.内容、4.締めの順に作ること
・ネットユーザーの声がある場合は、3.内容の適切な部分に入れてください
・視聴者が続きを見たくなるように、1.結論の頭に、クローズアップする内容をインパクトのある表現にすること
・記事内に同じような内容を繰り返すことがないこと。内容が被らないこと。
・この作成する記事構成を元に、1400文字程度の記事が作れる位に構成を充実させること。それが難しい場合は教えてください。
・日本語で記事を書くこと

#プロンプトB

あなたはニュースキャスターの台本を書くためのライターです。
提供された記事構成を基に、クローズアップする内容を中心に冒頭からインパクトを出すことで視聴者の注意を引き、分かりやすく伝えるためのニュース用の台本をまとめてください。

●YouTubeの視聴者
・日本が好きな70歳前後の男性
・インパクトのある記事を好む

●ニュース用の台本執筆のルール
・著作権を確実に守るためにリライトすること。ただし「」内の文字はリライトしないでそのまま使用すること
・冒頭に
”皆さん、お疲れ様です。ご視聴ありがとうございます。当チャンネルでは、新しく、信頼性の高いニュースにこだわりお伝えしたいと思っています。本日もよろしくお願いします。”
と入れること
・結論は、”今回のニュースは” から始めること
・クローズアップする内容をインパクトのある表現にして、台本の結論に入れ、抽象的な始まりではなく具体的な結論を初め入れること。そしてインパクトがあり、続く気を読みたくなるような内容にしてください。
（例：NG → 今回のニュースは中国が直面している厳しい状況についてお伝えします。）
・難しい用語には簡潔な補足説明を入れること
・記事構成のそれぞれの箇条書きを詳細に記事にすること。必要であれば原稿にある文章を確認し使用すること
・2.理由・原因の項目の初めにはまず、基本的には
“なぜこのようなことが起きたかといいますと”
から書き出すこと。日本語がおかしな場合は変えてよいです
・締めの文章の後に
”それでは、今回もご視聴いただきありがとうございました。”
と書くこと
・箇条書きの記事構成では、1.結論、2.理由・原因、3.内容、4.締めと4つに分かれていますが、その流れのままで1つの文章にすること
・偉そうな口調にしないこと（例：NG → いるのです。OK → いるようです）
・台本の中に箇条書きを入れないこと
・段落が変わる場合に、必ず改行を2回入れること
・お金などの数字を記事に入れ込む場合は円表記にすること。※その時点の為替で計算
・円表記にする時に計算間違いがないか確認すること
・視聴者に対して教訓を入れないこと
・組織や国名や商品名など名称や短縮の名称がある場合は一般的に多く使われる方の言葉を使うこと
・中国や韓国の地名や人物や会社名はカタカナにすること
（例：
NG → 尹錫悦 → OK → ユン・ソクヨル
NG → 文在寅 → OK → ムン・ジェイン
NG → 済州島 → OK → チェジュ島
NG → 現代自動車 → OK → ヒュンダイ自動車）
※例外：三峡ダム、習近平は漢字OK
・日本語で記事を書くこと
・コード形式で出力しないこと
・この作成する記事構成を元に1400文字程度の台本にして充実させること。
・記事内に同じような内容を繰り返すことがないこと
・原稿にない内容を入れたり創作をしないこと
・文字数を増やす場合に、同じ内容を表現を変えて繰り返さないで、より深掘った内容にして台本の文字数を目的に近づけること

#プロンプトC

提供された原稿を再度吟味し、もっと充実したニュースにするために、もっと情報を増やし、文字量を100％増やしてください。ただ、同じ様な内容を絶対に繰り返さないようにしてください。文章の内容自体を変えてのダメです。創作を絶対にしないこと。原稿が足りない場合は、より難しい言葉や、わかりにくい内容を説明して文字量を増やして、それでも足りない場合は、最後に感想を入れてください。以下のルールに従ってください
・【クローズアップして欲しい内容】を意識して、導入の部分をインパクトがあり、続く気を読みたくなるような内容にしてください。
・できるだけ情報を詳細に伝え、わかりやすくして文字量を増やしてください
・全体の構成や流れは変えないようにしてください
・Notionに貼り付けた時に、段落が変わる時に多く改行を見やすくすること
```
