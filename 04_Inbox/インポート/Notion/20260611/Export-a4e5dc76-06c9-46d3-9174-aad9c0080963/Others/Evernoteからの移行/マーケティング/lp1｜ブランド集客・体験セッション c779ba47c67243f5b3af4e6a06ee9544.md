# アイデアは出ましたか？恐らく、「もっと安くすればいいんじゃない？」と感じた方がほとんどではないでしょうか？安くしたら、たくさん集客しないといけないのに、なぜ、安売りに走ってしまうのでしょうか？**それは、まさに、あなたの強みを活かした自分ブランドの２つのカギを知らないことにあるのです。**では、次のように、あなたの強みが活かされたらどうでしょうか？

# **STEP1あなたのビジネスの行き詰まりを確認します**

あなたに対して、最適な集客プランをご提案したいので、今抱えているビジネスの悩みやこれまで実践してきたことなど丁寧にヒアリングします。そして、現状の問題点を全て洗い出して、売上のネックを見つけていきます。

# **STEP２売上アップに必要な行動だけに絞り込みます**

問題を明確にして、10個の質問であなた自身を診断。何から取り組むべきか？あなたにとって何が必要か？徹底的にムダを省いて、必要な行動だけに絞り込みます。

# **STEP3あなたの強みを活かした売上アップを伝授**

あなたに共感したお客様の絞り込み、あなたの強みを活かした差別化された商品作り、売り込まずに売れる方法を伝授します。

# **STEP４目標月商を達成するための戦略を立てます**

あなたの自分ブランドを最大限に活かし、目標月商を達成するためのあなたのビジネス戦略を立てることで、これから行動の手順が分かりスッキリするでしょう。
