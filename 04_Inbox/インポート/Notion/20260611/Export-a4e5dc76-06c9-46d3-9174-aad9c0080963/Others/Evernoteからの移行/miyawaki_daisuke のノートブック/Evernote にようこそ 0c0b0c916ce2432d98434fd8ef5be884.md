# Evernote にようこそ

作成日時: 2009年10月20日 17:09
更新されました: 2009年10月20日 17:23
URL: http://www.evernote.com/

| **Evernote にようこそ** |
| --- |
| Evernoteを使えば、考えたことや、見たこと、好きなことを保存できます。そして、それらすべてにどんなコンピュータや端末からでもアクセスできます。 |
| **いくつかの簡単な考えから始めることができます**
• "新規ノート" をクリックして、考えやタスクを記録します。
• Webクリッパーを使用して、Webページをクリップして保存します。
• お使いの電話でEvernoteを使用して、ホワイトボード、名刺、ワインラベルの写真を撮ります。 *Evernoteにより、スナップショット内のテキストが自動的に検索可能になります。***記憶をキャプチャする方法はたくさんあります**
• お使いのすべてのコンピュータと電話にEvernoteをインストール
• WebクリッパーをWebブラウザにインストール
• Evernote用メールアドレスにノートを送信
• [@myEN](http://s.evernote.com/myen)をフォローしてTwitterメッセージを保存
• デジタルカメラから写真をインポート**たくさんの役立つ機能**
• お使いのコンピュータと電話でノートを同期
• 画像内の印刷テキストまたは手書き文字を検索
• ノート、画像、To Do、PDF などを追加
• 友人や同僚とノートを共有
