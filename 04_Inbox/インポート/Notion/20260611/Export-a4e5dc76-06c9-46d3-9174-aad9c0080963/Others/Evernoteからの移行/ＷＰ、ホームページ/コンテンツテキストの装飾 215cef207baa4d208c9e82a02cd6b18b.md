# コンテンツテキストの装飾

作成日時: 2016年6月10日 22:27
更新されました: 2016年6月10日 22:32

★テキストのバックにカラーマーカー

[http://accesstrigger.okaerinasainet.net/?p=10511](http://accesstrigger.okaerinasainet.net/?p=10511)

【　HTML　】

<span class="marker_yellow">任意の文字</span>

黄緑色のマーカー

<span class="marker_lime">任意の文字</span>

水色のマーカー

<span class="marker_water">任意の文字</span>

桃色のマーカー

<span class="marker_pink">任意の文字</span>

オレンジ色のマーカー

<span class="marker_orange">任意の文字</span>

オレンジ色のマーカー

【　CSSへコピー　】

.marker_yellow {

background: linear-gradient(transparent 60%, #ffff66 60%);

}

.marker_lime {

background: linear-gradient(transparent 60%, #66FFCC 60%);

}

.marker_water {

background: linear-gradient(transparent 60%, #66ccff 60%);

}

.marker_pink {

background: linear-gradient(transparent 60%, #ff66ff 60%);

}

.marker_orange {

background: linear-gradient(transparent 60%, #ffa500 60%);

}
