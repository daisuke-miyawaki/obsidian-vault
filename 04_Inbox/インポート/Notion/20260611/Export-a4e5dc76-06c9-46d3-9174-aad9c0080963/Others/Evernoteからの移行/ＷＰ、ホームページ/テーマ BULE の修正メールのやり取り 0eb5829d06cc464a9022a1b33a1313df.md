# テーマ　BULE　の修正メールのやり取り

作成日時: 2016年9月26日 16:30
更新されました: 2016年9月26日 16:31

> 対象サイト（ページ）をスマホで見た場合に、
> 写真が文字の下に回り込まれずに、文字の改行が多くなってしまいます。

cssファイルを直接編集する必要がありますが、
responcive.css　　 705行目あたりに、

.entry img {
float:nonel
}
と追加してください。
これで、上に「画像」が、「下」に商品説明が表示できると思います。

> わかりにくくてしません、ページタイトルの文字をテーマオプションの
>
> h1のサイズで小さくしていました。

 それでしたら、テーマ内のresponcive.css　を直接編集する必要がありますが、
responcive.css　に下記を追加してください。

h2.widgettitle {
line-height:1.6em;
}
改行幅の数値の調整は、1.6 の部分を調整してください。
