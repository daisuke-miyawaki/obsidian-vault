# **こちらはFX自動売買XオーダーのEA設定マニュアルです。**

## 【１】チャートと時間足

**通貨ペアはGOLD（XAUUSDと表記する証券会社もあります）**

**時間足はM1（1分足）で設定お願いします。**

**XMでは「GOLD」**

**FX Fairは「XAUUSD」**

**と表記されているかと思います。**

マイクロ口座ご利用の場合はマイクロ口座用のチャートをご利用ください。誤ったチャートを設定した場合は稼働されませんので注意してください。

## **【２】ロット設定**

### **■マイクロ口座の場合**

**推奨は証拠金5万円で0.1ロットとしています。**

**※3万円で0.1ロットでも平常相場でも十分に運用は出来ておりますが、ややリスクが上がります。**

**※以下参考**

| 資金 | ロット |
| --- | --- |
| 1万円 | 0.02 |
| 2万円 | 0.04 |
| 3万円 | 0.06 |
| 4万円 | 0.08 |
| 5万円 | 0.1 |
| 10万円 | 0.2 |
| 20万円 | 0.4 |

### **■スタンダード口座の場合**

**推奨は証拠金50万円で0.01ロットとしています。**

**※30万円で0.01ロットでも平常相場でも十分に運用は出来ておりますが、ややリスクが上がります。**

**※以下参考**

| 資金 | ロット |
| --- | --- |
| 50万円 | 0.01 |
| 100万円 | 0.02 |
| 150万円 | 0.03 |

**※FX Fairで運用されている方は１００％ボーナスが利用できます。**

**ボーナス利用の場合はボーナスを含めた額で計算してください。**

## **【４】チャート画面の機能について**

![](%E2%98%85%E6%96%B0ver%20X%E3%82%AA%E3%83%BC%E3%83%80%E3%83%BC%E8%A8%AD%E5%AE%9A%E3%83%9E%E3%83%8B%E3%83%A5%E3%82%A2%E3%83%AB/%E3%83%81%E3%83%A3%E3%83%BC%E3%83%88%E7%94%BB%E9%9D%A2.png)

**①消化モードON/OFF**

**こちらの機能はボタン式になります。**

**消化モードをONにすることにより、現在のポジションが決済されたら自動的にEAを停止してくれます。**

**消化モードをOFFの場合は通常通りエントリー＆決済が行われます。**

**また決済時は現在の保有中のポジション群の±0レートの1pipsプラス側にいったところで利確しますので、指標がこの後控えており、早めに決済して停止したい場合にお使いください。**

**②一括決済**

**こちらの機能はボタン式になります。**

**一括決済ボタンを押すことにより現在のポジションを一括決済します。今のレートで手動で損切りしたい時、手動で利確したい時などにお使いください。**

**一括決決済後は、インターバルを3分設けており、その間は新規ポジションをとらないようになっています。**

**ただ3分経過後は新規ポジションのエントリーがされますので、エントリーしてほしくない場合は、その間にEAを停止してください**

**③プラマイゼロレート**

**こちらの機能はモニター用（閲覧専用）になります。**

**現在のポジション群がどこまでいけば±0になるかを分かりやすく表記してくれる機能です。**

**またチャート内に緑色の水平線でも表示してくれます。**

**損切り、利確などの一括決済ボタンと併用しやすい機能です。**

**④強制ロスカットレート**

**こちらの機能はモニター用（閲覧専用）になります。**

**現在のポジション群がどこまでいけば強制ロスカットになるかを分かりやすく表記してくれる機能です。**

**またチャート内に赤色の水平線でも表示してくれます。**

**こちらも③のプラマイゼロレートと同様に、損切り、利確などの一括決済ボタンと併用しやすい機能です。**

**⑤現在の含み損益**

**こちらの機能はモニター用（閲覧専用）になります。**

**現在のポジション群の含み損益を分かりやすく表記してくれる機能です。**

**（）内の数字は現在の含み損益の％を表示してくれます。**

**例えば口座10万円の資金が入っており、現在含み損を1万円抱えていた場合は、**

- **10,000(-10%) と表示されますので、即座に現在の含み損とドローダウンを把握できます。**

## **【５】EAの設定（パラメーター）**

**※スリッページ、マジックナンバーに関してはデフォルトのままで運用してください。**

**設定変更することがないようお願いいたします。**

![](%E2%98%85%E6%96%B0ver%20X%E3%82%AA%E3%83%BC%E3%83%80%E3%83%BC%E8%A8%AD%E5%AE%9A%E3%83%9E%E3%83%8B%E3%83%A5%E3%82%A2%E3%83%AB/%E3%83%8F%E3%82%9A%E3%83%A9%E3%83%A1%E3%83%BC%E3%82%BF.png)

**①初回エントリーのロット数**

**初回のエントリーロットを設定できます。**

**仮にマイクロ口座に5万円の資金が入っていれば推奨ロットは0.1ロットになりますので、「0.1」と入力してください。**

**スタンダード口座で50万円の資金が入っていれば推奨ロットは0.01ロットになりますので、「0.01」と入力してください。**

**②一括決済後エントリーまでのインターバル時間(分)**

**一括決済ボタンの押下後に、すぐにポジションを持たないようにするための機能です。基本的にはデフォルトのまま使用してください。**

**③消化モード時決済判定プラス幅(Pips)**

**消化モードの利確幅を決めます。デフォルトだと1Pipsとなっており、消化モードボタンを押した後に損益が±0レートから1Pipsプラス側にいったところで利確しますので、少額のプラスで早く決済することができます。**

**もちろん値を大きすれば大きなプラスで決済することもできますが、当然リスクも上がります。**

**早期撤退モードと考えていただくのがいいので、基本的にはデフォルトのまま使用してください。**

**④最大ナンピン回数**

**最大ポジション数を制限することができます。最大は20ポジションとなっております。値の数値を変更することで設定が適用されます。**

**⑤ナンピン幅(Pips)**

**ナンピン幅を設定することができます。デフォルトは18pipsとなっております。値の数値を変更することで設定が適用されます。**

**⑥ナンピン時ロット倍率**

**ナンピン時のロット倍率を設定することができます。デフォルトは1.5となっております。値の数値を変更することで設定が適用されます。**

**⑦「月末最終金曜日」と「第一月曜日」の停止**

**こちらの機能は月末・最終金曜日・第１月曜日にエントリーが入らなくなる機能です。**

**この機能の狙いは、週末や月末に機関投資家やヘッジファンドがリバランスの調整をすることがあり、リバランスの調整が入ると一気に相場が動く可能性があるため、リスク回避を狙いとしたロジックです。**

**また、リバランスの調整後、翌週月曜日も大きく相場が動く可能性があるため、第１月曜日も新規エントリーが入らないようにしています。**

**OFFで機能は作動せず、ONで「月末最終金曜日」と「第一月曜日」が稼働されないようになります。**

**⑧経済指標の時間帯自動回避**

**この機能は基本的にはOFFにしていただき、管理が難しい方のみONにしてください。エントリーが極端に制限されます。**

**重要な経済指標が起こる時間帯はエントリーしないようになります。**

**これは実際に指標がある日まではEAの機能では把握できませんので、ONにすると毎日以下の時間がエントリー制限されますのでご注意ください。**

**制限中ポジションが残っている場合、決済ポイントまで到達すれば決済はされます。**

**以下の時間停止されます。サーバー時間での表記です。**

**サマータイム**

**10時〜11時**

**14時〜17時**

**19時〜19:30**

**ウィンタータイム**

**11時〜13時**

**15時〜18時**

**20時〜20:30**

**ONで機能ON（経済指標の時間帯停止）、**

**fOFFで機能OFF（経済指標の時間帯も稼働）です。**

**こちらの機能はモニター用（閲覧専用）になります。**

**⑨曜日・時間停止機能**

曜日ごとに動かすか動かさないか、また時間制限をすることができる機能です。

ONでスケジュール機能が適用され、OFFでスケジュール機能は適用されず、通常通り運用されます。

**MT4時間で設定する必要がありますので、ご注意ください。**

**例えば開始時間を「3」、終了時間を「10」と入力した場合、**

**冬時間でしたら10時〜17時の範囲で稼働されます。**

**時間外になった場合はナンピンは行いますが、現在保有中のポジションが利確されれば、新規ポジションはとらない仕様となっております。**

**⑩テキスト表示設定**

**チャート内に表示する「プラマイゼロレート」「強制ロスカットレート」「現在の含み損益」のテキストの色と文字のサイズを変更できます。**

**⑪サマータイム判定有無**

**「⑧曜日・時間停止機能」の夏時間、冬時間を切り替えるために使用します。夏時間は3月第2日曜日（米国時間）から、冬時間は11月第1日曜日（米国時間）からとなります。**

**必要に応じて切り替えをお願いします。**
