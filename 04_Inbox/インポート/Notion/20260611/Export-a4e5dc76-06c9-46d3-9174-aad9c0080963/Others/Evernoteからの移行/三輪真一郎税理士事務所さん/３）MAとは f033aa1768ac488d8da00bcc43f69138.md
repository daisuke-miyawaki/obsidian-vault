# 商品ライフサイクルを考えると、

# 早く導入した方がいい！→「先行者利益』

例）

- [ ]  たまごっち：いっぱい売れたのに赤字
- [ ]  ランディングページ：個人事業主規模の事業でもホームページが１００万円以上で大喜び

（一番成果のいいお客さん→２ヶ月で４００万円の売り上げ）

MAとはマーケティングオートマチックの頭文字

神田さんの言っていた、お客さんを数値で管理できる。

さらに、その数値に合わせてアプローチできる。

具体的にこんなことができます。

# ホームページの数値で見えてお客さん主導でお客さんが安心でき、

# 自分の代わりに２４時間営業をし続けるメリットと、

# 対面営業の様にお客さんの気持ちに合わせて、

# お客さんが望むアプローチでセールスをしてくれます。
