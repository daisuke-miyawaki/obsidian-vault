# メルマガネタ　量子力学

作成日時: 2018年1月20日 17:05
更新されました: 2018年1月20日 17:33

学生時代に、人間の体は原子の集まりだと習いました。

知っている人も多いと思いますが、

原子は原子核を中心に電子が周りを回っています。

そして、その大きさの差は原子核が１円玉に対して、その回っている周囲は東京ドームほどの大きさらしく、随分と原子核と原子核の間が空いているのがわかります。

そして、これも知っているかもしれませんが、原子核は中性子と陽子でできています。中性子も陽子は素粒子と呼ばれています。

素粒子と言えば、光の素粒子にフォトンと呼ばれているものがあります。

そのフォトンは粒でもあり、波でもあります。

そのフォトンは私達の話す言葉や、思考にものりそれが引き寄せの法則を動かす１部になっています。

素粒子が引き寄せをしているなんて面白いですね。

スピリチュアルな引き寄せの法則が、物理である素粒子で説明され、学校の授業で学ぶ時が来るかもしれませんね。

原子を分解 → 原子核、電子でできている

原子核 → 中性子、陽子、でできている

中性子、陽子 → クオーク でできている

ということは原子は電子、クオークでできている

電子、クオーク → 最小でこれ以上分解できない

（この様にこれ以上分解できない単位を「素粒子」と呼ぶ

この素粒子の研究を量子力学という

（昔は原子が最小単位だったので、原子が素粒子だった。）

常軌を足しても、実際の質量にならない。足りない。

だから、これ以外にも見えないエネルギーがあると言われている

クオークには６つの種類がある（その種類をフレバーという）

・アップ、ダウン、ストレンジ、チャーム、トップ、ボトム
