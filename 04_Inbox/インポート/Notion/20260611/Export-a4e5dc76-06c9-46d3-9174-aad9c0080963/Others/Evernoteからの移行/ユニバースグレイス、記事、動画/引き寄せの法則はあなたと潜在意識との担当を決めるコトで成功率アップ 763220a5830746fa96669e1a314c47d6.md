# 引き寄せの法則はあなたと潜在意識との担当を決めるコトで成功率アップ

作成日時: 2018年11月28日 15:23
更新されました: 2018年11月28日 17:03

今回は、

引き寄せの法則で、

あなたと潜在意識との役割をきちんと決めて、

成功率アップさせる方法について説明します。

これにより、

引き寄せの法則の失敗の原因でよくある、

不安や焦りを減らし、

逆の引き寄せによる失敗を防ぎます。

まずは、

大まかな役割分担について説明し、

次にもっと細かな説明と、その理由、

次に、成功のポイントについて説明します。

まずは、

大まかな分担についての話になります。

この分担と言うのは、

タイトルにあるように、あなたと、あなたの潜在意識との役割分担になります。

正しくは、あなたの顕在意識と、潜在意識とになります。

どちらも自分なのに役割分担？

と思うかもしれませんが、あなたの潜在意識はあなたのものですが、

あなたと違う意識で、活動するコトが多くあり、

ここでは、別と捉えた方が、後々、潜在意識からの無駄なロックを受けずに

すむ場合があるので、自分とは違うものだと認識してもらった方が、

潜在意識の力を発揮しやすくなります。

これにつては、後からもう少し、詳しく説明します。

それでは、

具体的な役割分担についての説明をします。

引き寄せの準備や、何を引き寄せるかを決めるのは、

あなたの仕事で、

それに合わせて、引き寄せをするのが、

潜在意識の仕事です。

あなたのする引き寄せの準備とは、

引き寄せたい願望を引き寄せられる人になり、

潜在意識にそれを伝えるコトと、

波動を整えるコトで、それを潜在意識にしっかりと伝えやすくするコトです。

自分の能力にふさわしくないモノを引き寄せようとする場合、

それを引き寄せられると思い込めば、いいのですが、

ほとんどの人は、それに失敗し、

潜在意識に思い込もうとしているのがバレてしまい、引き寄せを失敗してしまいます。

その失敗の経験から、潜在意識のロックが更に強くなり、

いっそう、引き寄せが難しくなります。

これまでお話しましたが、

引き寄せの法則を成功させるには

潜在意識があなたの願望を現実だと感じないと引き寄せはされません。

引き寄せを失敗してしまう人は、そこを意識しないで、

ただ、自分の求める願望を引き寄せたいという考えで、引き寄せをしてしまいます。

そのために、潜在意識の反発にあい、失敗してしまいます。

まずは、自分が現在引き寄せられる範囲を理解し、

達成可能な願望を目標にしましょう。

そして、

その成功を積み重ねると、

潜在意識との信頼関係ができて、

より大きな願望の引き寄せを達成するコトができます。

なので、すでに失敗している人は、

ここで、ちょっと現状を見直し、

少し、低い目標にしてより確実に成功するか、

行動により、自分自身を成長させ、現実的に達成しやすくし、

脳的には、その行動により潜在意識が、変化が起こっているコトを伝え、

潜在意識がその目標が自分の現実だと思えるコトにしていくコトが大切です。

今回は、役割分担の概要について説明させていただきました。

次回以降、もっと細かな説明と、

成功のポイントについて説明します。
