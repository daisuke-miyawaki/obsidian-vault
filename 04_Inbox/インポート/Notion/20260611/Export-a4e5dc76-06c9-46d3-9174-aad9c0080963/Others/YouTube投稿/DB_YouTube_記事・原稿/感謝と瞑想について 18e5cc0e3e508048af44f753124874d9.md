よし状態を維持するための
瞑想をしていきましょう。

# 人は、
なかなか思考を排除するのは難しく、
この仮想現実から抜け出せません。

# 瞑想をすることで、
仮想現実の仕掛けである、
細かな情報を遮断し、
仮想現実自体の情報を減らし、
思考を減らしていきます。

# そして、
思考を減らすだけでなく、
体の感覚をなくしていくことで、
さらに仮想現実の情報が減ります。

# さらに
その脳が動かない状態で、
感謝することで、
開運、ベアーを弾くバリアになります。

# その感謝は、
言葉を思考するのではなく、
感謝の波動を感じ、
それを体中の素粒子で震わせ、
電子雲で全身を良い状態で維持します。

# 感謝するとは？

# 感謝するとは
「ありがたい」「ありがとう」と
思うことではない。

# 思考ではなく、
感じること。

# 思考ではなく、
感じること。

# 例えば、
サウナの整う
冬の山道を長時間歩いたあとに、
温かい温泉に入る
赤ちゃんがお風呂でウンチをする
に近い感覚です。

# この仮想現実を作っている存在に
伝えるには日本語でも英語でもありません。

# 感覚という言語で、
この仮想現実を作っていくことで、
感謝の力で自分の望む未来が創造されていきます。
