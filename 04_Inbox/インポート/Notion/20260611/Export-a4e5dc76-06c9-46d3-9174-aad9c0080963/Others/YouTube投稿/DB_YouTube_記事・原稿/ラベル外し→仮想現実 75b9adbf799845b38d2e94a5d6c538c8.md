生まれてからの経験や得た情報が
脳に蓄積され、
潜在意識が様々なジャッジをしています。

# その潜在意識の機能により、
脳は重要な情報に集中できるようになり、
不要な情報をフィルタリングすることで
私たちは効率的に注意を向けることができ、
安全で健康的な生活を送ることができます。

# しかし、
この潜在意識のジャッジは
よいことばかりではありません。

# 過剰に安全を求めたり、
現状維持を求めたりなどの個性的な判断で、

# その人が本当にもとめている
行動や、思考ができなるなる場合が多分にあります。

# それを取り除き
その潜在意識が作った
仮想現実から抜け出すテクニックが、
「名前外し」です。

![スクリーンショット 2024-06-03 18.31.12.png](%E3%82%B8%E3%83%A3%E3%83%83%E3%82%B8%E3%82%92%E3%81%97%E3%81%AA%E3%81%84%E3%80%82%E3%83%9D%E3%82%B8%E3%83%8D%E3%82%AC%E3%81%AB%E6%8C%AF%E3%82%89%E3%82%8C%E3%81%84%E3%81%AA%E3%81%84%E3%80%82/%25E3%2582%25B9%25E3%2582%25AF%25E3%2583%25AA%25E3%2583%25BC%25E3%2583%25B3%25E3%2582%25B7%25E3%2583%25A7%25E3%2583%2583%25E3%2583%2588_2024-06-03_18.31.12.png)

# 名前外しとは？

# 名前外しは、
物事や人物に対する名前やラベルを取り除き、
純粋な存在として認識する方法です。

# この方法を徹底することで、
ストレスや悩みを軽減し、
仮想現実から離れ客観的に世界や自分を見ることができます。

![スクリーンショット 2024-06-03 18.35.54.png](%E3%82%B8%E3%83%A3%E3%83%83%E3%82%B8%E3%82%92%E3%81%97%E3%81%AA%E3%81%84%E3%80%82%E3%83%9D%E3%82%B8%E3%83%8D%E3%82%AC%E3%81%AB%E6%8C%AF%E3%82%89%E3%82%8C%E3%81%84%E3%81%AA%E3%81%84%E3%80%82/%25E3%2582%25B9%25E3%2582%25AF%25E3%2583%25AA%25E3%2583%25BC%25E3%2583%25B3%25E3%2582%25B7%25E3%2583%25A7%25E3%2583%2583%25E3%2583%2588_2024-06-03_18.35.54.png)

# 名前外しの手順（実践例）

# 職場の人間関係

## 例えば、職場の同僚に対して嫌な感情を抱く場合、
その人に対して名前外しを行います。

# 同僚を外す。
氏名を外す。
男性を外す。
人間を外す。
生物を外す。
物体を外す。

![スクリーンショット 2024-06-04 1.16.38.png](%E3%83%A9%E3%83%99%E3%83%AB%E5%A4%96%E3%81%97%E2%86%92%E4%BB%AE%E6%83%B3%E7%8F%BE%E5%AE%9F/%25E3%2582%25B9%25E3%2582%25AF%25E3%2583%25AA%25E3%2583%25BC%25E3%2583%25B3%25E3%2582%25B7%25E3%2583%25A7%25E3%2583%2583%25E3%2583%2588_2024-06-04_1.16.38.png)

# 名前外しの効果

# これを徹底すると、
存在そのものが曖昧になり、
嫌な感情が軽減されます。

# そして、
認識の変更ができます。
誰にでも過去の記憶や経験から、
固定概念があります。
その固定概念を外すきっかけになります。
