# 引き寄せの法則の信者は、
引き寄せの法則をふんわりとしか理解していない
（勝ってなイメージですが・・・・）

![スクリーンショット 2025-02-23 18.17.43.png](%E5%BC%95%E3%81%8D%E5%AF%84%E3%81%9B%E3%81%AE%E6%B3%95%E5%89%87%E3%81%AE%E7%BD%A0/%E3%82%B9%E3%82%AF%E3%83%AA%E3%83%BC%E3%83%B3%E3%82%B7%E3%83%A7%E3%83%83%E3%83%88_2025-02-23_18.17.43.png)

# 成功したら、
引き寄せの法則で成功したと思う

# 失敗したら、
引き寄せの法則をもっと頑張ろうと思う

# 願掛けに近く、ふわりとしており、
裏付けや、論理的な根拠がない

# 根拠がないから、
失敗したり、成功したいを繰り返したり、
失敗ばかりを繰り返し、
心身を消耗していく

# 昔の成功者は念が強く
地球が変化する前は叶いやすかった。

# 地球が変化したことに気付かずに
頑張る昔の成功者は、
気合で頑張りどんどんドツボに

# 本当に幸せになるには？

![698006168.png](%E5%BC%95%E3%81%8D%E5%AF%84%E3%81%9B%E3%81%AE%E6%B3%95%E5%89%87%E3%81%AE%E7%BD%A0/698006168.png)

# 宇宙の法則が神様の法則

# 無知・無能な人間が考えたのではなく
全てを理解している優秀な精霊が
教えてくれた事で、
自分たちはその実績を
身を持って実感している（確信）

# この仮想現実は自分の心の状態によって
創造されていることを理解する。

# そして、
常に良い心の状態を維持することで、
良い未来を仮想現実に生成する

# 引寄の法則では
上手く願望が叶っても
不幸せになる現実もあり得るが、

# 宇宙の法則では、
上手くできれば、
幸せになることしかなく、

# 想像を遥かに超える
未来が想像されることもよくある

# 引き寄せの法則とは違い、
修行の内容がはっきりしているので、
結果も再現性が高い

## 再現性とは、
様々な場面で様々な人がやっても
同じ結果が出やすいかどうか
