# 誰でも
頑張らないことがでいない。

# 例えば・・・

# 良い結果を出そうと思ってしまう。

# 不安から逃れようとしてしまう。

# 自分を認めて欲しいと思ってしまう。

# 他人より良くなりたい。

# など。

# 人は、
自分にとってベストな
環境であっても、
常に不満を持ちます。
そして、
それを宇宙が用意してくれた
ものであっても
文句を言い否定します。

# なぜ、
頑張ってしまうのか？

![スクリーンショット 2024-06-17 15.49.07.png](../../../HOME/DB_%E3%83%A1%E3%83%A2%E3%83%BB%E8%AB%8B%E6%B1%82%E9%96%A2%E9%80%A3/%E9%81%A0%E8%97%A4%E3%81%95%E3%82%93%E5%8B%89%E5%BC%B7%E4%BC%9A%202025%2003%2029/%E3%82%B9%E3%82%AF%E3%83%AA%E3%83%BC%E3%83%B3%E3%82%B7%E3%83%A7%E3%83%83%E3%83%88_2024-06-17_15.49.07.png)

# 頑張ることが正しい、
頑張らないと良くならないなどの
潜在意識の蓄積が
無意識に頑張る癖をつけています。

# その結果、
仮想現実の登場人物を信じて、
自分を信じていない。
宇宙を信じていない。
ということになります。

# では、
どうしたら良いでしょうか？

# 普段から、
宇宙にまかせることに集中する

# 宇宙にまかせていれば
大丈夫と信じる

# 頑張らないを意識する
