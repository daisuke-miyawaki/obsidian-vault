# 願望を達成したいと
思ってはいけない理由

---

# 「願望を達成したい」=「不足を感じたい」
ということを忘れない。

# 例えば、
暖かいセーターが欲しいと思った場合、
暖かいセーターがない状態を
感じないと始まらない。

# ということは
不足を叶える必要がある。

# 不足がかなると。
次は欲しいと思う。

# その欲しいと思う
不足が叶う。

# というループが起こる。

# ということは、
願望を達成したと思わないで、
願望を達成しないといけない。

---

# 例えるなら、
本当は自分は
何でも放映できる
映写機みたいなもの

![f8fe3a73-bd22-4a9a-bd59-0b3a03e1786a.webp](%E9%A1%98%E6%9C%9B%E3%82%92%E9%81%94%E6%88%90%E3%81%97%E3%81%9F%E3%81%84%E3%81%A8%E6%80%9D%E3%81%A3%E3%81%A6%E3%81%AF%E3%81%84%E3%81%91%E3%81%AA%E3%81%84/f8fe3a73-bd22-4a9a-bd59-0b3a03e1786a.webp)

# 映写機は
自分の姿が見えないから
その事にまったく気付けない。

# 潜在意識を出演させると
どんどん細かな設定や、
物語がリアルに語られる。

# そして気付いたら
監督・脚本・主演・共演・お客も全部が
潜在意識になっている。

![449b8684-51b5-4307-88af-bc03a9325f28.webp](%E9%A1%98%E6%9C%9B%E3%82%92%E9%81%94%E6%88%90%E3%81%97%E3%81%9F%E3%81%84%E3%81%A8%E6%80%9D%E3%81%A3%E3%81%A6%E3%81%AF%E3%81%84%E3%81%91%E3%81%AA%E3%81%84/449b8684-51b5-4307-88af-bc03a9325f28.webp)

# 潜在意識の完璧な演技と、
あまりのリアルさと、
詳細な設定に
映写機はスクリーンに写し出された
映像を信じ込み、
自分がその主人公だと勘違いしてしまう。

# そうなると、
本当は何でも好きなものを
映し出せるはずの映写機が、

# 潜在意識に乗っ取られ、
不足を中心とした、
壮大な物語しか映し出せなくなり、
それは死ぬまで続く。

# まず、
それに気付き潜在意識の自分勝手を
一旦すストップさせ、
自分が映写機であって、
物語の主人公でないことを
思い出すことが重要。

# そして、
はじめから不足ありきの物語ではなく、
充足ありきの物語のループをスタートさせる。

---

- 自分メモ
    
    願望を達成したいと思った時に注意が必要。「願望を達成したい」=「不足を感じたい」ということを忘れない。願望がや目標がある時点で、実は不足を感じていることになる。不足を感じているということは、その願望は叶わないことになる。願望を叶えると、不足を叶えるは一緒。だから、願望を叶えたいと思った瞬間に、不足した未来が作らえる。そして願望を叶える努力をするということは、不足を作るために頑張ることになる。
    不足を克服する自分が不足でないと存在できないことになる。
    不足を創ったのもゲンさんだし、その不足を克服するために頑張るのもゲンさん。そのストリーの主演をしているにもゲンさん。そしてそのゲンさんの物語を映し出している映写機が本当の自分になる、映写機は自分の姿を見れない。映写機は映し出しているスクリーンの映像を観ているだけ。そこにゲンさんが「自分を主演にさせて！」
    と出しゃばって来る。そして、映写機もゲンさんの迫真の演技に騙されて、自分が映像を写しているだけなのに、いつしか映像の方を自分だと勘違いしてしまう。そしてエゴを自分だと思い込む。しかし、映写機は本当は映し出す映像を選択する権利がある。だから願望（不足）が湧いて来たら、その映像を選択しないと思うだけで良い。自分が選択した瞬間に、ゲンさんの不足物語が停止される。
