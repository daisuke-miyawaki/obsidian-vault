# 自愛の重要性

---

# 人間が怖いのは、
死ぬことと、
自分が自分を好きでなくなることです。

![スクリーンショット 2024-03-18 23.43.55.png](%E8%87%AA%E6%84%9B%E3%81%AE%E9%87%8D%E8%A6%81%E6%80%A7/%25E3%2582%25B9%25E3%2582%25AF%25E3%2583%25AA%25E3%2583%25BC%25E3%2583%25B3%25E3%2582%25B7%25E3%2583%25A7%25E3%2583%2583%25E3%2583%2588_2024-03-18_23.43.55.png)

# 自信のない人は、
自分より下の人と
自分を比べ安心したり、

# 人を落とすことで、
自分が優位に立ちたがります。

# それらをしないと、
自分の存在価値が低く思えてしまうのです。

![スクリーンショット 2024-03-18 18.33.42.png](%E8%87%AA%E6%84%9B%E3%81%AE%E9%87%8D%E8%A6%81%E6%80%A7/%25E3%2582%25B9%25E3%2582%25AF%25E3%2583%25AA%25E3%2583%25BC%25E3%2583%25B3%25E3%2582%25B7%25E3%2583%25A7%25E3%2583%2583%25E3%2583%2588_2024-03-18_18.33.42.png)

# 逆に自信のある人は、
他人の幸せも喜ぶ余裕があります。

# それは、
自分の事が好きで、
すでに重要なものを
手に入れているからです。

# このように
人間は、思考と潜在意思の表面と、
潜在意識の奥とでは、
考えが違うように思えることがあります。

# そして、
思考の根底には、
死なないこと、
自分を好きでいることを元にあります。

# では、
どうしたら
よいのでしょうか？

![スクリーンショット 2024-03-18 22.13.06.png](%E8%87%AA%E6%84%9B%E3%81%AE%E9%87%8D%E8%A6%81%E6%80%A7/%25E3%2582%25B9%25E3%2582%25AF%25E3%2583%25AA%25E3%2583%25BC%25E3%2583%25B3%25E3%2582%25B7%25E3%2583%25A7%25E3%2583%2583%25E3%2583%2588_2024-03-18_22.13.06.png)

# どんな自分でも許しましょう

# 他人ではなく、
10年前の自分、
１年前の自分、
1ヶ月前の自分、
昨日の自分と比べ、
1mmでも成長していれいばよいことです。

![スクリーンショット 2024-03-18 23.35.02.png](%E8%87%AA%E6%84%9B%E3%81%AE%E9%87%8D%E8%A6%81%E6%80%A7/%25E3%2582%25B9%25E3%2582%25AF%25E3%2583%25AA%25E3%2583%25BC%25E3%2583%25B3%25E3%2582%25B7%25E3%2583%25A7%25E3%2583%2583%25E3%2583%2588_2024-03-18_23.35.02.png)

# 極端な話、
最終的に自分たちは死にます。

# なので、
どれだけ知識があっても、
運動ができて金メダルをとっても、
総理大臣になっても、
それ自体にはまったく意味がありません。

# 仮想現実の中の出来事です。

# なので、
自分が優れている必要はありません。

# 仮想現実に騙されていますが、
本当はただ幸せを感じているだけでよいです。

# 何かを持って行きたい場合は、
良い思い出は持って行けるそうです。

# 良い思いでとは、
はかなく、せつないものだそうです。

![スクリーンショット 2024-03-19 1.23.26.png](%E8%87%AA%E6%84%9B%E3%81%AE%E9%87%8D%E8%A6%81%E6%80%A7/%25E3%2582%25B9%25E3%2582%25AF%25E3%2583%25AA%25E3%2583%25BC%25E3%2583%25B3%25E3%2582%25B7%25E3%2583%25A7%25E3%2583%2583%25E3%2583%2588_2024-03-19_1.23.26.png)

# 幸せになるために、
仮想現実が作った価値を捨てて、
自分を大切にし、
今に感謝をして生きて生きましょう。

![スクリーンショット 2024-08-27 1.06.42.png](%E6%84%9F%E8%AC%9D%E3%81%99%E3%82%8B%E3%81%93%E3%81%A8%E3%81%A7%E5%AE%9D%E3%82%AF%E3%82%B8%E3%81%8C%E5%BD%93%E3%81%9F%E3%82%8B%E4%BB%95%E7%B5%84%E3%81%BF/%25E3%2582%25B9%25E3%2582%25AF%25E3%2583%25AA%25E3%2583%25BC%25E3%2583%25B3%25E3%2582%25B7%25E3%2583%25A7%25E3%2583%2583%25E3%2583%2588_2024-08-27_1.06.42.png)
