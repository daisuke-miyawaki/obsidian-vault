良い状態であったからこそ、
仮想現実を上手く書き換え、
現実ではありえない修復力を見せたと思います。

# もし、
その良い状態を再現できたら、
願望を叶え、
この仮想現実を好きに
書き換えることができることになります。

①良い状態を維持
②良い波動が宇宙に蓄積

①良い状態を維持
②良い波動が宇宙に蓄積
③宇宙が波動を元に仮想現実を構築

# この中で私達ができるのは、
「 ①良い状態を維持 」だけです。

# ただ、
良い状態を維持するだけでは、
奇跡的な回復ではなく、
早く回復するだけになります。

# そこで奇跡的な願望達成に必要な2つが
・これまで通りに良い状態の維持
・願望に合わせた状態でいる

- AIが下記のメモを元に物語を生成
    
    かつて、ある森の中に、いろいろなサルが暮らしていました。彼らはそれぞれ違う特技を持ち、自分たちなりに賢く生きようとしていました。芋を洗って食べるサル、そのまま食べるサル、人間から餌をもらうために芸を覚えたサルなど、様々です。しかし、どんなに賢くても、彼らは高度な道具を作ることや計画を立てること、文明を発達させることはできませんでした。それは、神から見た人間の姿にも似ています。私たち人間も、多くの技術や文化を持ちながら、神から見ればまだまだ未熟な存在なのです。
    
    この森でのサルたちの生活は、私たち人間社会にも通じるものがあります。私たちはしばしば、自分たちがどれほど賢いか、または特別であるかを競い合ってしまいます。しかし、本質的には、私たちは皆、その能力の中で限られており、サルたちと同じように、ある種の「どんぐりの背比べ」をしているに過ぎないのです。
    
    しかし、ここに大きな転機があります。自分たちが実は「サル」であること、つまり人間としての限界や未熟さを認めることで、多くの悩みや競争から解放されるのです。サルたちがサルらしく精一杯に生きているように、私たちも自分自身を受け入れ、自由に、そして幸せに生きることができるようになります。
    
    この自覚は、サルから抜け出し、更に高い意識へと進むための第一歩です。私たちの感じる感覚や思考、見えるもの全てが、この仮想現実の一部であると気づくこと。それは、怒りや悲しみ、周囲の苛立ちや面倒など、全てがこの「サルの世界」の一部であると認めることから始まります。
    
    しかし、その認識を持つことで、私たちは周囲のサルたち、つまり他人の振る舞いに惑わされず、学んだことを実生活に活かし、良いペースで生きることができるようになります。私たちがそれを実践し、マスターすれば、仮想現実を超えた新しい視点を持つことができ、自分の力でこの仮想現実、つまり現実世界を変えていくことができるのです。
    
    この物語は、サルと人間、そして人間と神の関係を比較することで、私たちがどのようにして自分自身を理解し、成長していけるかを示しています。未熟さを認め、それを乗り越えることで、私たちはもっと自由で、幸せな生を送ることができるようになるのです。
    
- 自分メモ
    
    ### **思考の問題解決法：ステップバイステップ**
    
    1. **仮想現実での失敗をどう見る？**
        - 世の中が仮想現実だって知ってるよね？日々の「失敗」や「問題」は、ゲームの中で起こるイベントみたいなもの。ゲームでの失敗は実際の自分に影響しないのと一緒だよ。これをちゃんと理解することが、問題に冷静に取り組むための第一歩だね。
    2. **問題にどう向き合う？**
        - 問題が起きたとき、基本的にこんな2つの反応があるんだ。
            - **①全てが嫌になって逃げたくなる**：これは一時しのぎで、結局はまた同じ問題に直面することになるよ。
            - **②「また同じ間違いをしてる」と客観的に考える**：これは自分を外から見ることができるから、問題の本質を理解する手助けになるんだ。
    3. **自分を客観的に観察しよう**
        - 「またこの仮想現実にやられてるな」と自分で気づくことが大事。これを意識すると、仮想現実の影響を受けずに、もっと落ち着いて状況を評価できるようになるんだよ。
    4. **思考をどうコントロールする？**
        - ここにも2つのやり方があるよ。
            - **①ネガティブな思考を止める**：頭の中でネガティブな声がするたびに「ストップ」と言って、思考をリセットしよう。
            - **②すべての思考を止める**：もっと思い切った方法で、ポジティブな思考もネガティブな思考も含めて、すべての思考を静めてしまうんだ。これをすると、心が本当に平和になるよ。
    
    ### **イメージしてみてね**
    
    - **ビデオゲームをしてると想像してみて**：ゲーム中にいろいろ問題が起きるけど、実生活のあなたには何の影響もないよね。それと同じで、この仮想現実の中で起きることも、本当のあなたには影響しないんだよ。
    
    このように、この世界が仮想現実だと理解し、どう思考をコントロールするか学ぶことで、心をもっと穏やかに保つことができるんだ。どうだい、ちょっとはイメージしやすくなったかな？
