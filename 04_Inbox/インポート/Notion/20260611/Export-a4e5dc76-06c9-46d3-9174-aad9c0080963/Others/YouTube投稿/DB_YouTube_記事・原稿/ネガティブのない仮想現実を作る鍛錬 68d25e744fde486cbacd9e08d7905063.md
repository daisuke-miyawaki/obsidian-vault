# ネガティブを排除とは？

![スクリーンショット 2024-07-29 23.30.13.png](%E3%83%8D%E3%82%AC%E3%83%86%E3%82%A3%E3%83%96%E3%81%AE%E3%81%AA%E3%81%84%E4%BB%AE%E6%83%B3%E7%8F%BE%E5%AE%9F%E3%82%92%E4%BD%9C%E3%82%8B%E9%8D%9B%E9%8C%AC/%25E3%2582%25B9%25E3%2582%25AF%25E3%2583%25AA%25E3%2583%25BC%25E3%2583%25B3%25E3%2582%25B7%25E3%2583%25A7%25E3%2583%2583%25E3%2583%2588_2024-07-29_23.30.13.png)

# 例：
そうえば、
明日OOに行かないといけない。
めんどい。

# OOOの支払いがある。
お金が減るのが嫌だ。

# 今日も暑い。だるい。

# 歩いたら、疲れた。

# など、
ネガティブに属する思考を全て排除します。

# ネガティブな思考が出てきたら、
即カットし、
ガッツポーズ（小さくていい）で、
自分を褒めましょう。

# 最終的に100％を目指しますが、
進歩していればOKです。

# ネガティブな思考をして、
それをカットできなくてもOKです。
そこで、自分を責めると、
その思考がネガティブになります。

# 1歩でも進めばOK！

# そして、
ネガティブな思考を
ポジティブな思考に置き換えましょう。

![スクリーンショット 2024-07-29 23.36.59.png](%E3%83%8D%E3%82%AC%E3%83%86%E3%82%A3%E3%83%96%E3%81%AE%E3%81%AA%E3%81%84%E4%BB%AE%E6%83%B3%E7%8F%BE%E5%AE%9F%E3%82%92%E4%BD%9C%E3%82%8B%E9%8D%9B%E9%8C%AC/%25E3%2582%25B9%25E3%2582%25AF%25E3%2583%25AA%25E3%2583%25BC%25E3%2583%25B3%25E3%2582%25B7%25E3%2583%25A7%25E3%2583%2583%25E3%2583%2588_2024-07-29_23.36.59.png)

# OOOの支払いがある。
お金が減るのが嫌だ。
　　　↓
OOOのお陰で、
こんなに便利で生活が楽だ。

# 歩いたら、疲れた。
　　　↓
今日もよい運動ができて良かった。
より健康になれた。

# というように、
ちょっとずつで良いので、
ネガティブな思考を
ポジティブな思考に
変換する癖を付けましょう。
