自分にピッタリのヒントを
プレゼントしてくれています。

# たとえば、
お店の中の気になる人、
映画の物語、
今、聴いている歌、
テレビのニュース
など・・・・

# 心が動くことが
ヒントの可能性が高くなります。

# 良いことだったり、
イラツイたり、
目立っていたりと、
気になる目立つことです。

# なので、
常にヒントを受け取る
気持ちを持ちましょう。

# まずは、練習です。
「一桁違いで当たりそうだった」
ことからヒントを受け取りましょう。

# ソクラテスの無知の知

![Designer.png](%E7%8F%BE%E5%AE%9F%E3%81%8B%E3%82%89%E5%AE%87%E5%AE%99%E3%81%AE%E3%83%92%E3%83%B3%E3%83%88/Designer.png)

# ソクラテスも無知で無能

# ソクラテスは
人間は無知で無能と知りながら、
それを伝えようとしたことで、
その無知で無能な人間に殺された

# ソクラテス自身が、
自分が無知で無能としてわきまえていれば、
殺されることはなかった

# バカは死んでも治らないので、
ほかってけば良かった・・・

# これまで話してきなしたが、
自分を含めた全ての人間が
無知で無能なことを深く理解し、
常に意識する必要があります。

# 自分たちは
無知で無能なので、
何もできない。

# だから宇宙にまかせます。

# 自分で頑張らないことで、
宇宙が自分の望む仮想現実を
創ってくれます。

# 皆が無知で無能なので、
他人と比較したり、
判断や、ジャッジしたり、
劣等感を抱いたりする必要がありません。

# 皆が平等に無知で無能だから、
どうがんばっても
自分も同じで、
どんぐりの背比べ

# だったら、
無駄な努力より、
自由に設計できる仮想現実で
幸せになりましょう。
