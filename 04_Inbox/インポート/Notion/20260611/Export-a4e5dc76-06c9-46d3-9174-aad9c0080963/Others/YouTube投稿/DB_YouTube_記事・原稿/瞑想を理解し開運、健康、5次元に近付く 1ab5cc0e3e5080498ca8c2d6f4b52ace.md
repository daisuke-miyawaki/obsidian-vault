# 瞑想について

# 4次元（仮想現実）を弱くすることが重要です

# 仮想現実は、
潜在意識が作っていると
言ってもよいと思います

# 潜在意識の活動を止めるために

# 思考を減らし、
体の力を抜くことで、
潜在意識の存在が弱まります

# しかし、
瞑想だけでは
そこの域に達するのは難し場合があります

# なので
普段から
思考をなくし
体の力が入っているかのチェックだけでも
できると良いです

# 自分の思考がない時に
実感できる人がほとんどですが、

# 体の力が入っているかわからない
人がほとんどです

# 顕在意識の範囲での力みは
認識しやすいですが、

# 潜在意識の範囲での力みは
認識しにくいです

# 極端な話で、
心臓や横隔膜や、
頚椎周辺の筋肉は
自律神経を通し
潜在意識がコントロールしているので、
顕在意識でのコントロールは難しいです

# しかし、
潜在意識下での力みでも
認識できる部位があります

# 例えば、
首や頭、肩などです

# まずは
この部位をチェックし
力を抜く癖をできる範囲でしましょう

# そして
瞑想時には
その他の頚椎周りなども
できれば力みをなくしましょう

# これらの力みは
最初は認識できなくても
慣れでできるようになります

# 普段から、
意識を脳に取られずに
体に意識を持っていくことで、
体の部位の状態を認識できるようになります
