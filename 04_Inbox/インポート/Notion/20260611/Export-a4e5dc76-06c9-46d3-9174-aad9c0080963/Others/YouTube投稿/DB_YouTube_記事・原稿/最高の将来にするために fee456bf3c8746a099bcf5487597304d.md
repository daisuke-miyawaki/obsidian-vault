最大限に自分の人生を
豊かにすることを選ぶ！

# そのために

# 他人にコントロールされない、
他人をコントロールしない。

# それらは、
あちら側がしかけていることです。

# 自分のペースで、
自分のために生きましょう。

# しかし、
世界のルール、
日本人とは、
名古屋では、
家族とはなど多くの洗脳に中で、
それを実行するのが難しいです。

# その一番の原因が
潜在意識です。

![スクリーンショット 2024-06-17 16.09.33.png](%E6%9C%80%E9%AB%98%E3%81%AE%E5%B0%86%E6%9D%A5%E3%81%AB%E3%81%99%E3%82%8B%E3%81%9F%E3%82%81%E3%81%AB%20fee4-304d/%25E3%2582%25B9%25E3%2582%25AF%25E3%2583%25AA%25E3%2583%25BC%25E3%2583%25B3%25E3%2582%25B7%25E3%2583%25A7%25E3%2583%2583%25E3%2583%2588_2024-06-17_16.09.33.png)

# 潜在意識にとって、
変わらないこと、
死なないことが重要です。

# そのためには、
将来のことを考えられませんし、
辛いことや、いやなことも受け入れます。

# しかし、
それでは本当の幸せが
遠のいてしまいます。

# その潜在意識の邪魔をなくし、
自分の人生を取り戻すには、
「決める」ことが重要です。

![スクリーンショット 2024-06-17 16.15.35.png](%E6%9C%80%E9%AB%98%E3%81%AE%E5%B0%86%E6%9D%A5%E3%81%AB%E3%81%99%E3%82%8B%E3%81%9F%E3%82%81%E3%81%AB%20fee4-304d/%25E3%2582%25B9%25E3%2582%25AF%25E3%2583%25AA%25E3%2583%25BC%25E3%2583%25B3%25E3%2582%25B7%25E3%2583%25A7%25E3%2583%2583%25E3%2583%2588_2024-06-17_16.15.35.png)

# 本当に決めると
潜在意識も力をかしてくれます。

# ただ、
決めるとは、
「決める」と思うことではありません。
心がロックして動かかい大岩のように、
心の支柱のように「決める」ことが大切です。

# ここで、
決めたことを
続けるポイントです。

![スクリーンショット 2024-06-17 16.18.08.png](%E6%9C%80%E9%AB%98%E3%81%AE%E5%B0%86%E6%9D%A5%E3%81%AB%E3%81%99%E3%82%8B%E3%81%9F%E3%82%81%E3%81%AB%20fee4-304d/%25E3%2582%25B9%25E3%2582%25AF%25E3%2583%25AA%25E3%2583%25BC%25E3%2583%25B3%25E3%2582%25B7%25E3%2583%25A7%25E3%2583%2583%25E3%2583%2588_2024-06-17_16.18.08.png)

# 人間として、
この仮想現実に生まれたからには、
全ての人が、当たり前ですが、未熟です。

# しかし、
多くの人がそれを
忘れてしまいます。

# それも当然です。
潜在意識には現状維持の機能があり。
これまで通りの思考をさせようとします。

# そこで、
この仮想現実に
縛りつけようとしている
潜在意識と仮想現実のコントロールから
抜けるために、
「変化すること」「成長すること」を
よいことだと認めましょう。

# そして、
変化したした自分を
しっかり褒めましょう。

# この自分の幸せになるための変化は、
何かの賞を取ったり、
役職に就くより重要なことで、
大きな称賛することです。

# 賞や役職は、
他人の評価で、
まさに、
奴らや、潜在意識、仮想現実のコントロールで、
自分の幸せに直結していません。

# しかし、
自分が幸せになるために変化は、
自分の幸せに直結しています。

# なので、
少しの変化も遠慮なく称賛しましょう。
褒めることで、これまで受けた洗脳も弱まり、
奴らや、潜在意識、仮想現実の
コントロールも弱まり、

# 幸せな将来が、
ドンドン仮想現実にたまり、
未来が作られてゆきます。
