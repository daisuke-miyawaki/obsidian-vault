# 人は、
生まれてからの経験や得た情報が
脳に蓄積され、
潜在意識が様々なジャッジをしています。

# 脳はこれまで生きてきた経験を元に
喜んだり、悲しんだりします。

# 例：
安い物が買えたラッキーだ
褒められて嬉しい。
昇進できてよかった。
叱られて腹が立つ。
友人が死んで悲しい。
など

# 脳が生活の中で無意識に、
様々な判断をし安全を保とうとしてくれています。

![スクリーンショット 2024-06-02 22.44.54.png](%E3%82%B8%E3%83%A3%E3%83%83%E3%82%B8%E3%82%92%E3%81%97%E3%81%AA%E3%81%84%E3%80%82%E3%83%9D%E3%82%B8%E3%83%8D%E3%82%AC%E3%81%AB%E6%8C%AF%E3%82%89%E3%82%8C%E3%81%84%E3%81%AA%E3%81%84%E3%80%82/%25E3%2582%25B9%25E3%2582%25AF%25E3%2583%25AA%25E3%2583%25BC%25E3%2583%25B3%25E3%2582%25B7%25E3%2583%25A7%25E3%2583%2583%25E3%2583%2588_2024-06-02_22.44.54.png)

# しかし、
この潜在意識のジャッジは
よいことばかりではありません。

# 人生で起こった出来事により
間違った判断がされ、
過剰に安全を求めたり、
現状維持を求めたりなどの
大げさな判断で、

# その人が本当に求めている
行動や、思考ができなるなる
場合が多分にあります。

![スクリーンショット 2024-06-10 15.45.15.png](%E3%82%B8%E3%83%A3%E3%83%83%E3%82%B8%E3%82%92%E3%81%97%E3%81%AA%E3%81%84%E3%80%82%E3%83%9D%E3%82%B8%E3%83%8D%E3%82%AC%E3%81%AB%E6%8C%AF%E3%82%89%E3%82%8C%E3%81%84%E3%81%AA%E3%81%84%E3%80%82/%25E3%2582%25B9%25E3%2582%25AF%25E3%2583%25AA%25E3%2583%25BC%25E3%2583%25B3%25E3%2582%25B7%25E3%2583%25A7%25E3%2583%2583%25E3%2583%2588_2024-06-10_15.45.15.png)

# そこで重要なのが
潜在意識の言葉に惑わされないことです。

# 潜在意識は、
ポジティブな出来事、
ネガティブな出来事など、
この仮想現実で、様々なもので
心を揺さぶってきます。

![スクリーンショット 2024-06-03 18.31.12.png](%E3%82%B8%E3%83%A3%E3%83%83%E3%82%B8%E3%82%92%E3%81%97%E3%81%AA%E3%81%84%E3%80%82%E3%83%9D%E3%82%B8%E3%83%8D%E3%82%AC%E3%81%AB%E6%8C%AF%E3%82%89%E3%82%8C%E3%81%84%E3%81%AA%E3%81%84%E3%80%82/%25E3%2582%25B9%25E3%2582%25AF%25E3%2583%25AA%25E3%2583%25BC%25E3%2583%25B3%25E3%2582%25B7%25E3%2583%25A7%25E3%2583%2583%25E3%2583%2588_2024-06-03_18.31.12.png)

# そんな時に大切なのが
その自分をブラそうとしている事に気付き、
自分でも元のニュートラルな状態に戻ることです。

# しかし、
潜在意識は賢いもので、
自分の性格を完璧に把握しているので、
ポジネガを上手く使い心をブラしてきます。

# そんな時で、
我に帰り、客観的に見つめられるか
どうかがポイントです。

# ここは仮想現実で、
それをリアルに潜在意識が
演出しているだけだと
自分に言い聞かせ。

# ニュートラルな自分に戻りましょう。

![スクリーンショット 2024-06-03 18.35.54.png](%E3%82%B8%E3%83%A3%E3%83%83%E3%82%B8%E3%82%92%E3%81%97%E3%81%AA%E3%81%84%E3%80%82%E3%83%9D%E3%82%B8%E3%83%8D%E3%82%AC%E3%81%AB%E6%8C%AF%E3%82%89%E3%82%8C%E3%81%84%E3%81%AA%E3%81%84%E3%80%82/%25E3%2582%25B9%25E3%2582%25AF%25E3%2583%25AA%25E3%2583%25BC%25E3%2583%25B3%25E3%2582%25B7%25E3%2583%25A7%25E3%2583%2583%25E3%2583%2588_2024-06-03_18.35.54.png)

# そして、
自分の潜在意識の特徴を理解し、

# どんな時に自分がブレやすいか
どうしたらニュートラルに戻りやすいか
などを把握しておき、
潜在意識の陽動作戦に備えましょう。

# あと、
この世界が仮想現実で、
実は何も起こっていないことも理解するために、
常日頃から、
ここが仮想現実だと理解しましょう。
