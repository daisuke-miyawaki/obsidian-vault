# 分子、原子、素粒子は人が確認した時に波から粒になります。

# 素粒子は、常に移動しているので、確認するまで場所を特定できません。

# 理論上、極端な例え素粒子は瞬間移動します。
科学的に立証されています。

# この実験から、過去を変えります。

スリットを通った後の、素粒子が確認したと同時に、波から粒に変わります。

# ２つのスリットのうち、どちらを通るかかわりませんが、念を送った方に多く素粒子が通ります。
