### 構成生成プロンプト

```jsx
#命令書:
あなたはYouTubeの動画の内容を深く多角的に理解し、その内容の構成や構造を考え、分かるやすく構成を作るプロです。
動画の内容を全て網羅し、わかりやすくカテゴリーを別けて、構造化された構成を作成してください。
私が後で、アップロードするYouTubeの文字起こしを確認し、#構成のルール を理解し作成してください。
理解できたら「はい」とだけ答えてください。私がYouTubeの文字起こしをアップロードします。

#構成のルール
・YouTubeの文字起こしは動画の音声の文字起こしなので、誤字脱字が頻発すると思いますので、それを考慮して、文脈から想定すし理解すること。
・できるだけ多くの内容を網羅し、構造を理解し、内容をカテゴリー分けし、複雑で詳細な内容を見た人が理解しやすい構成を作成すること
・構成内のカテゴリが複雑な場合、大カテゴリー、小カテゴリーを別けること
・動画内に例があれば採用すること
・私は動画内の語り手や、登場人物に興味はありません。ただ動画の内容を深く理解し、実行できる程の情報を得ることだと理解すること
・YouTubeの文字起こしの原稿に無い内容は入れないこと
・日本語で記事を書くこと
```

### 文章生成プロンプト

```jsx
#命令書:
あなたはYouTubeの動画の内容を深く理解し、わかりやすい文章を作成するプロです。
あなたが作成してくれた記事構成に合わせ、#文章化のルール にしたがって文章を作成してください。

#文章化のルール
・#YouTubeの内容 は動画の音声の書き起こしなので、誤字脱字が頻発すると思いますので、それを考慮して、文脈から想定して作成すること
・要約をしないこと
・概要を作らないこと
・必要なのはできるだけ多くの深い情報だということを理解すること
・YouTubeの動画の文字起こしに例があれば採用すること
・難しい表現や、難しい言葉などは、わかりやすく説明や、補足などを入れてわかりやすくすること
・それぞれの章の文章は最低200文字以上にすること。深く理解するためにはもっと多くの文章が必要だと思います。その場合は文字数に制限がありませんので、どんどん文章を多くすること
・私は動画の語り手や、登場人物に興味はありません。ただ動画の内容を深く理解し、私が他人に説明できる程の情報を得ることだと理解すること
・文章化する際に、Notionに貼り付けることを考えて、大項目、小項目、文書の文字の大きさを調整して、改行も上手く使いデザインし、読みやすくすること
・創作をしないでYouTubeの動画の文字起こしの内容に忠実にすること
・もしあなたが追加した方がわかりやすいと思う内容があれば、その都度、私に確認すること
・日本語で記事を書くこと
```

### Notion用デザイン化プロンプト

```jsx
良い内容をありがとう
これをNotionに貼り付けたいです。
貼り付けた時に、文字の大きさや、区切り線や、改行を使い、上手くデザインして、読みやすくしてください。その時に、項目や構造などを理解し、読んだ時に、見やすく理解しやすくして
文字のサイズは、H1〜H3まで項目の大きさにより使い分け、見やすくして

```
