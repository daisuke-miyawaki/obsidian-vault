# Claudeで使用できるXMLタグ一覧

タグ: Claude3, コード・タグ, プロンプト, プロンプト例
作成日: 2024年3月12日 9:10

XMLタグの一覧をマトリックス形式で示します。

| タグ | 説明 | 使用例 |
| --- | --- | --- |
| `<doc>` | ドキュメントの開始と終了を示す | `<doc>本文がここに入ります。</doc>` |
| `<summary>` | 要約を示す | `<summary>この文書は〜について説明しています。</summary>` |
| `<title>` | タイトルを示す | `<title>プロンプト術入門</title>` |
| `<heading>` | 見出しを示す | `<heading>XMLタグの種類</heading>` |
| `<paragraph>` | 段落を示す | `<paragraph>XMLタグは〜という目的で使用されます。</paragraph>` |
| `<sentence>` | 文を示す | `<sentence>これは一文目です。</sentence><sentence>これは二文目です。</sentence>` |
| `<keyword>` | キーワードを示す | `<keyword>プロンプト</keyword>` `<keyword>XMLタグ</keyword>` |
| `<cite>` | 引用を示す | `<cite>プロンプトは言語モデルの入力である。- Claude3 マニュアル</cite>` |
| `<list>` | リストの開始と終了を示す | `<list><item>項目1</item><item>項目2</item></list>` |
| `<item>` | リストの項目を示す | `<list><item>項目1</item><item>項目2</item></list>` |
| `<code>` | コードブロックを示す | `<code>print("Hello, Claude!")</code>` |
| `<question>` | 質問を示す | `<question>XMLタグの主な用途は何ですか?</question>` |
| `<answer>` | 回答を示す | `<answer>XMLタグは文脈や構造を明示するために使用されます。</answer>` |
| `<instruction>` | 指示を示す | `<instruction>以下の文章を要約してください。</instruction>` |

このようにXMLタグを使うことで、テキストの構造や意味をモデルに明示的に示すことができます。適切なXMLタグの使用は、Claude3の性能を最大限に引き出すために非常に重要です。
