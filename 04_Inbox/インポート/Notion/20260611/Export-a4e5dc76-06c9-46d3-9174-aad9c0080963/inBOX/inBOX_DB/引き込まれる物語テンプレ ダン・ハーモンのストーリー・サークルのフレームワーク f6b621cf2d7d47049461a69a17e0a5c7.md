# 引き込まれる物語テンプレ　ダン・ハーモンのストーリー・サークルのフレームワーク

タグ: 内容作りアイデア, 情報発信, 情報発信ネタ
作成日: 2024年5月6日 19:00

ダン・ハーモンのストーリー・サークルをより詳細に解説し、成功させるためのポイントや注意点を加えて説明します。

### **ステップごとの詳細とポイント**

1. **安定状態、快適ゾーン**
    - 説明: 主人公は日常生活を送っています。視聴者にとって理解しやすい状態です。
    - ポイント: 主人公の普段の環境や性格、関係性を明確に示すことが重要です。これにより、後の変化が際立ちます。
2. **欲望**
    - 説明: 主人公は何かを必要とし、それを追求し始めます。これは物理的なものかもしれませんし、内面的な変化かもしれません。
    - ポイント: 主人公の欲望が明確でなければ、物語に動機付けが欠けてしまいます。視聴者が感情移入できるような強い動機を設定しましょう。
3. **新しい状況へ**
    - 説明: 主人公は日常を離れ、新しい環境や状況に身を置きます。
    - ポイント: この変化は物語に新鮮さと緊張感をもたらすため、視聴者の興味を引き続き保持するためには、変化が顕著であることが重要です。
4. **試練、適応**
    - 説明: 主人公は新しい状況に適応しようと努力します。ここでの試練や挑戦が、キャラクターの成長を促します。
    - ポイント: 主人公の挑戦を通じて彼の能力や弱点を明らかにし、それによって視聴者の共感を誘います。
5. **成功、何かを得る**
    - 説明: 主人公はその努力の結果、何らかの重要なものを得ます。それは目的の達成や重要な教訓かもしれません。
    - ポイント: この成果は主人公にとって意味深いものでなければならず、物語のクライマックスに寄与する要素です。
6. **代償**
    - 説明: 成功には代償が伴います。主人公は何か大切なものを失うことがあります。
    - ポイント: この段階は物語に深みを与えるため、喪失が主人公にとっての成長や変化を強調するものであるべきです。
7. **帰還**
    - 説明: 主人公は変わり果てた姿で元の世界に戻ります。この過程で、彼の変化が試されることになります。
    - ポイント: 主人公がどのように変化したか、そしてその変化が彼の世界にどのような影響を与えるかを示すことが重要です。
8. **新たな安定状態、変化**
    - 説明: 物語の終わりに、主人公は何らかの形で変わります。これは内面的な変化や、外部環境への新たな適応が反映されることです。
    - ポイント: この最終的な変化は物語全体を通じて築かれた結果であり、視聴者にとって満足のいく解決を提供すべきです。

### **成功させるポイントと注意点**

- **キャラクターの動機と欲望**: 主人公の動機が強く、関連性があり、視聴者が共感できるものであることが重要です。動機が弱いと、物語は説得力を欠くことになります。
- **バランスとペーシング**: 各ステップは物語のペーシングを考慮して適切にバランスを取る必要があります。あまりに急ぎ足で進めると、重要な感情的瞬間が薄れてしまいます。
- **登場人物の成長**: 物語の終わりまでに主人公が明確な成長を遂げることが重要です。視聴者はこの成長を見ることで、物語により強く引き込まれます。
- **一貫性と信頼性**: 物語の内部論理は一貫性を保つ必要があります。不合理なプロットや行動は視聴者を遠ざける可能性があります。

このフレームワークを適切に使用することで、物語は視聴者に強い影響を与えることができ、深い感情的な共感を呼び起こすことが可能です。
