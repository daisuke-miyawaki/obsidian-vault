# ネドじゅん式 意識変容システム：その哲学、構造、および実践メソッド全体

## 1. 緒言：ネドじゅん式意識変容システムの全体像

### 1.1 報告書の目的と範囲

本報告書は、ネドじゅん氏が提唱する意識変容のための体系的な「技術」と、その根底にある思想、そして個々のメソッドがどのように有機的に結びついているかという「構造」を、多角的な視点から徹底的に分析することを目的とする。本報告は、表面的な紹介に留まらず、各技術の背景にある哲学やその実践的意義を深く掘り下げる。また、依頼者の要請に基づき、調査対象はあくまでこのシステム自体であり、提唱者個人に関する情報は意図的に除外している。このアプローチにより、本報告書はネドじゅん氏の提唱する技術体系の学術的かつ実践的な価値を客観的に評価する専門的な資料となることを目指す。

### 1.2 「悟リズム」と「しあわせ右脳」の概念

ネドじゅん氏のシステムは、悟りや意識変容といった概念を、特定の修行ではなく、日常生活の中で軽やかに体感できるものとして再定義しており、これを「**悟リズム**」（Satorizm）と名付けている 。この「

**悟リズム**」の核心は、絶え間ない思考のループから解放され、自然や身体のリズムに調和しながら生きる意識状態にある 。このシステムの最終的な目標は、「

**しあわせ右脳**」をベースにした意識状態を体感し、継続することである 。これは、論理や計画、過去や未来の思考に囚われることなく、直感や「今、ここ」の感覚に導かれる状態を指し、その状態が「ひたすら幸せ」で「毎瞬毎瞬に意識がある」状態をもたらすと考えられている 。

## 2. 核心哲学：ネドじゅん式システムの思想的基盤

### 2.1 「自動思考」の解剖

ネドじゅん氏の哲学は、人間の苦しみや生きづらさの根源を「**自動思考**」、すなわち頭の中で絶えず行われるおしゃべりにあると診断することから始まる 。この

**自動思考**は、意識的な意図とは無関係に、

- 食事中に「食べ終わったら〇〇しなきゃ」と考えること
- 友人との会話の後で「余計な一言だったかな」と反省すること
- さらには入浴中に「明日の仕事はうまくいくかな」と心配するといった、「今、考える必要のないこと」を延々と続ける無意識の癖である 。

この絶え間ない思考のループは、人が「今目の前のことを味わえなく」させ、結果として自らを不幸に陥れる機能不全のメカニズムとして説明されている 。このシステムは、この

**自動思考**にまず「気づくこと」を第一歩とし、「気づけば7割成功」と提唱している 。

### 2.2 左脳ベースから右脳ベースへの意識変容

ネドじゅん氏のシステムにおける主要な目標は、この**自動思考**を司る「**左脳**」優位の状態から、「**右脳**」優位の状態へと意識の焦点を移す「右脳回帰」にある 。この哲学において、

- **左脳**は「後から作られた理論的な脳」と定義され、過去の再現性や論理、未来の計画を主軸に思考する役割を担う 。
- 対照的に、**右脳**は「太古の昔からある古い脳」と説明され、直感や「今、ここ」の感覚的な情報を主軸に処理するとされている 。

この意識の重心を移動させることで、人は絶え間ない思考のノイズから解放され、より自然で直感的な生き方を体感できるようになるとされている 。

### 2.3 「内側の幸せ」への徹底的な集中と「全力受容」の姿勢

ネドじゅん氏のシステムが既存の多くの自己啓発やスピリチュアルなアプローチと一線を画す点は、徹底して「**内側の幸せ**」、すなわち「心が楽に生きられるようになること」を追求する点にある 。多くの人々が「今の状況が苦しいから、外側を変えたい（望みを叶えたい）」という動機から行動するのに対し、このシステムは「心の状態が整えば、望みは勝手に湧き、自然と叶う」という、因果関係の転換を提示する 。

この内側への集中姿勢は、「**全力受容**」という概念に集約される 。これは、人生において起こる出来事を「一切自分で計画したり考えたりせず、積極的に受け入れる」という実践的な態度であり、外的な状況に一喜一憂するのではなく、内的な意識状態の安定を第一に置くことの重要性を示している。この哲学は、苦しい状況にある人々に対し、「苦しいのは、状況のせいではなく、本当は自分自身の思考のせいかもしれない」という洞察を提供することで、根本的な問題解決を促す 。

## 3. コア・メソッド：意識変容のための主要技術

### 3.1 エレベーター呼吸法

**エレベーター呼吸法**は、ネドじゅん式システムにおいて、**自動思考**を停止させるための最も重要なツールとして位置づけられている 。このメソッドの理論的根拠は、「人は感覚に意識を向けている間は思考を働かせることができない」という脳の特性を利用することにある 。実践者は、この呼吸法によって半強制的に思考を中断させ、身体感覚へと意識を集中させることを目指す。

具体的な実践方法は、呼吸を「お腹の下から喉のあたりまで上げたり下げたりする」というものである 。このとき、特徴的なのは「エレベーターの床をずりずり体にこすりつける」ような意識を付加することである 。この独特な意識の向け方が、より強く身体に意識を集中させ、思考の介入を妨げる効果をもたらすとされている。ユーザーからは、この呼吸法を「筋トレみたいに」繰り返すことで、実際に

**自動思考**が減少しているという報告が寄せられている 。

### 3.2 自動思考に気づくワークと「ガッツポーズ」

このワークは、**自動思考**が浮かんだ瞬間にその思考を「捕獲」し、「気づく」こと自体を目的とする 。このシステムでは、この「気づき」が極めて重要視されており、「気づいたら7割成功」とまで言われている 。

この気づきを習慣化し、脳に定着させるためのユニークな実践方法が「**ガッツポーズ**」である 。

**自動思考**が浮かび、それを認識した際に「小さくガッツポーズをして口角を上げる」ことを推奨している 。この行動は、

**自動思考**が出てきたことに対して自己批判に陥るのではなく、「気づき、一瞬でも止めることができた」という行為自体をポジティブな体験として脳に教え込むための、非常に効果的な行動心理学的手法である。このアプローチは、自分を責める傾向が強い人々にとって、非常に有用なアイディアであると評価されている 。

### 3.3 右脳さんぽ：直観との繋がりを育む散歩法

「**右脳さんぽ**」は、直感と繋がり、その感覚を研ぎ澄ますためのユニークな散歩法である 。このワークでは、意識の焦点を「おなか」におろし、論理や計画ではなく、内側から湧き上がる直感に導かれるままに散歩をする 。この方法を通じて、思考が過剰に介入することなく、五感で「今、ここ」の風景や感覚を純粋に味わうことを目指す。

このワークを実践したユーザーからは、「いろいろと発見があっておもしろい」という感想が報告されている 。これは、意識の焦点を内側と感覚に向け、思考の介入を減らすことで、日々の風景が新鮮で尊く感じられるようになるという効果を示唆している 。このアプローチは、思考の支配から解放され、世界と感覚的に再接続するための、シンプルかつ効果的な手段を提供している。

## 4. 補助的メソッドおよび関連概念

### 4.1 「ミニチップ」による右脳へのイメージ伝達

ネドじゅん氏のシステムは、内面の変容だけでなく、現実世界への影響についても言及している。そのツールの一つが、望みを叶えるための視覚化ツールである「**ミニチップ**」である 。このメソッドでは、叶えたい願いを「

**ミニチップ**」という形でコンパクトなイメージにまとめ、それを**右脳**に飛ばすという方法が紹介されている。

あるユーザーは、ペットの猫の健康状態の改善を願ってこのワークを実践したところ、一週間後の検査で数値が明らかに改善し、猫も自力でご飯を食べられるようになったという具体的な体験談を報告している 。この事例は、このシステムが単なる内面の変容に留まらず、現実世界に影響を与えるという認識をユーザーに与えていることを示しており、このメソッドが持つ象徴的な効果と心理的な力を物語っている。

### 2.2 左脳ベースから右脳ベースへの意識変容

ネドじゅん氏のシステムにおける主要な目標は、この自動思考を司る「左脳」優位の状態から、「右脳」優位の状態へと意識の焦点を移す「右脳回帰」にある 。この哲学において、

この意識の重心を移動させることで、人は絶え間ない思考のノイズから解放され、より自然で直感的な生き方を体感できるようになるとされている 。

### 4.2 その他のメソッドと哲学

ネドじゅん氏のシステムには、上記のコア・メソッド以外にも、意識変容を促すための様々な技術が含まれている。

- **「いま・ここの呼吸」**：**エレベーター呼吸**と並び、今この瞬間に意識を集中させるための呼吸法である 。足元や地面に意識を向けることで、思考の介入を防ぎ、「今、ここ」にグラウンディングする効果がある 。
- **「主語なしで考える」**：思考の主体である「私」を切り離すことで、思考との同一化を防ぐワークである 。これは「思考の声」と「魂の声」を区別する訓練となり、思考に支配されない状態を目指すための実践的なアプローチである 。
- **「わからないことをわからないまま残す」**：物事をすぐにジャッジし、言語化しようとする**左脳**の癖をやめるための訓練である 。このワークを通じて、思考ではなく「お腹で考える」、すなわち感覚的に物事を捉える状態への移行を促す 。

### 4.3 悟り・非二元論との関連性

ネドじゅん氏のシステムは、東洋哲学や非二元論の概念と多くの共通点を持っている。ユーザーレビューでは、「空の概念」や「禅」との類似性が指摘されている 。特に「思考を完全に自分とは思っていない」という概念は、非二元論の核心である「私という思考の分離」と合致している 。

このシステムが独自性を発揮しているのは、このような抽象的で難解な哲学を、日常生活で誰もが実践可能な「ワーク」に落とし込んでいる点にある 。これにより、哲学的な理解だけでなく、身体的・感覚的な体験を通じて意識変容を「体感」することが可能となり、従来の教えでは得られなかった根本的な変容をもたらす可能性を示唆している 。

## 5. システムの構造と実践の全体像

### 5.1 意識変容の段階的モデル

ネドじゅん氏のシステムは、各メソッドが独立したツールではなく、段階的に意識を変化させていくための有機的なプロセスとして構築されている。

1. **第一段階：問題の認識と気づき**
このプロセスの出発点は、自身の苦しみの根本原因が、外的な状況ではなく、内的な「**自動思考**」にあると「気づく」ことである 。この段階では、まず客観的に自身の思考を観察する訓練が始まる。
2. **第二段階：思考の停止と身体的体感**
次に、**エレベーター呼吸法**や**いま・ここの呼吸**といった身体的なワークを通じて、思考の暴走を強制的に停止させる訓練を行う 。これにより、意識の焦点を思考から身体の感覚へと移すことを体感する。
3. **第三段階：行動の強化と習慣化自動思考**を止める度に「**ガッツポーズ**」をすることで、その行為を脳に良いこととして学習させ、新たな行動パターンを定着させる 。このシンプルな行動が、意識の重心を
    
    **右脳**ベースへとシフトさせるための動機づけと強化の役割を果たす。
    
4. **第四段階：右脳ベースへの移行と体感**
これらの訓練を継続することで、意識の焦点が「今、ここ」の直感や感覚へと自然に移行し、最終的な目標である「**しあわせ右脳**」の状態を体感する 。この状態では、人生が思考ではなく直感や無意識に導かれていく感覚を得られるとされている 。

### 5.2 継続と体感の重要性

調査資料からは、「ワークを実際にやってみること」そして「筋トレのように繰り返し」続けることが、このシステムを機能させる上で不可欠であるというメッセージが繰り返し示されている 。これは、抽象的な概念を頭で理解するだけでなく、身体的・感覚的な体験を通じて意識変容を「体感」することの重要性を強調している 。このシステムが、文字数が少なく、イラストも多く用いられていることからも、概念的な理解よりも、無理なくワークを実践し、感覚的に変化を感じることに重きを置いていることが伺える 。このアプローチは、難解な理論に疲弊した人々にとって、実践へのハードルを下げ、継続的な変化を促す上で有効である。

## 6. 結論と推奨事項

### 6.1 ネドじゅん式システムの総合評価

本報告書で明らかになったように、ネドじゅん氏のシステムは、抽象的な悟りや非二元論の概念を、誰もが日常生活で実践可能な具体的で身体的な「ワーク」へと巧みに変換している 。その独自性は、多くの自己啓発やスピリチュアルが焦点を当てる「願望実現」という外側へのアプローチではなく、

**自動思考**という内側の問題を根本的に解決することに集中している点にある 。この焦点の転換は、外的な変化を求めて疲弊した人々にとって、新たな解決策となり得る可能性を秘めている。全体として、このシステムは心理学的な洞察と東洋哲学の要素を融合させながらも、極めて実践的かつ親しみやすい形式で提示されており、その独自性と有効性が高く評価される。

### 6.2 今後の自己探求への推奨

このシステムは、漠然とした生きづらさを感じていたり、ネガティブな思考に悩まされている人々にとって特に有益である 。また、人生を根底から変えたいと願いながらも、従来の自己啓発書で変化を体感できなかった人々にも新たな道を示す可能性がある 。実践にあたっては、各ワークを「面白おかしく」「無理なく」続けること、そして結果をすぐに求めず、小さな意識の変化を「体感」していくことが鍵となる。このシステムは、頭でっかちになるのではなく、身体と感覚を通じて自己探求を進めたいと考える人々にとって、信頼できるガイドとなり得るだろう。
