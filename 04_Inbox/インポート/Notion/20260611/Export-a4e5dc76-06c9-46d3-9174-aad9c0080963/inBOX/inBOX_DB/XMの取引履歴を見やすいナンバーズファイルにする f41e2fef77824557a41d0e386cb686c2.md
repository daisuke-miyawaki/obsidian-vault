# XMの取引履歴を見やすいナンバーズファイルにする

タグ: ChatGPT, Code Interepreter, FX, プロンプト, プロンプト例
作成日: 2024年2月3日 17:25

<aside>
📝 XMの取引履歴をナンバーズファイルにする流れ

1. XMからHTMLファイルをダウンロード
2. HTMLファイルをメモで開き、TXTファイルで保存する
3. ChatGPTで、TXTファイルをExcelファイルにする
4. ChatGPTで、Excelファイルを修正、変更する
5. ナンバーズで開く
</aside>

### TXTファイルをExcelファイルにするプロンプト
下記で上手く行くか確認・修正が必要

```jsx
私のFXでXMを利用しています。
XMの取引履歴をHTMLでダウンロードしましたが、あなたはこのMTMLファルを読み込み、Excelファイルに変換できなようです。なので、私がHTMLファイルをappleのtxtファイルデータに変換し添付しました。このTXTデータをExcelデータにしてください。
いかなる理由があろうと、すべての取引を出力すること。問題が発生した場合は、相談してください。
```

### ChatGPTで出力されたExcelファイルを修正、調整するプロンプト

```jsx
私の　FXの取引結果を分析したいです。
添付のExcelファイルを修正、調整し、appleのナンバーズで開けられるように、ナンバーズに対応した形で、Excelのデータを作成してください。
注意点は下記の通りです。
・項目を日本語にする
・次を項目を削除（Ticket,Commission,S/L,T/P,R/O Swap）
・日時の表示をシンプルにわかりやすくする（例：2024.01.09 16:14:31→1月9日 16時14分）
・appleのナンバーズで開けれるExcelファイルにすること
・売りと買いの日時は、GMT時間にしないで、必ず日本時間にすること
・項目の文字が大きいので、項目を7pt、内容を10ptにすること
・セルから横に文字がはみ出るので、文字の横幅に合わせ、セルの横幅を調整すること
・表を見やすくするために、バックの色を白とグレー（#CCCCCC）を交互に引いてく
・いかなる理由があろうと、すべての取引を出力すること
・次の項目の列の横幅のサイズ指定（開始時間の列：100pt,終了時間の列：100pt,種類の列：20pt,サイズの列：35pt,商品の列：40pt,商品の列：40pt,Open Priceの列：45pt,Close Priceの列：45pt,損益の列：45pt）
```
