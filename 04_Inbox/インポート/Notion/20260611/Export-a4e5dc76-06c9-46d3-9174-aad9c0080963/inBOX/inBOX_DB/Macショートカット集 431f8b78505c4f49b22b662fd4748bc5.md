# Macショートカット集

タグ: Mac, PC, 効率化, 取扱説明書
テキスト: Macで使える便利なショートカット集
作成日: 2024年7月17日 13:05

### Finder関連のショートカット

| ショートカットキー | 説明 |
| --- | --- |
| Command (⌘) + Shift (⇧) + ドット (.) | 隠しファイルの表示・非表示を切り替え |
| Command (⌘) + N | 新しいFinderウィンドウを開く |
| Command (⌘) + T | Finderで新しいタブを開く |
| Command (⌘) + Shift (⇧) + N | 新しいフォルダを作成 |
| Command (⌘) + Delete (⌫) | 選択したアイテムをゴミ箱に移動 |
| Command (⌘) + Shift (⇧) + Delete (⌫) | ゴミ箱を空にする |
| Command (⌘) + Option (⌥) + Esc | フォースクイットのダイアログを開く |

### システム全体のショートカット

| ショートカットキー | 説明 |
| --- | --- |
| Command (⌘) + Space | スポットライト検索を開く |
| Command (⌘) + Tab | 開いているアプリケーション間を切り替える |
| Command (⌘) + Option (⌥) + Esc | アプリケーションのフォースクイットウィンドウを開く |
| Command (⌘) + Control (⌃) + Q | 画面をすぐにロックする |
| Control (⌃) + Command (⌘) + F | フルスクリーンモードの切り替えを行う |

### テキスト編集のショートカット

| ショートカットキー | 説明 |
| --- | --- |
| Command (⌘) + C | コピー |
| Command (⌘) + X | 切り取り |
| Command (⌘) + V | 貼り付け |
| Command (⌘) + Z | 元に戻す（アンドゥ） |
| Command (⌘) + Shift (⇧) + Z | やり直す（リドゥ） |
| Command (⌘) + A | 全選択 |

### ウィンドウ操作のショートカット

| ショートカットキー | 説明 |
| --- | --- |
| Command (⌘) + M | 現在のウィンドウを最小化する |
| Command (⌘) + H | 現在のアプリケーションを隠す |
| Command (⌘) + Option (⌥) + H | 他のすべてのアプリケーションを隠す |
| Command (⌘) + W | 現在のウィンドウを閉じる |
| Command (⌘) + Option (⌥) + W | 現在のアプリケーションのすべてのウィンドウを閉じる |
