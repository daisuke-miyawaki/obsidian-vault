# Blender【ショートカット集】

タグ: 3DCG, Blender, アプリ・ソフト, 説明・解説
作成日: 2024年4月27日 0:59

## **画面操作**

- **視点の移動**: **`中クリック`**＋ドラッグ
- **ズーム**: **`マウスホイール`**、または**`Ctrl + 中クリック`**＋ドラッグ
- **視点の回転**: **`Shift + 中クリック`**＋ドラッグ

## **オブジェクト操作**

- **移動**: **`G`**
- **回転**: **`R`**
- **スケール**: **`S`**
- **オブジェクトの選択/選択解除**: **`右クリック`**
- **複製**: **`Shift + D`**

## **編集モードの操作**

- **モード切り替え**: **`Tab`**
- **頂点選択**: **`1`**
- **辺選択**: **`2`**
- **面選択**: **`3`**
- **押し出し**: **`E`**
- フェイス（面）をインセット: **`i`**
- **ナイフツール**: **`K`**
- **ループカット**: **`Ctrl + R`**

### **立方体の角を丸くする**

- **ベベルツール**: **`Ctrl + B`** でベベルを適用し、マウスのスクロールでセグメント数を増減
- **ベベルの適用範囲**: エッジ選択モード(**`2`**)で適用したいエッジを選択してから **`Ctrl + B`**
- **頂点を滑らかにする**: 選択した頂点を **`Ctrl + Shift + B`** でスライドさせる

### **立方体の追加**

- オブジェクトモード**を使う**:
    1. オブジェクトモードで、**`Shift + A`** キーを押します。
    2. メニューが表示されるので、「メッシュ」を選択し、次に「立方体」を選択します。

### **その他便利なショートカット**

- **全選択/全選択解除**: **`A`**
- **選択範囲を反転**: **`Ctrl + I`**
- **Undo/Redo**: **`Ctrl + Z`** / **`Ctrl + Shift + Z`**
- **スムーズ操作**: **`W`** + **`S`**
- **頂点結合**: **`M`**

### **コレクション関連ショートカット**

- **コレクションへの移動**: **`M`**
- **コレクションの表示/非表示**: **`1-0`**
- **コレクション全体の選択**: **`Ctrl + 左クリック`（アウトライナー内）**

## **レンダリングと出力**

- **レンダリング開始**: **`F12`**
- **レンダリングのキャンセル**: **`Esc`**
- **イメージの保存**: **`F3`**
