🦖 ペット

- レベルアップ
    
    Giveexptotarget （経験値） 0 0
    例：Giveexptotarget  100000 0 0
    ※最大：1500（テイム前の場合は1000）これ以上は弱くなる
    
- テイム・刷り込み
    - 強制テイム：**Forcetame**
    - Setimprintedplayer “（プレーヤー名）”（プレーヤーID）
    例：Setimprintedplayer “MIYAMIYA” 1234567890
    - 刷り込み値を100％にするコマンド
    Setimprintquality 1
- ペット色変換
    
    生物の色変更コマンド
    Settargetdinocolor （カラー領域） （カラーID）
    例：Settargetdinocolor  0 1
    
    カラー領域
    [https://ark.fandom.com/ja/wiki/Creature_IDs](https://ark.fandom.com/ja/wiki/Creature_IDs)
