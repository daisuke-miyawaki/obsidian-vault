古い**all-in-one wp migration ver.6.68をダウンロード**

[all-in-one-wp-migration.6.68.zip](https://drive.google.com/file/d/19Nu0oLahhAaETsH_OPp8jFDFuvgCxFZ6/view?pli=1)

※上記からダウンロードできるが、一応自分でもバックアップを持っている

コードの書き換えは、**all-in-one wp migrationに設定されている容量を変更する**

- FTPプラグインのWP-FileManagerwoを入れ、ダウンロードし書き換えアップロードする
書き換えるのは、プラグインのフォルダ内にある「**constants.php」**

ファイルを開いて**「Command + F」**で検索すると

```jsx
// =================
// = Max File Size =
// =================
define( 'AI1WM_MAX_FILE_SIZE', 536870912 );
```

が見つかる。
これの**末尾に「* 10」を追加すると容量が10倍になる。（500GB）**

```jsx
// =================
// = Max File Size =
// =================
define( 'AI1WM_MAX_FILE_SIZE', 536870912 * 10 );
```
