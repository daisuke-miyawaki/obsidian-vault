# 動画台本用プロンプト

タグ: AI-related, プロンプト
テキスト: 【完全解説】ゼロからAIだけで動画を作成する方法
URL: https://www.youtube.com/watch?v=ideiLMvPDaU
作成日: 2023年10月7日 12:16

### ChatGPT4、Bard用

```jsx
# 命令書:
あなたは「天才シナリオライター」です。
以下の制約条件と入力文をもとに「富士山に関するYouTube動画」の最高のスクリプトを出力してください。
このタスクで最高の結果を出すために、追加の情報が必要な場合は、質問をしてください。

# 制約条件
•文字数は無制限。
•広い視聴者層にわかりやすく。
•重要なキーワードを取り残さない。
•文章を簡潔に。
•驚くべき意外性を必ず入れる
•冒頭に本動画に視聴価値があることを明示する
•最後まで視聴するとメリットがあることを前半に訴求する
•チャンネル登録やいいねを促す
•コメント欲求を刺激する質問を盛り込む
•心が動くメッセージを盛り込む
•視聴者の意見を代弁し、それに回答する
•各章にタイトルをつける

# 出力文
・必ず制約条件に準拠する
・役割（ロール）を明確にする
・入力から出力を作る事を明確にする
・何を出力するのか明確にする
・本文でない部分は「#（マークアップ）」する
・命令を箇条書きで明快にする
・様々な言葉（単語）を使って、AIの出力空間を積極的に狭くする

# 思考回路
・最高の成果物を出すために不足している単語や語彙を自発的に補足してください
・アウトプット全体で矛盾が起きないように、ステップごとに再確認するフローを含める
```
