# Claudeで使える【XMLタグ】

タグ: AI-related, コード・タグ, プロンプト, プロンプト例
作成日: 2024年3月12日 15:03

<instructions> - このタグは、ある作業の手順や指示を示す際に使用します。 - 例:

```xml
<instructions>
1. ファイルを開きます。
2. 編集したい箇所を選択します。
3. 変更を加えます。
4. 変更を保存して終了します。
</instructions>

```

<example> - サンプルやモデルケースを提示する際に使用します。 - 例:

```xml
<example>
  <problem>2x + 3 = 7 という方程式を解きなさい。</problem>
  <solution>
    2x + 3 = 7
    2x = 7 - 3
    2x = 4
    x = 2
  </solution>
</example>

```

<input> - プログラムやシステムへの入力値を示す際に使用します。 - 例:

```xml
<input>Hello World</input>

```

<tag> - このタグ自体は一般的な用途はありませんが、カスタムタグとして使用できます。 - データの種類を示したり、別の要素とグループ化したりする際に使用する可能性があります。 - 例:

```xml
<tag type="greeting">Hello</tag>
<tag type="name">John</tag>
<tag type="message">How are you today?</tag>

```

このようにXMLタグは、データを構造化し、意味を明確にするために使用されます。適切なタグを選択することで、情報をよりよく伝えることができます。

記事内でクローズアップして強調したい部分があれば、以下のようなタグを使うことができます。

<highlight>強調したい重要な文章</highlight>

- このタグで囲まれた文章が強調表示(Bold、色付きなど)されることを意図します。

<important>重要な情報がここに入ります</important>

- 重要な情報や要点を示す際に使用します。アイコンやボックスで視覚的に強調される可能性があります。

<callout>注目して欲しいポイントです</callout>

- 注目喚起したい部分をコールアウトする際に使用します。
- 通常はボックスやアイコンで囲まれ、デザイン的に目立つようになります。

<pullquote>引用したい一節がここに入ります</pullquote>

- 本文からクローズアップして引用したい一節を示す際に使用します。
- 通常は本文から違うスタイル(インデントや囲み線など)で表示されます。

これらのタグにより、記事の重要部分をマークアップし、視覚的にも分かりやすく強調できます。使い分けは状況によりますが、意図に合わせて適切なタグを選ぶとよいでしょう。
