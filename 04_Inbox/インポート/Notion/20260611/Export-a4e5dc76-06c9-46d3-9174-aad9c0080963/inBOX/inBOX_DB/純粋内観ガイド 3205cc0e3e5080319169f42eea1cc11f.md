# 純粋内観ガイド：自己の状態をありのままに観察する

## 1. 内観の定義

「今の自分の精神状態やその動きを、良い・悪いと判断せず、ただありのままに記述・観察すること」

## 2. 内観前の準備

- **分析の停止**: 「なぜこうなったのか？」「どうすれば良くなるか？」という原因追及や解決策の検討は一切行いません。
- **物理的な静寂**: 意識を外側（周囲の雑音やタスク）から切り離せる環境を確保します。
- **ジャッジの禁止**: どんな状態（怒り、焦り、虚無感、あるいは平穏）が出てきても、それは「ただの現象」であり、否定も肯定もしません。

## 3. 内観の実施方法（自由記述）

以下の5項目について、数値や記号を使わず、今の状態を短文で自由に記述してください。

1. **思考の動向**：今、頭の中では何が動いているか？（例：特定の考えが反復している、または静かである）
2. **身体の反応**：今、身体のどこに力みや違和感があるか？（例：指先に力が入っている、呼吸が浅い）
3. **感情の温度**：今、自分はどのような感情の中にいるか？（例：焦りを感じている、あるいは平坦である）
4. **現実との距離感**：自分は今、目の前の現象に飲み込まれているか、あるいは少し離れた場所から眺めているか？
5. **抵抗の有無**：今、何かをコントロールしようとする力みはあるか、あるいは委ねる感覚があるか？

## 4. 実施上の注意点

- **「記述」への集中**: 数値や評価（5段階など）は、比較や評価の判断を誘発し、観察の本質を損なうため行いません。必ず言葉で記述してください。
- **平準化の意識**: 毎日同じフォーマットで記録を続けることで、自分の中の「変化のパターン」が自然と可視化されます。
- **停滞の受容**: 「進歩がない」「何も分からない」という感覚そのものも、重要な観察結果（事実）です。その旨をそのまま正直に記述してください。
