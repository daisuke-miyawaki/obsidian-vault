# ChatGPTのDALLE3機能で使える小技10選

テキスト: DALLE3の使い方、画像を読み込みそのポーズをDALLE3で生成など

作成日: 2023年10月18日 12:54

<aside>
📝 **画像を読み込みそのポーズをDALLE3で再現**

1. GTP4V（ノーマル・Default）でポーズの見本にしたい画像を読み込む
2. プロンプトの入力「この画像をDALL-E3の詳細なプロンプトにして下さい」
3. DALL-E3にそのプロンプトを入力する
4. そこからプロンプトを入れて希望の写真にしていく
</aside>

<aside>
📝 縦横比の変更（アスペクト比）

- 16:9とプロンプトに追加
- 例：森の画像　16:9
- 多分、正方形と、16:9、9：16しかできない

```jsx
森の画像
16:9
```

</aside>

<aside>
📝 画像をプロンプト化する

1. GTP4V（ノーマル・Default）で見本にしたい画像を読み込む
2. プロンプトの入力「この画像をDALL-E3の詳細なプロンプトにして下さい」
3. DALL-E3にそのプロンプトを入力する
4. そこからプロンプトを入れて希望の写真にしていく
</aside>

<aside>
📝 画像に文字を入れる

- プロンプトに文字を入れる（まだテストしてない）

```jsx
ANIMAL
16:9
森と動物の雰囲気
```

</aside>

<aside>
📝 プロンプトを英語に変換してより正確に伝える

- 「プロンプトは英語にして生成してください」と入れると精度が上る
</aside>
