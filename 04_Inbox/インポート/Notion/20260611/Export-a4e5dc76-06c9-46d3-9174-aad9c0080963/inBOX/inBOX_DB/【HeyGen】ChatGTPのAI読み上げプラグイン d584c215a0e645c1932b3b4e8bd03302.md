# 【HeyGen】ChatGTPのAI読み上げプラグイン

タグ: ChatGPT, GPTs, プラグイン, 情報
作成日: 2023年11月19日 18:58

<aside>
📝 **heygenで使うAIの設定**

heygenで使うAIの設定は、以下のとおりです。

- **性別**：男性、女性、中性から選択できます。
- **国籍**：英語、日本語、中国語、韓国語から選択できます。
- **声質**：ナレーション、トーク、ボーカルから選択できます。

これらの設定は、heygenプラグインの設定画面から変更できます。

<aside>
📝 プロンプトで行う場合

- **性別**：`#gender:男性`、`#gender:女性`、`#gender:中性`
- **国籍**：`#nationality:英語`、`#nationality:日本語`、`#nationality:中国語`、`#nationality:韓国語`
- **声質**：`#voice:ナレーション`、`#voice:トーク`、`#voice:ボーカル`

例えば、以下のようになります。

`#gender:男性
#nationality:英語
#voice:ナレーション

これは男性の英語のナレーションです。`

また、複数の設定を同時に指定することもできます。

例えば、以下のようになります。

`#gender:女性
#nationality:日本語
#voice:トーク
これは女性の日本語のトークです。`

※なお、これらのプロンプトは、heygenプラグインの設定画面の設定を上書きします。

</aside>

</aside>

<aside>
📝 **heygenでできること**

heygenでできることは、以下のとおりです。

- テキストの読み上げ
- 音声の生成
- 動画の生成

テキストの読み上げでは、テキストをAIが読み上げてくれます。音声の生成では、テキストから音声を生成することができます。動画の生成では、テキストや音声を組み合わせて動画を生成することができます。

</aside>

<aside>
📝 **プロンプトの入れ方**

heygenで読み上げたいテキストをプロンプトとして入力します。プロンプトは、1行で1つの文章を入力します。

例えば、以下のようになります。

```jsx
これはプロンプトです。
```

複数行の文章を読み上げたい場合は、改行コードを挿入して、複数行に分けて入力します。

例えば、以下のようになります。

```jsx
これはプロンプトです。

これは2行目のプロンプトです。
```

また、プロンプトの中に、変数を埋め込むこともできます。変数は、$で囲んで指定します。

例えば、以下のようになります。

```jsx
名前は$nameです。
```

この場合、$nameの部分は、ユーザーが入力した名前で置き換えられます。

</aside>

<aside>
📝 **その他の使い方**

heygenには、以下のようなものもできます。

- 読み上げ速度や声質を調整する
- 読み上げのタイミングを調整する
- 読み上げの音量を調整する

これらの設定は、heygenプラグインの設定画面から変更できます。

**具体的な使い方例**

heygenは、以下のような用途に使用できます。

- テキストの読み上げボット
- 音声合成ソフト
- 動画制作ソフト

例えば、以下のようなものが挙げられます。

- ニュース記事の読み上げ
- 小説の朗読
- 音声ガイドの作成
</aside>
