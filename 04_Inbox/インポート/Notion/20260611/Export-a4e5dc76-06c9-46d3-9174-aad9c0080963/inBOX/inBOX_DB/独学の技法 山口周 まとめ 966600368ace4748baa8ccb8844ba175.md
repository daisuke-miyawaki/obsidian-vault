<aside>
🗂️ 知的戦力をどう上げるか？

<aside>
🗂️ 4つのモジュール

- 流れ：戦略→インプット→抽象化・構造化→ストック
</aside>

<aside>
🗂️ 戦略

- テーマを決める
- 知的戦闘力を高める方向を考える
    - 自分の強み、弱み、特徴を加味した戦略
    - やらないことがわかることで無駄が減る
- 武器を探すようなリアルな視点で考える
- 戦略は粗い方向だけで良い
それは、決め過ぎることで限界や、流動性、クリエイティビティを失うから
</aside>

<aside>
🗂️ インプット

- 広範囲のソースから自分の五感で行う知的生産
- 本やテレビ、YouTubeだけでなく、音楽、映画、アート作品もOK
- 常に学びのスイッチをONにする
- 眼の前の事象からも学べる
</aside>

<aside>
🗂️ 抽象化・構造化

- 洞察につながる「問い」と「組み合わせ」
- 知識を武器に変えるフェーズ
- 問いを作るための学び
- 抽象化された仮説は、構造化によって別の知識、情報と紐付けられる
</aside>

<aside>
🗂️ ストック

- 効果的に知識を引き出せるシステム作り
- Notionにストックしいつでも取り出せるように整理
</aside>

</aside>

<aside>
🗂️ 自分の価値を高める戦略

<aside>
🗂️ テーマが主で、ジャンルが従

- 同じジャンルからの情報収集を避ける
- テーマとジャンルをクロスオーバーさせる
- 例：テーマ「組織における権力」
　　ジャンル「歴史文学」「政治哲学」「映画」「動物行動学」
というように分ける、偏りのない知識を入れる
</aside>

<aside>
🗂️ プロデュースとは掛け算

- アメリカのロック×イギリスのコスチューム
→ビートルズ
- デザイン×テクノロジー
→アップル
</aside>

<aside>
🗂️ ジャンル選びは「持っているもの」を起点に

</aside>

<aside>
🗂️ 知識の整理

- ラベルを明確に
</aside>

</aside>

<aside>
🗂️ 生産性の高いインプット技法

<aside>
🗂️ インプットの目的

- 短期的な仕事で知識をえる
- 専門域を深める
- 教養を広める
- 娯楽
</aside>

<aside>
🗂️ ポイント

- 共感できる良いインプットに安心しない
- 無目的なインプットこそ後で生きる
- 身の丈にあわせる
- 関連分野をまとめて
- 教養主義の罠に落ちない
- 量より密度
- 問いのないところに学びなし
</aside>

<aside>
🗂️ 知的ストックの貯蔵法・活用法

<aside>
🗂️ 生け簀に「情報」という魚を生きたまま泳がせる

- 厚いストックは常識を相対化する
- 創造性が1000倍になる
- 共感できない情報も大切
- 興味深い事実から得られる「洞察」「示唆」
- 洞察や示唆から得られる行動の指針
- 知識を状況に応じて使い、次の段階は、
知識を組み合わせ自分ならではの概念を構築
- 本のインプットしたリプレイを作るイメージでまとめ記録する
</aside>

<aside>
🗂️ 戦略

- テーマを決める
- 知的戦闘力を高める方向を考える
    - 自分の強み、弱み、特徴を加味した戦略
    - やらないことがわかることで無駄が減る
- 武器を探すようなリアルな視点で考える
- 戦略は粗い方向だけで良い
それは、決め過ぎることで限界や、流動性、クリエイティビティを失うから
</aside>

<aside>
🗂️ インプット

- 戦略の方向性に合わせ情報をインプットする
</aside>

<aside>
🗂️ 抽象化・構造化

- インプットした知識を抽象化したり、他のものと結びつけることで、自分なりのユニークな示唆・洞察・気づきを生み出す
</aside>

<aside>
🗂️ ストック

- 獲得した知識と、抽象化・構造化で得られた示唆や洞察をセットで保存しいつでも引き出せるように整理
</aside>
