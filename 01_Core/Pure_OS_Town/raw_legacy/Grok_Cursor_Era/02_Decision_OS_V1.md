# Decision OS

## 目的

AI提案を採用するか判断する意思決定OS。

## 役割

[AI Proposal Policy](01_AI_Proposal_Policy_V1.md) を通過した提案に対し、採用・保留・却下を判定する。

## Version

**Version 1.0**（2026-07-09）

---

## Version1 審査項目

提案ごとに、以下7項目を確認する。

| # | 審査項目 | 確認内容 |
|---|----------|----------|
| 1 | **事実確認** | 根拠は事実か。推測・一般論・ハルシネーションの混在はないか |
| 2 | **人生戦略OSとの整合性** | `01_人生戦略OS/` の価値観・戦略・意思決定基準と矛盾しないか |
| 3 | **Knowledge OSとの整合性** | `SecondBrain/00_KnowledgeOS/` のルール・構造と矛盾しないか |
| 4 | **長期運用性** | 数週間後も維持できるか。一時的な流行や過剰設計ではないか |
| 5 | **世界の失敗事例** | 同様の設計で失敗した事例はないか。リスクは許容範囲か |
| 6 | **実装負荷** | ユーザー（宮脇）の負担は現実的か。監査役としての疲弊を増やさないか |
| 7 | **レビュー結果** | [AI Review Process](03_AI_Review_Process_V1.md) の指摘は解消されたか |

---

## 判定出力フォーマット

Decision OSの判定は、必ず以下の形式で出力する。

```
## 判定

- **結果**: 採用 / 保留 / 却下
- **理由**: （判定の根拠を簡潔に）
- **次回確認事項**: （保留の場合に何を確認するか。採用・却下の場合は「なし」）
```

### 判定基準

| 結果 | 条件 |
|------|------|
| **採用** | 7項目すべて問題なし。または軽微な懸念は許容範囲 |
| **保留** | 事実確認・整合性・レビュー結果のいずれかが未確定 |
| **却下** | 重大な矛盾・高リスク・実装負荷過大。またはVersion1のスコープ外 |

---

## 運用ルール

- Decision OSは **採決** である。レビューとは別のレイヤー
- ChatGPTは設計者ではなく **監査役** として本OSを実行する
- 保留は「却下」ではない。次回確認事項を明記して再審査する
- 却下された提案のうち将来有用なものは、Proposal PolicyのVersion2候補へ送る
