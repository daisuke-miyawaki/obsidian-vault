# Schema Update Rules - Pure OS Town Governance

## 絶対ルール
- Schema変更提案はPatrolのみが行える
- Mayorが整合性チェック後、Human Overseerに提示
- Humanは「承認」または「却下」のみ。詳細編集禁止
- 承認された変更は全Townに即時反映 + バージョン管理
- 変更履歴はgovernance/change_log.mdに自動記録

## 禁止
- Patrol以外からのSchema変更提案
- Humanの日常介入
- 過去体系への配慮を理由にした変更

このルールはPURE_OS.mdの第6条を具体化したもの。PatrolとMayorは常時遵守。
