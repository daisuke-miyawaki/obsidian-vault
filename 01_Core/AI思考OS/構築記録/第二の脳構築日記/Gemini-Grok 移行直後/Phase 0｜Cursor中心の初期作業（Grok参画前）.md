# Phase 0: Cursor中心の初期作業（Grok参画前）

## 背景
- Grok参画前にCursorをメインに第二の脳構築を進めていた
- プレハブフォルダを中心に試行錯誤
- AI会社化、ナレッジ管理、フォルダ設計が分散して混乱

## 主要資料と取り組み
- **Cursor運営プロンプト設計・プレハブ運営方針**
  - Cursorを記録管理担当として位置づけ
  - Inbox中心の軽量運用
  - 完璧主義を避け、運営しながら育てる方針

- **第二の脳構築アイデアリサーチ**
  - 外部ナレッジ（YouTubeなど）の蓄積方法
  - 即時インデックス（CSV）の検討
  - インプットの熱量を止めない運用

## このPhaseの問題点
- 設計が複数チャットに分散
- 全体像を把握しにくい
- Grokを統括PMとして迎える必要性が生まれた

## 学び
- Cursorは開発・記録に強いが、統括は苦手
- 分散した設計を1つにまとめる必要性
- プレハブ段階から本格的なエコシステム設計へ移行
