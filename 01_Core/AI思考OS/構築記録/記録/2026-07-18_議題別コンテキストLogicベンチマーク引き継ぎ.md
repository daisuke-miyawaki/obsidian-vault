### 主なベンチマーク
1. **Context Engineering + Topic/Role-aware Routing**
   - n8n, RCR-Router, AgentCenter
   - タスク/役割/議題ごとにコンテキストをisolate & switch。
   - トークン節約25-47%、drift防止。

2. **LLM Wiki / Living Memory for Second Brain**
   - Karpathy影響（Rowboatなど）
   - 議題（topic）ごとにコンパイルされたwikiを作成。生ノートから自動summary/index。
   - あなたのNotionエクスポート重複問題解決に特に有効。

3. **Event-Sourced / Shared Memory Architecture**
   - ESAA-Conversational
   - 会話をevent log化 → topic別summary + decisions + tasksでhandoff。

4. **Self-Evolving Context & Multi-Agent Patterns**
   - Shared knowledge graph, hierarchical / event-driven orchestration。
   - コンテキスト自体をagentが更新・curation。
