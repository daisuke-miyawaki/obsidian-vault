作成日: 2026-07-24  
作成者: Grok（前チャットの議論を基に作成）

---

## 1. このプロジェクトの本当の目的

**ファイル整理**が主目的である。

将来何十年も成長し続けるAI思考OSのために、既存のファイル・概念の役割を明確にし、適切な配置・整理を行うことが目的。

概念の議論自体が目的ではない。  
概念の役割確認は「ファイルをどう整理するかを決めるための手段」に過ぎない。

---

## 2. 現在の工程（フェーズ）

**観察工程**（設計・修正・提案の工程ではない）

- 既存の概念について「主な役割」「他との違い」「まだはっきりしない点」を文書に基づいて観察する
- 新しい概念を作らない
- 構造を作らない
- 修正案を出さない
- 「こうあるべき」を言わない
- わからないものは「わからない」と残す

この工程の成果物は「理解の深化」と「わからない点の明確化」である。  
構造や正本の決定はまだしない。

---

## 3. 現在把握できていること

### 比較的はっきりしている概念
- **Human**: 最終判断を持つ側。「最終判断は人間」「Human Review」など。
- **人生戦略OS**: Humanの人生の知識体系・一次情報源（SSoT）。
- **User Model**: 人生戦略OSから抜いた、AIの日常判断用の最小材料（圧縮）。
- **AI思考OS**: AI自身の判断原則（理解優先・SSoT尊重・目的整合など）。
- **Memory Policy**: 何をどのTierで覚える／参照するか。
- **Governance索引**: ガバナンス関連へ迷わず行く入口。

### 会話上使っているが、正式概念かは未確認のもの
- **Why**: 人生の目的・価値観側を指す会話用ラベル。実体としてよく指すのは0400や人生戦略OSの目的記述。
- **Who**: Humanを判断材料として圧縮した側。実体としてよく指すのはUser Model。
- **How**: AIがどう考える・どう協働するかの原則側。実体としてよく指すのはAI思考OS。

### 名前はあるが実体が複数／薄いもの
- Knowledge / KnowledgeOS
- Governance本体（索引・憲法・各ルールのどれを指すか不明）
- Project
- Context
- Automation

---

## 4. 現在残っている「わからない」点（重要）

1. Why / Who / How は、既存ファイルの読み方ラベルなのか、OSに置く常設概念なのか。
2. Governance の「本体」は索引・憲法・各ルールのどれを指すのか。
3. Knowledge の置き場は一つに見えない（KnowledgeOS / 03_素材庫 / SecondBrain / Failure Library など）。
4. Context / Project / Automation は日常語として使われているが、定義正本があるかは不明。
5. User Model と AI思考OS の境目（特性か原則か）は、現状の文章だけでは切り切れない。

※ これらは「解決する」対象ではなく、「現時点でわからない」と確認できていることが成果。
